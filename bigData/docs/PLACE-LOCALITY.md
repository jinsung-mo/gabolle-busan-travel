# 장소 로컬성 — 규칙과 근거 (S15P21E201-1164)

`process/place-locality.mjs` 가 무엇을 어떻게 내는지. **코드가 아니라 여기가 규격이다.**

```
로컬성 = 반경 300m 안 가게들의 업종 가중치 평균을, 부산 안에서 순위로 바꾼 값
         100 = 동네 · 0 = 관광지
```

이 축은 **「관광지 ↔ 동네」 양 끝을 담는 유일한 축**이다. 관광객 비율 축은
**쓸 재료가 로컬과 같아서** 만들지 않는다 — 만들면 사용자가 질문을 두 번 받고 답은
한 번만 반영된다.

---

## 🔴 0. 처음 가설은 틀렸다 — 지우지 않고 남긴다

**영업 지속기간**으로 가려 했다. 인허가 데이터에 `인허가일자`·`폐업일자` 가 있어서
*「동네는 오래된 가게가 많고 관광지는 자주 바뀐다」*고 본 것이다. **실측이 반대로 나왔다.**

```
2026-09-17 · 반경 200m 영업연수 중앙값
  자갈치시장(관광지)   19.8년   ← 제일 오래됨
  남포동(관광지)       14.3년
  괴정동(주거)         12.4년
  사직동(주거)          1.6년   ← 제일 짧음
```

**오래된 관광지가 있고 새로 생긴 주거지가 있다.** 가게 나이는 「관광지↔동네」가 아니라
**「그 상권이 언제 생겼나」**를 잰다. 다른 축이다.

🔴 **다음 사람에게: 이 가설을 다시 세우지 마라.** 그럴듯하지만 자갈치 19.8 대 사직 1.6 이
그 자리에서 깬다.

**인허가 수집은 헛일이 아니다** — 좌표 변환 검증(상가정보와 짝 15,218개, **오차 중앙값
1.7m**)에 쓰였고 음식 랭킹 쪽에 남는다. 로컬 축의 재료가 아닐 뿐이다.

## 1. 무엇으로 가르나 — 업종 구성

상가정보의 **상권업종대분류**를 쓴다. **우리가 만든 분류가 아니라 이미 붙어 있는 것**이다.

> **숙박이 관광 신호다.** 호텔·모텔·게스트하우스는 **밖에서 온 사람**이 있어야 선다.
> 동네 사람은 자기 동네에서 안 잔다.
>
> **교육이 동네 신호다.** 학원·교습소는 **사는 사람**이 있어야 생긴다.
> 관광객은 학원에 안 다닌다.

부산 **192개 행정동 전수** 실측이 받쳐 준다 (2026-09-17):

```
숙박 상위   청학1동 16.3% · 송정동 14.7% · 광안2동 13.4% · 민락동 12.3% · 암남동 8.8%
            → 전부 해변 아니면 항만·역 주변

숙박 0%     만덕3동(교육 7.4%) · 괴정2동(6.2%) · 덕천3동(5.4%) · 용호2동 · 부곡4동
            → 전부 주거지이고 교육이 높다
```

가중치는 **`config/locality-weights.json`** 에 있다. 🔴 **그 숫자는 실측이 아니다** —
「숙박이 관광이고 교육이 동네다」는 사람의 판단이다. 순서는 믿을 만하지만 간격은 지어낸
것이다. 파일 머리말에 그대로 적어 두었다. `road-noise-weights.json` 과 같은 성격이다.

🔴 **음식과 소매는 0(중립)** 이다. 둘이 전체의 58% 인데 관광지에도 동네에도 똑같이 많다.
여기에 방향을 주면 **「가게가 많은 곳」이 곧 「관광지」**가 되어 버린다. 다른 이야기다.

## 🔴 2. 왜 날 비율이 아니라 순위인가

숙박 비율 분포가 한쪽으로 심하게 쏠려 있다 — **최소 0.0% · 중앙 0.8% · 최대 16.3%**.
날 비율을 0~100 으로 펴면 **거의 모든 장소가 「동네」 끝에 뭉치고**, 사용자가 손잡이를
어디에 놓아도 결과가 안 바뀐다.

그래서 **부산 안에서의 순위(백분위)** 로 바꾼다.
`process/shade.mjs` 가 같은 이유로 같은 선택을 했다 —
*「백분위는 사람이 정한 상한이 아니라 데이터가 정한다」*.

🔴 **그래서 이 값은 상대값이다.** *「로컬 점수 70」*은 *「부산의 다른 장소들과 견주어 상위
30%」*라는 뜻이지 절대적인 무엇이 아니다. **장소가 늘면 점수가 움직인다.**
화면은 「부산에서 로컬한 편」처럼 읽히게 써야 한다.

⚠️ **분포가 고른 것은 자료가 고르다는 뜻이 아니다.** 순위로 바꿨으니 당연히 고르다.
아래 구간별 개수가 전부 545 안팎인 것은 **설계의 결과이지 발견이 아니다.**

## 🔴 4. 이 값이 못 하는 것

* **가게 자체를 안 본다. 동네를 본다.**
  실제로 나온 예 — **`신라스테이 서부산` 이 99.8점(제일 동네)** 이다. 호텔인데 그렇다.
  주변이 주거·산업 지역이라 그렇게 나온 것이고 **틀린 값이 아니다.** 이 축은
  *「이 **동네**가 로컬한가」*이지 *「이 **가게**가 로컬한가」*가 아니다.
  같은 이유로 관광지 한복판의 오래된 동네 밥집도 낮게 나온다
* **관광객이 실제로 몇 명인지 모른다.** 숙박 밀도는 「관광지로 개발됐나」이지 사람 수가 아니다
* **업종 분류가 2026-06 수집분에 묶여 있다.** 새로 생긴 가게는 없다
* **표본이 모자라면 줄을 안 만든다** — 반경 안 가게가 30곳 미만이면 값이 없다 (283곳).
  🔴 **「모른다」를 「동네다」로 바꾸지 않는다.** 산속·해안이 주로 여기 걸린다
