# 걸을 만한가 — 구글맵이 안 세는 것들

**2026-08-27 조사.** 어디까지 알아봤고, 무엇을 아직 못 했는지의 기록이다.

---

## 0. 왜 이 문서가 있나

구글맵은 *"도보 5분"* 이라고 말한다. 그런데 부산에서 **산복도로 300m 와 광안리
해변 300m 가 똑같이 5분**으로 나온다. 실제로 걸으면 전혀 다른 5분이다.

> **걷는 비용은 거리도 시간도 아니다. 힘듦과 쾌적함이다.**

현지인은 그냥 안다 — 저 길은 여름에 그늘이 없다, 저긴 오르막이다. 여행 서비스는
그걸 물어본 적이 없다. 그 빈칸을 데이터로 채우는 것이 bigData 파트의 일이다.

채우고 나면 서비스가 이렇게 말할 수 있다 — *"이 구간은 걸을 만합니다"* 또는
*"여긴 택시를 타세요"*. [FIELD-STUDY.md](FIELD-STUDY.md) 가 그 판단의 **가중치**를
사람에게 물어 정하는 방법이고, 이 문서는 그 **재료**를 어디서 구하는지다.

## 1. 지금 있는 것

| 요소 | 어디서 | 상태 |
|---|---|---|
| **경사** | DEM 에서 계산 | ✅ 전역 67,676구간 |
| **계단** | OSM + 고도차 추정 | ✅ 617곳 20,106단 |
| **버스 실소요시간** | BIMS 실시간 폴링 | 🔄 쌓는 중 (소급 불가) |

🔴 **경사를 OSM 태그로 안 만든 이유**가 이 파트 전체의 태도를 보여준다.
부산 전역 way 68,765개에서 `incline` 태그 보유율이 **0.3%** 였다. 태그에 기대는
설계는 전역에서 무너진다. 그래서 고도에서 **계산**했다.

같은 판단을 아래 요소들에도 적용한다 — **태그를 믿기 전에 보유율을 먼저 잰다.**

## 2. 그늘 — 두 갈래로 나뉜다

여름 부산에서 그늘 유무는 "조금 덜 쾌적" 이 아니라 **걷느냐 마느냐**를 가른다.

### 2.1 가로수 — 받으면 바로 쓸 수 있다

```
부산광역시_구군 가로수 현황
778개소 · 18만 그루 · 수종 38종 · 무료 · 자동승인
https://apis.data.go.kr/6260000/RoadsideTreeService/RoadSideTreeStusInfo
```

**길 단위 데이터다.** 집계 숫자가 아니라 구간이 들어 있다.

| 필드 | 예 |
|---|---|
| `loc_nm` | 부산광역시 중구 중앙대로 |
| `sec_timepoint` → `sec_endpoint` | 영주사거리 → 롯데백화점 |
| `plant_distance` | 1.6 km |
| `total` + 수종별 38개 컬럼 | 244그루 (메타세콰이아 149, 버즘나무 69 …) |

🔴 **수종이 나뉘어 있는 것이 핵심이다.** 나무마다 그늘이 다르다.

| 수종 | 그늘 |
|---|---|
| 메타세콰이아 · 버즘나무(플라타너스) | 크고 짙다 |
| 왕벚나무 · 느티나무 | 여름에 잎이 무성해 좋다 |
| 주목 · 가이즈카향나무 | 키가 작아 거의 없다 |

그래서 *"가로수가 있다/없다"* 가 아니라 **그늘 점수**를 만들 수 있다 —
수종 가중치 × 그루 수 ÷ 식재거리.

⚠️ **이 데이터는 계산으로 절대 못 만든다.** 나무가 어디 심겼는지는 위성 고도에도
OSM 태그에도 거의 없다. 받아야만 알 수 있는 것이다.

### 2.2 건물 그림자 — 계산할 수 있다. 크롤링할 게 아니다

```
건물 높이  +  태양 고도(날짜·시각)  =  그림자 길이
```

경사를 고도에서 계산한 것과 **같은 종류의 계산**이다. 사진이 필요 없다.

🔴 **그림자는 시각에 따라 답이 달라진다.** 여름 정오 부산에서 해는 약 77° 로
거의 머리 위라 60m 건물도 그림자가 **14m** 밖에 안 된다. 길을 못 덮는다.
오후 4시에는 해가 30° 로 내려가 같은 건물이 **104m** 그림자를 만든다.

여행 일정에는 이미 시간표가 있으므로 이 성질이 오히려 잘 맞는다 —
*"이 구간을 오후 2시에 걸으면 뙤약볕, 4시면 그늘"* 이라고 말할 수 있다.

**높이 데이터 실측 (2026-08-27, 받아둔 OSM 286MB 기준)**

```
부산 bbox 안 건물          52,614개
height 태그 있음            1,099  ( 2.1%)
building:levels 있음       16,206  (30.8%)
둘 중 하나라도 있음         16,223  (30.8%)
```

경사 태그가 0.3% 였던 것에 비하면 **100배 좋은 상태**다. 층수는 높이로 바꿀 수
있다 — 한국 아파트 층당 약 2.8m, 상가 약 4m. 정확한 m 를 몰라도 그림자 길이를
재는 데는 충분하다.

⚠️ **남은 70% 를 어떻게 볼 것인가.** 표본을 보면 아파트·대학 같은 **큰 건물에
층수가 있고** 작은 건물에 없는 패턴이다. 그림자에 실제로 영향을 주는 것은 큰
건물이므로(2층 상가는 그림자 5m 로 길을 못 덮는다) **빈 70% 는 대체로 그림자를
못 만드는 건물**일 가능성이 크다. **이건 가설이고 아직 확인하지 않았다** —
면적으로 세어보면 답이 나온다.

## 3. 경치 — 로드뷰는 쓸 수 없다

`CLAUDE.md` 1절이 이미 정한 것이다. **네이버·카카오 로드뷰 이미지는 수집·재배포가
금지**다. 화면에 임베드해서 보여주는 것만 허용된다.

대안은 셋이고, 아직 어느 것도 안 했다.

| | 무엇 | 비고 |
|---|---|---|
| Mapillary | CC BY-SA — 다운로드·가공 가능 | 토큰 대기 + 부산 커버리지 미확인 |
| OSM 파생 | 바다·공원·전망대와의 거리로 근사 | 이미 받아둔 데이터로 가능 |
| 직접 촬영 | 제약 없음 | 사람 시간이 든다 |

OSM 파생이 제일 싸다. *"경치가 좋다"* 를 직접 재는 대신 **"물가·공원·고지대에
가깝다"** 로 근사하는 것이다. 완벽하진 않지만 0 보다 낫고, 지금 있는 데이터로
오늘 만들 수 있다.

## 4. 안 맞았던 것 — 찾아봤으나 버린 것

기록으로 남긴다. **다음 사람이 같은 검색을 반복하지 않게.**

- **보행 관련 오픈API 42개를 훑었다.** 대부분 어린이·노인 **교통사고 다발지역**
  통계다. 안전 정책용이지 *"이 길이 걸을 만한가"* 가 아니다. 지역도 경기·강원·
  성남이 많고 부산 것이 거의 없다.
- **건축물대장 API** 는 **주소로 조회**하는 구조다. 우리는 좌표 범위로 훑어야
  하는데 그게 안 된다. 부산 건물 5만 개를 한 건씩 주소로 부를 수도 없다.
  → 도형과 대장이 이미 합쳐진 **GIS건물통합정보**가 맞는 물건이다.

건질 것이 하나 있었다.

- **국토교통부_보행우선구역(WMS/WFS)** — 국가가 *"여기는 걷기 좋게 조성했다"* 고
  지정한 구역. **계산으로는 만들 수 없는 종류의 신호**다. 부산에 몇 구역이
  있는지는 아직 안 봤다.

## 5. 지금 막혀 있는 것

🔴 **국가공간정보포털(nsdi.go.kr)에 연결이 안 된다.**

```
https://www.nsdi.go.kr      curl → 000
http://www.nsdi.go.kr       curl → 000
https://openapi.nsdi.go.kr  curl → 000
```

`000` 은 HTTP 응답이 아니라 **연결 자체가 안 됐다**는 뜻이다. 브라우저 문제가
아니라 망 또는 사이트 문제다. 점검인지 이 네트워크에서의 차단인지는 **확인하지
못했다. 다른 망에서 다시 시도할 것.**

여기가 막히면 건물통합정보(도형+층수)를 못 받는다. 다만 OSM 의 30.8% 로
시작은 되므로 **일정을 막지는 않는다.**

## 6. 다음 한 걸음

우선순위 순이다.

1. **가로수 활용신청** — 자동승인이라 로그인만 하면 끝난다. 받는 즉시 그늘 점수를
   만들 수 있다. **오늘 할 수 있는 것 중 가장 값이 크다**
2. **OSM 층수 빈 곳의 성격 확인** — 면적으로 세어 "작은 건물이라 그림자가 없다"
   가설을 검증한다. 참이면 건물통합정보를 안 기다려도 된다
3. **nsdi 재시도** — 다른 망에서
4. **보행우선구역의 부산 커버리지 확인**

수치는 이 문서에 적지 않는다 — 그늘 점수의 가중치도, 층당 높이도. 그것들은
**측정이 정하는 값**이고, 여기 적으면 그 순간 낡는다.
경사 기준선을 `_calibration.json` 이 정하게 한 것과 같은 이유다 (`CLAUDE.md` 6절).
