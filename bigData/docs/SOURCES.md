### 3. 국토지리정보원 5m DEM — 지금 쓰는 30m 를 교체한다 (아직 못 받음)

- https://map.ngii.go.kr 국토정보플랫폼 → 로그인 → 수치표고모델
- 대용량 파일전송 S/W 를 깔라고 한다 (Windows)
- 받은 뒤 `npm run calibrate` 를 **다시 돌려 기준선을 다시 정한다**

> 🔴 **2026-09-06 실측 — 지도 화면의 `공개DEM` 은 이것이 아니다.**
> 국토정보맵에서 지역을 찍으면 `수치지도 · 항공사진 · 정사영상 · **공개DEM** · 온맵 …`
> 갈래가 뜨고, **공개DEM 은 프로그램 없이 브라우저에서 바로 받아진다.** 그래서 위의
> *"대용량 전송 S/W 가 필요하다"* 가 안 걸린다 — **다른 물건이라서 안 걸리는 것이다.**
>
> 도엽 `35913`(해운대 일대)을 6개 연도 전부 받아 재 봤다.
>
> | | |
> |---|---|
> | 격자 간격 | **90m** (x·y 모두. 간격 종류가 `[90.0]` 하나뿐) |
> | 크기 | 264 × 319 칸 (2014년만 260 × 314) · float32 |
> | 덮는 범위 | 23.8km × 28.7km — 도엽 한 장이 아니라 부산 일대 통째 |
> | 좌표계 | **EPSG:5186** (Korea 2000 중부원점). 부산 지점 넷을 투영해 확인 |
> | 고도 | 0 ~ 612m |
> | 연도 | 2014 · 2021~2025. **여섯 개 내용이 전부 다르다**(md5 상이) |
>
> 🔴 **90m 는 지금 쓰는 것보다 3배 거칠다.** AWS Terrain Tiles 가 31m 다
> (`data/staged/_vista-summary.json` 의 `cellM: 31.28`). **교체가 아니라 후퇴다.**
> 경사 계산에 쓰면 안 된다.
>
> **그럼 어디에 쓰나 — 두 가지.**
> 1. **SRTM 수직오차를 재는 자.** 지금 고도는 위성(SRTM) 기반이고 수직오차 ±5m 로
>    적혀 있다. 이건 국내 공식 측량이라 겹치는 점 8만 개로 실제 편차를 낼 수 있다.
>    바다 마스크 임계값을 손대지 않기로 한 근거가 그 ±5m 다 — 그 숫자를 실측으로 바꾼다
> 2. **좌표계가 건물과 같다.** GIS건물통합정보도 `EPSG:5186` 이라 변환 없이 겹친다
>
> **5m 는 여전히 못 받았다.** 별도 경로이고, 위의 전송 S/W 안내는 그쪽 것으로 보인다.
> 받는 경로를 다시 찾아야 한다.

### 🔴 영업시간 필드 이름이 분류마다 다르다

하나로 받으려 했으면 관광지와 문화시설이 통째로 비었을 것이다.

| 분류 | 영업시간 | 휴무일 |
|---|---|---|
| 음식점 | `opentimefood` | `restdatefood` |
| 관광지 | `usetime` | `restdate` |
| 문화시설 | `usetimeculture` | `restdateculture` |

그래서 수집기는 **이름을 하나로 뭉개지 않고 응답 원문을 그대로 남긴다.**
어느 필드가 영업시간인지는 `process/` 가 판단한다. 넷째 이름이 나와도 안전하다.

### 실제로 얼마나 채워졌나 (2026-09-08)

| 분류 | 상세 | 영업시간 | 휴무일 |

| 문화시설 | 35 | 34 | 35 |

## 인증 없이 되는 것 (이미 받아둠)

작업 범위는 **부산 전역**이다.

| | 라이선스 | 명령 |
|---|---|---|
| Geofabrik 전국 OSM 286MB | ODbL 1.0 | `npm run collect:osm` |
| ↳ **거기서 뽑은 부산 전역** (way 68,765) | ODbL 1.0 | `npm run collect:extract` |
| AWS Terrain Tiles 고도 3,127타일 | 공개 데이터 | `npm run collect:terrain` |
| Overpass — focus 구역(중구·동구) | ODbL 1.0 | `npm run collect:overpass` |

> 🔴 **전역을 Overpass 로 긁지 않는다.** 공용 서버에 241배 부하다.
> 전역은 PBF 에서 뽑는다 — 네트워크를 안 쓰고 64초에 끝난다.
> `overpass.mjs` 에 면적 상한 200km2 가 코드로 걸려 있어 전역을 부르면 거부한다.

**ODbL** — 출처를 밝히고, 이 데이터로 만든 DB 를 배포하면 같은 라이선스로 열어야 하는
조건. 우리는 서비스만 하고 DB 를 배포하지 않으므로 **출처 표기**만 지키면 된다.
