# 데이터 출처 — 무엇을 어디서, 누가 신청하나

기계가 읽는 판은 [`config/sources.json`](../config/sources.json) 이다. 이 문서는 사람용이다.

## 🔴 지금 당장 해야 하는 것

우선순위 순서다. 1번이 늦으면 되돌릴 수 없다.

### 1. 공공데이터포털 API 키 — BIMS 실시간 버스 ⚠️ 오늘

**실시간 데이터는 소급 수집이 안 된다.** 오늘 안 켜면 오늘치가 영영 없다.

1. https://www.data.go.kr 회원가입
2. "부산광역시 버스" 검색 → 실시간 위치 관련 오퍼레이션 **활용신청** (보통 자동승인, 1시간 내)
3. 마이페이지에서 **일반 인증키(Decoding)** 복사
4. 활용신청 상세의 **요청주소**도 복사 (오퍼레이션마다 다르다. 지어내지 않는다)
5. ```bash
   cd bigData && cp .env.example .env
   # DATA_GO_KR_KEY 와 BIMS_ENDPOINT 를 채운다
   npm run collect:bims        # 끄지 않고 둔다
   ```

### 2. 도로명주소 전자지도 (실폭도로) — 심사가 있다

대상 구역에서 OSM 의 `width` 태그는 **0.2%** 다. 폭 판정의 유일한 근거가 이것이다.
계산으로 만들 수 없으므로 **안 받으면 기능이 사라진다.**

- https://business.juso.go.kr → 신청서 작성 → 본인인증 → "도로명주소 전자지도"
- 시도/시군구 단위. **부산광역시** 로 신청
- 소관 기관 심사가 있다 → **빨리 넣을수록 좋다**
- 받을 것: `실폭도로`(폭 폴리곤), `도로구간`, `출입구`

### 3. 국토지리정보원 5m DEM — 지금 쓰는 30m 를 교체한다

- https://map.ngii.go.kr 국토정보플랫폼 → 로그인 → 수치표고모델
- 대용량 파일전송 S/W 를 깔라고 한다 (Windows)
- 받은 뒤 `npm run calibrate` 를 **다시 돌려 기준선을 다시 정한다**

### 4. Mapillary 토큰 — 조망 점수

- https://www.mapillary.com/developer → 앱 등록 → 토큰
- `.env` 의 `MAPILLARY_TOKEN`
- **먼저 부산 커버리지를 확인한다.** 크라우드소싱이라 지역 편차가 크다
- 비어 있으면 팀이 직접 촬영해서 올린다 — 직접 찍은 것은 제약이 없고,
  발표에서도 "직접 수집했습니다" 가 훨씬 강하다

### 5. 소상공인 상가(상권)정보 — 리뷰 대신 쓸 신호

- https://www.data.go.kr/data/15083033/fileData.do → 로그인 → CSV
- 부산만 약 20만 건. `data/raw/poi/` 에 둔다
- 여기서 **영업 지속기간**이 나온다 — 조작할 수 없는 신호

## 인증 없이 되는 것 (이미 받아둠)

| | 라이선스 | 명령 |
|---|---|---|
| Geofabrik 전국 OSM 285MB | ODbL 1.0 | `npm run collect:osm` |
| Overpass 대상 구역 8개 주제 | ODbL 1.0 | `npm run collect:overpass` |
| AWS Terrain Tiles 고도 | 공개 데이터 | `npm run collect:terrain` |

**ODbL** — 출처를 밝히고, 이 데이터로 만든 DB 를 배포하면 같은 라이선스로 열어야 하는
조건. 우리는 서비스만 하고 DB 를 배포하지 않으므로 **출처 표기**만 지키면 된다.
화면 어딘가에 `© OpenStreetMap contributors` 가 있어야 한다.

## 🔴 쓰면 안 되는 것

| | 왜 | 대신 |
|---|---|---|
| 네이버 지도 크롤링 | 약관상 응답 저장 금지 | OSM + 공공데이터 |
| 카카오 로드뷰 이미지 수집 | 카카오 공식 답변으로 금지 | Mapillary 또는 직접 촬영 |
| 네이버 리뷰 별점 | 리뷰 이벤트로 오염 — 신호가 아니다 | 영업 지속기간·유동인구·카드매출 |

발표에서 데이터 출처를 설명해야 한다. **크롤링이라고 말하는 순간 거기서 끝난다.**
