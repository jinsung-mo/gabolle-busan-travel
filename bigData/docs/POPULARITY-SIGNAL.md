## 1. 가져와도 되는가 — `robots.txt` 원문

`robots.txt`(**사이트가 자동 프로그램에게 "여기는 긁지 마라"를 적어 두는 파일**)를
먼저 읽었다. 원문은 [`findings/01-source-verdict.json`](../eval/popularity/findings/01-source-verdict.json) 에
그대로 들어 있다.

### 🔴 `m.place.naver.com` · `pcmap.place.naver.com` — 방문자/블로그 리뷰 수가 실제로 적혀 있는 화면

첫 요청(2026-09-07 21:5x KST)에 온 원문 전체다.

```
User-agent: *
Disallow: /
```

**예외가 한 줄도 없다.** 이 두 곳이 이 분석의 목표였다. 여기서 끝이다.

> 이 두 줄은 **처음 한 번 받았을 때** 적어 둔 것이다. 그 뒤로는 같은 주소가
> 429 만 돌려준다(아래). 그래서 `findings/01-source-verdict.json` 에는 이 본문이
> `null` 로 남아 있다 — 차단 화면 본문에 **우리 공인 IP 가 찍혀 나와서**
> 저장소에 남기지 않기 때문이다.

### `map.naver.com`

```
# BOT ACCESS FOR THE PURPOSES OF AI TRAINING AND RETRIEVAL-AUGMENTED GENERATION (RAG) IS STRICTLY PROHIBITED.
User-agent: GPTBot
Disallow: /
...
User-agent: ClaudeBot
Disallow: /
User-agent: Claude-SearchBot
Disallow: /
...
User-agent: *
Disallow: /
Allow: /$
Allow: /p/$
Sitemap: https://map.naver.com/sitemap.xml
```

우리를 **이름으로 지목해서** 막는다. 그리고 `*` 에게도 첫 화면(`/$`)만 열어 둔다 —
가게 상세는 닫혀 있다.

### `map.kakao.com` · `place.map.kakao.com` · `www.diningcode.com`

셋 다 같은 모양이다. 다이닝코드는 이렇게 적혀 있다.

```
User-agent: ClaudeBot
User-agent: Claude-Web
User-agent: anthropic-ai
Disallow: /
```

### 🔴 그리고 네이버 플레이스는 실제로 우리를 막았다

`robots.txt` **한 파일**을 읽으려던 요청 열 번 안쪽에서 이런 답이 왔다.

> **서비스 이용이 제한되었습니다.**
> 과도한 접근 요청으로 서비스 이용이 제한되었습니다. 잠시 후 다시 시도해주세요.
> IP: (우리 공인 IP — 가린다)(07/Sep/2026:22:13:56 +0900)

HTTP 429(**Too Many Requests** — "너무 자주 왔다"). 3초 간격·동시 요청 1개로도
이렇다. **여기서 멈췄다.** 우회는 이 작업의 범위가 아니다.

| 출처 | 판정 |
|---|---|
| `m.place.naver.com` · `pcmap.place.naver.com` | 🔴 전면 금지 + 실제 차단 |
| `map.naver.com` | 🔴 ClaudeBot 지목 금지 |
| `map.kakao.com` · `place.map.kakao.com` | 🔴 ClaudeBot 지목 금지 |
| `www.diningcode.com` | 🔴 ClaudeBot 지목 금지 |
| `openapi.naver.com` | 🔴 `Disallow: /` (API 는 아래) |

## 2. 공식 API 는 그 칸을 안 준다

화면이 막혔으니 공식 경로를 봤다. **네이버 지역 검색 API** 문서가 말하는 응답 칸은
이게 전부다.

```
title  link  category  description  telephone  address  roadAddress  mapx  mapy
```

**평점 없음. 방문자 리뷰 수 없음. 블로그 리뷰 수 없음. 가격대 없음.**
열쇠가 있어도 안 나온다 — 칸이 없기 때문이다.

한계가 두 개 더 있다.

- `display` **최댓값 5**, `start` **최댓값 1** — 한 질의에 5곳, 페이지 넘기기 없음
- `sort=comment` 는 *"업체 및 기관에 대한 카페, 블로그의 리뷰 개수순으로 내림차순 정렬"* —
  **순서는 주는데 개수는 안 준다**

카카오 로컬 API 도 같다(상호·분류·주소·좌표까지). 평점 칸이 없다.

> **자격증명**: 이 저장소에 있는 네이버 키는 **네이버 로그인용**이고 검색 API 는
> 인증을 거부했다(`errorCode 024`). 다만 위에서 봤듯 **키가 있어도 결론은 같다.**

## 4. 신호별 판별력 (AUC)

**AUC** — 정답 하나와 비정답 하나를 아무렇게나 집었을 때 신호가 정답 쪽을 더 크게
매길 확률. **0.5 가 동전 던지기.** `p` 는 *"신호가 아무 힘도 없는데 우연히 이만큼
갈렸을 확률"* 이다.

조정용 정답 111곳 vs 업종 맞춘 무작위 350곳.

| 신호 | AUC | p | 판정 |
|---|---|---|---|
| 가장 가까운 역까지 거리 | 0.500 | 0.996 | 아무 힘도 없다 |
| 500m 안 역 승하차 합 | 0.496 | 0.884 | 아무 힘도 없다 |
| 가장 가까운 역의 승하차 | 0.543 | 0.169 | 동전과 구별 안 됨 |
| **걸어서 닿는 유동인구** (3km 중력합) | **0.557** | 0.070 | 동전과 구별 안 됨 |
| 🔴 **해운대구·수영구인가** | **0.639** | **<0.0001** | **처음으로 유의하다** |
| *(견줄 기준)* 라운드3 최고 — 맛집 골목 밀집 | 0.497 | — | |
| *(견줄 기준)* 라운드3 — 대중교통 근접 | 0.481 | — | |

> 🔴 **평점·방문자 리뷰 수·블로그 리뷰 수·방문자/블로그 비율·가격대의 AUC 는 이 표에
> 없다. 못 얻었기 때문이다. 비워 둔다 — 그럴듯하게 채우지 않는다.**

> 🔴 **유동인구는 방문자 리뷰 수의 대리 지표지 같은 것이 아니다.** 역 승하차는
> "그 가게에 간 사람"이 아니라 "그 동네를 지난 사람"이다.

> 🔴 **해운대·수영은 조정용 표를 보고 고른 구다.** 그래서 이 0.639 는 "고른 것"이지
> "확인한 것"이 아니다. 확인은 **판정용 47곳**으로 해야 하고, 이 분석은 그것을 열지 않았다.

## 5. 핵심 가설 — "사람들이 많이 가는 곳이 곧 현지인의 맛집인가"

### 답: **아니다.**

걸어서 닿는 유동인구가 가장 좋은 유동인구 신호였는데도 **AUC 0.557, p=0.07** 이다.
동전 던지기와 통계적으로 구별되지 않는다. 라운드3 최고치(0.497)보다는 낫지만,
**"사람이 지나는 길목"으로 맛집을 찾을 수는 없다.**

방문자 리뷰 수 자체는 못 재 봤으므로, 정확히 말하면 이렇다 —
**동네 단위 유동인구로는 안 된다는 것이 실측됐고, 가게 단위 방문 흔적은 아직 모른다.**

### 그리고 더 중요한 답 — **"현지인의 맛집"은 "전문가의 맛집"과 다른 집이다**

정답지 셋은 서로 독립이다. 블로그100 은 작성자가 *"미쉐린가이드 블루리본 부산의맛 등
평가기관의 평가에 전혀 신경쓰지 않은 순수 부산 현지인으로서 솔직한 추천"* 이라고
밝힌 개인 목록이다.

| | |
|---|---|
| 전문가 표 (미쉐린 ∪ 블루리본) | 105곳 |
| 현지인 표 (블로그100) | 76곳 |
| **둘 다** | **23곳** |
| 현지인이 고른 집이 전문가 목록에도 있을 확률 | **30.3%** |
| 아무 식당이나 전문가 목록에 있을 확률 | 0.195% |
| 배수 | 155배 |
| 자카드(합집합 중 교집합) | **14.6%** |

우연보다 155배 겹치니 **완전히 다른 것을 보는 것은 아니다.** 하지만
**현지인이 고른 집의 70%를 전문가는 모른다.**

## 6. 무엇이 맛집을 만드는가

### 🔴 업종은 같게 고르고, 가게는 다르게 고른다

두 목록이 **업종을 고르는 방식**은 **93.9%** 같다. 그런데 **실제로 고른 가게**는
**14.6%** 만 같다.

| 업종 | 전문가 105곳 | 현지인 76곳 |
|---|---|---|
| 백반/한정식 | 19곳 (0.9배) | 14곳 (0.9배) |
| 경양식 | 15곳 (5.7배) | 10곳 (5.2배) |
| 일식 회/초밥 | 13곳 (5.0배) | 9곳 (4.8배) |
| 돼지고기 구이/찜 | 11곳 (1.6배) | 10곳 (2.0배) |
| 횟집 | 9곳 (2.4배) | 7곳 (2.5배) |

**이것이 신호 18개가 전부 실패한 이유다.** 우리가 가진 공개 데이터는 전부
*"무엇을 파는가 · 어디에 있는가"* 만 말한다. 그런데 맛집을 가르는 것은
**같은 업종·같은 동네 안에서 어느 집인가**다. 그 칸이 우리 데이터에 **없다.**
없는 칸으로는 어떤 모델도 못 푼다.

### 업종 쏠림 (정답 158곳 vs 부산 음식 53,716곳)

| 업종 | 정답 | 배수 | p |
|---|---|---|---|
| 경양식 | 22곳 | **5.5배** | 1.2e-10 |
| 베트남식 전문 | 5곳 | **5.8배** | 1.9e-3 |
| 일식 회/초밥 | 18곳 | **4.6배** | 1.1e-7 |
| 횟집 | 13곳 | 2.3배 | 5.5e-3 |
| 돼지고기 구이/찜 | 19곳 | 1.8배 | 9.0e-3 |
| 백반/한정식 | 31곳 | **1.0배** | 0.56 |
| 카페 | 5곳 | **0.23배** | — |

- **가장 많은 업종(백반/한정식 31곳)이 가장 안 특별하다.** 부산에 원래 제일 많아서
  많이 뽑힌 것이지 쏠린 게 아니다. **개수를 세면 속는다. 배수를 봐야 한다**
- 부산 하면 회·돼지국밥이라는 통념 중 **회는 맞다**(4.6배·2.3배).
  돼지고기 구이/찜은 1.8배로 생각보다 약하다
- **경양식이 1위(5.5배)** 라는 것은 뜻밖이다. 다만 이건 정답지가 미쉐린·블루리본 쪽으로
  기운 결과일 수 있다 — 세 목록 어디에서도 5배 안팎이라 목록 편향만은 아니다
- **카페는 0.23배.** 맛집 목록은 카페를 맛집으로 안 친다

### 자리 — 해운대·수영에 반이 있다

| 목록 | 곳 | 해운대+수영 | 배수 |
|---|---|---|---|
| 미쉐린 | 34곳 | **73.5%** | 4.40배 |
| 블루리본 | 78곳 | 47.4% | 2.84배 |
| 블로그100 (현지인) | 76곳 | 46.1% | 2.76배 |
| 부산 전체 | 53,716곳 | 16.7% | 1.00배 |

블루리본 부산 목록은 **시티투어버스 6개 테마**에서 옮겨 온 것이라, 해운대 쏠림이
*"버스가 해운대를 지난다"* 를 재는 것일 수 있었다. 그래서 버스와 무관한
**현지인 목록**에서 따로 봤더니 **거기서도 2.76배**다. **착시가 아니다.**

### 가격 — 부산 맛집은 비싼 집이 아니다

미쉐린이 매긴 가격대(부산 34곳): **₩ 21곳 · ₩₩ 8곳 · ₩₩₩ 5곳.**
가장 싼 등급이 **62%** 다. 블루리본도 리본 1개가 62곳, 2개가 15곳, 3개는 0곳이다.

### 오래 버틴 것과 맛있는 것은 거의 무관하다

백년가게(**30년 넘게 이어 온 점포를 정부가 인증한 것**) 부산 27곳 중,
맛 정답지에도 있는 곳은 **1곳뿐**이다.

## 7. 그래서 우리 기준은 무엇이 되어야 하나

1. **평점·리뷰 수를 서비스 설명에서 뺀다.** 합법적으로 얻을 경로가 없다 (S15P21E201-97 의 판단 근거)
2. **"인기"를 기준으로 삼지 않는다.** 유동인구는 맛집을 못 가른다 (0.557, p=0.07)
3. **업종과 자리는 후보를 좁히는 데만 쓴다.** 경양식·회·해운대/수영은 실제로 쏠려 있지만,
   그것으로 가게를 고를 수는 없다 — 같은 업종·같은 동네 안에서 갈리기 때문이다
4. 🔴 **가게 단위로 사람을 가르는 칸을 우리가 직접 만들어야 한다.**
   공개 데이터에는 그 칸이 없다는 것이 오늘로 다섯 번째 확인됐다.
   에픽 S15P21E201-706 의 세 질문·짝 비교 설문·암묵 피드백이 그 칸을 만드는 일이다
5. **"현지인의 맛집"을 목표로 삼는다면 미쉐린·블루리본을 정답지로 쓰면 안 된다.**
   현지인 목록과 30%밖에 안 겹친다. 어느 쪽을 쫓을지는 **제품의 결정**이다

## 8. 못 한 것과 그 이유

| 못 한 것 | 이유 |
|---|---|
| 평점 · 방문자 리뷰 수 · 블로그 리뷰 수 수집 | `robots.txt` 전면 금지 + 실제 IP 차단 (1절) |

| 카카오·구글로 우회 | 카카오도 같은 금지. 구글 Places 는 키가 없다 |
