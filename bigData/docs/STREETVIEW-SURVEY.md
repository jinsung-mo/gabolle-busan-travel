> 금지이고, Mapillary 는 라이선스가 열려 있지만 **장소 앞에 사진이 없다(3%)**.

> **② 🔴 그리고 라이선스가 열려도 그것만으로는 못 쓴다.** 사진을 보고 판정한 값은

## 2. 국내 둘 — 이미지를 주는 창구가 없다

**네이버**: NAVER Cloud Maps 의 REST API 는 **6종뿐**이다 — Dynamic Map · Static Map ·
Geocoding · Reverse Geocoding · Directions 5 · Directions 15. **거리뷰가 없다.**
거리뷰는 JS 지도에 얹는 레이어로만 제공된다.

**카카오**: 로드뷰는 `kakao.maps.Roadview` — **화면에 그리는 JS 도구**다. 정적 이미지 API 가
문서에 없다. FAQ 는 *「로컬 API 응답 결과 데이터는 별도 저장하여 사용할 수 없음」*.

🔴 **카카오는 「금지 확인」이 아니라 「허용 근거 없음」이다.** 개발자 포럼에 *「로드뷰 이미지
활용」* 질문이 여러 건 있는데 **공식 답변이 판단을 안 주고 외부 안내 링크로 넘긴다.** 그
링크를 열면 **로고(상표) 표기 규정만** 있고 이미지 가공 정책은 없다. 정확히 하려면
`with.kakao.com/map` 으로 **사람이 문의해야** 한다.

## 3. 구글 — 주기는 하는데 저장이 금지다

> *"Content pre-fetching, indexing, storing, or caching is generally prohibited"*
> — 파노라마 ID **하나만** 예외라 무기한 저장 가능

그리고 Maps Content 로 머신러닝 모델을 **`train, test, validate or fine-tune`** 하는 것이 금지다.

⚠️ **구분해서 적는다.** 금지가 확인된 것은 **⑴ 이미지 저장 ⑵ 모델 학습**이다.
**이미지를 모델에 넣어 판정만 하는 것(추론)** 은 읽은 조항에 **명시가 없다** — 허용도 금지도
아닌 **확인 못 함**이고, 저장 금지에 걸리는지는 **법무 판단 영역**이다.

**비용은 막는 요인이 아니었다.** Static Street View SKU `9BD0-A2EE-44C3` —
**월 10,000회 무료**, 이후 $7.00/1,000. 2,600곳 × 4방향 = 10,400회면 **$2.80** 이다.
**막는 것은 돈이 아니라 약관이다.**

## 🔴 4. Mapillary — 라이선스는 통과, 커버리지에서 막힌다

거리 사진을 공개 라이선스로 여는 곳이라 **앞의 셋이 막힌 자리를 비켜 간다.**

### 라이선스 — 구글과 정반대다

약관 12절, 상업적 용도로 허용되는 것:
> *"improvement, **training**, and development of products, services, maps, studies,
> platforms, websites, applications, software, **algorithms**, **datasets**, solutions,
> or technologies"*

**구글이 콕 집어 금지한 그 단어(`training`)가 Mapillary 의 허용 목록에 있다.**
사용자 사진은 3절(2)에 따라 **CC BY-SA 4.0** 이다. 의무는 **저작자 표시** —
*"you must attribute the image(s) by visibly displaying the Mapillary logo and linking back"*.

⚠️ **법무 판단이 필요한 것 둘** (엔지니어가 답할 자리가 아니다):
1. 5절이 *"Copy, reproduce, distribute … the **Mapillary Services**"* 를 금지하는데 3절(2)은
   **사용자 사진**이 CC BY-SA 라고 한다. **플랫폼과 사진의 라이선스가 다른 것**으로 읽히지만
   확실하지 않다
2. **CC BY-SA 는 동일조건변경허락(share-alike)** 이다. 사진에서 뽑은 판정값이 「2차적 저작물」
   인지 — 사실은 저작권 대상이 아니니 아닐 것 같지만 단정할 수 없다

### 🔴 부산 커버리지 — 여기서 막힌다

표본 30곳(관광공사 15 + 상가 15)에 대해 **사진은 안 받고 위치만** 물었다 (2026-09-17).

```
반경  30m 안에 사진이 있는 곳   1/30곳 ( 3%) · 사진  18장
반경 100m 안에 사진이 있는 곳   6/30곳 (20%) · 사진 172장
반경 300m 안에 사진이 있는 곳  13/30곳 (43%) · 사진 717장

촬영 연도  2023년 334장 · 2025년 258장 · 2024년 31장 · 2026년 42장
```

**부산에 사진이 없는 것은 아니다** — 300m 로 넓히면 43% 이고 최근 것도 많다.
**큰길 위에는 있다.** 그런데 **장소 앞(30m)에는 3% 뿐이다.**

🔴 **접근성은 출입구를 봐야 판정된다.** 계단 한 칸, 문턱 하나가 답을 가른다.
300m 밖 큰길 사진으로는 **그 가게 문 앞에 계단이 있는지 알 수 없다.**
30m 안에 사진이 있던 유일한 곳도 **해운대 그린레일웨이(산책로)** 였다 — 사람이 카메라를
들고 걷는 곳이지, 식당 문 앞이 아니다.

**3% 는 지금 우리가 가진 3.7% 보다도 낮다.**
