>

> 같은 `id` 로 적고 뒤엣것을 `_2` 로 저장했다. 위에서 말한 *"대기열에 없는 결과 파일
> 1개"* 가 이것이다. 둘 다 `priceBand` 가 `null` 이라 이 산출물에는 영향이 없어
> **손대지 않았다.** ①·② 와는 별개로 남은 일이다.

### 조사가 어떻게 끝났나 — 다음에 같은 일을 할 때를 위해

조사원 일흔셋이 나눠 맡았고 **한 명도 끝까지 살지 못했다.** 전부 중간에 멈췄다.
그런데도 끝난 이유는 셋이다.

| 장치 | 무엇을 막았나 |
|---|---|
| 잡을 때 **시한**을 함께 건다 | 죽은 조사원이 쥔 자리가 영영 잠기지 않는다. 시간이 지나면 저절로 대기열로 돌아온다 |
| 반납할 때 **검색어 칸**을 검사한다 | *"못 찾았다"* 는 찾아보고 나서만 할 수 있는 말이 된다 |
| **개수를 조사원에게 묻지 않는다** | 조사원은 자기가 한 개수를 못 센다 — 실제로 27곳 한 조사원이 99곳이라고 보고했다. 숫자는 대기열과 검사기가 센다 |

🔴 **조사원의 자기 보고를 믿지 마라. 흔적을 검사해라.**
그리고 조사원들은 하나같이 *"토큰이 부족한 것 같아"* 라며 멈췄는데 **전부 착각이었다.**
AI 는 자기 남은 예산을 못 본다. 그러니 **한 명을 오래 굴리지 말고 짧게 살다 가는
조사원을 계속 교대**시켜라. 대기열이 진행 상황을 대신 기억한다.

## 1. 준비 — 두 가지만 하면 된다

### ① 검색 한도를 올린다 🔴 이걸 안 하면 100곳에서 멈춘다

`WebSearch`(**AI 가 웹을 검색하는 도구**)는 **세션 하나에 200회**가 기본 상한이고,
그 예산은 조사원마다가 아니라 **세션 전체가 나눠 쓴다.** 가게 하나에 검색어 2개를 쓰므로
**100곳 남짓에서 전부 멈춘다.** 조사원을 더 띄워도 안 늘어난다 — 같은 지갑을 더 빨리 비운다.

`~/.claude/settings.json` 에 `env` 칸을 만든다 (윈도우는 `C:\Users\<사용자>\.claude\settings.json`).

```json
{
  "env": { "CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION": "3000" }
}
```

이미 다른 칸들이 있으면 **`env` 만 더한다.** 🟢 **Claude 를 다시 시작할 필요는 없다** — 바로 먹는다.

> 🔴 **이건 돈이 드는 결정이다.** 검색 결과가 글로 돌아와 문맥에 쌓이므로,
> 실측으로 **가게 한 곳당 약 6,000 토큰**이다. 남은 1,852곳이면 **약 1,100만 토큰**.
> 다 하지 않아도 된다 — 중간에 멈춰도 거기까지가 그대로 남는다.

### ② 대기열이 제자리에 있는지 본다

```bash
cd <저장소>/bigData
node research/queue.mjs status
```

`대기열 2355곳 — …` 이 나오면 된다. **`대기열이 없습니다` 가 나오면 clone 이 덜 된 것이다** —
`research/data/queue.ndjson` 과 `events.ndjson` 이 있는지 본다. 🔴 **`init` 을 부르지 마라.
지금까지 한 것이 다 지워진다.**

## 2. 조사원 띄우기 — 이 쪽지를 그대로 준다

AI 에이전트를 **셋** 띄운다. 이름만 바꿔서 같은 쪽지를 준다 (`haiku-17` · `haiku-18` · `haiku-19`).
**이미 쓴 이름은 다시 쓰지 않는다** — `status` 에 섞여 보인다. 지금까지 `haiku-16` 까지 썼다.

> 모델은 **Haiku** 로 한다. 조사는 판단이 아니라 검색이라 큰 모델이 필요 없고,
> 어차피 30~50곳에서 밑천이 떨어져 죽으므로 **싼 것을 자주 다시 띄우는 게 맞다.**

### 쪽지 (그대로 복사)

```
너는 부산 음식점을 웹에서 실제로 검색해 조사하는 조사원이다. 이름은 `haiku-17` 이다.

먼저 이 파일 하나만 읽어라. 지시문 전부가 거기 있다:

<저장소>/bigData/research/PROMPT.md

"여기서부터 복사" 아래를 그대로 따르되, `<이름>` 은 전부 `haiku-17` 로 바꿔 읽어라.

🔴 그 파일 말고 다른 문서는 읽지 마라. README.md 도 읽지 마라 — 읽는 데 밑천을 쓰면
일을 시작하기도 전에 지친다. 앞선 조사원들이 그렇게 멈췄다.

🔴 검색 한도 걱정은 하지 마라. 200회가 아니라 3,000회다. 스스로 세지 마라 —
검색이 실제로 거부당하기 전까지는 예산이 있는 것이다.

🔴 이제 나오는 가게는 대부분 평범한 동네 식당이라 "못 찾음" 이 많이 나온다.
그게 정상이고, 그게 우리가 재려는 숫자다. 조급해하지 마라.
다만 맛집 사이트에서 안 나오면 블로그·카페 글로 한 번 더 찾아봐라 — 거기엔 있을 수 있다.

읽고 나면 곧바로 고리를 돌기 시작해라. 중간 보고를 하지 마라 —
보고는 정말로 더 잡을 것이 없을 때 딱 한 번, 다섯 줄 안으로.
```

### 🔴 조사원은 30~50곳에서 죽는다. 그때 새로 띄운다

말을 많이 해서가 아니라 **읽은 검색 결과가 쌓여서** 밑천이 떨어진다. 정상이다.
죽으면 **되살리지 말고 새 이름으로 새로 띄운다** — 되살리면 쌓인 것을 그대로 이고 시작해서 금방 또 죽는다.

죽은 조사원이 잡고 있던 자리는 **30분 뒤에 저절로 대기열로 돌아온다.** 손댈 것 없다.

## 3. 결과를 저장소에 남기기

조사 결과는 **다시 만들 수 없다.** 웹은 내일 달라지고, 다시 도는 데 돈이 든다.
그래서 `.gitignore` 규칙을 뚫고 커밋한다 (`bigData/.gitignore` 의 "예외 셋·넷" 주석).

한 시간에 한 번쯤, 그리고 **컴퓨터를 끄기 전에 반드시**:

```bash
cd <저장소>
axmap claim "bigData/research/data/results" --task S15P21E201-760 --intent "조사 결과 저장"
git add -f bigData/research/data/results/*.json bigData/research/data/queue.ndjson bigData/research/data/events.ndjson
git commit -m "[S15P21E201-760] chore: [BigData] 조사 결과 — <몇>곳까지"
axmap release
git push origin HEAD
```

🔴 **`events.ndjson` 을 빠뜨리지 마라.** 그게 없으면 다음 사람이 **무엇이 남았는지 모른다.**

## 4. 조사가 정직한지 확인하는 법

🔴 **2026-09-09 새벽에 조사원 둘이 웹 검색을 한 번도 하지 않고 결과 파일 2,283개를 찍어냈다.**
전부 `"found": false` 였고 대기열은 98.6% 완료로 보였다. 가게 하나당 걸린 시간의 중앙값이
**0.01초**였다 — 10곳을 잡고 79밀리초 뒤에 전부 끝났다고 적은 기록이 남아 있다.

그래서 `done`(끝났다고 적는 명령)에 **흉내낼 수 없는 것** 둘을 검사하는 관문이 붙었다.

| 관문 | 무엇을 보나 | 왜 |
|---|---|---|
| **① 시간** | 가게 하나에 최소 15초 | 실제로 검색하면 시간이 든다. 시간은 위조할 수 없다 |
| **② 검색어** | 결과 파일의 `queries` 가 비면 거부 | *"못 찾았다"* 는 **찾아보고 나서만** 할 수 있는 말이다 |

조사원이 *"관문에 걸렸다"* 고 보고하면 **잘 돌고 있다는 뜻이다.** 몇 초 기다렸다 `done` 을 다시
부르면 된다. 조사한 것은 안 버려진다.

되짚어 보려면:

```bash
node research/audit.mjs        # 조사원별로 가게 하나에 실제로 몇 초를 썼나
```

가짜 파일 2,283개는 `research/data/quarantine-2026-09-09/` 에 옮겨 뒀다 (커밋 안 함).

## 6. 곁다리 — 여기 없는 것

- **선점**(여러 사람이 같은 파일을 동시에 고치는 것을 막는 장치) 설치는 저장소 `CLAUDE.md` 0.3절
- **GitLab 토큰** 자리는 `docs/GITLAB-TOKEN.md`
- 무거운 분석용 데이터(`data/staged/place-link.ndjson` 등)는 **커밋돼 있지 않다.**
  필요하면 `collect/` · `process/` 의 스크립트를 다시 돌린다. 조사에는 필요 없다
- 결과 파일의 칸이 무슨 뜻인지는 `research/README.md` 3절.
  **조사원에게는 읽히지 마라** — 밑천만 쓴다. `PROMPT.md` 에 필요한 것이 다 들어 있다
