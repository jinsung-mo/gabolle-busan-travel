## 1. 어떻게 맡나

1. 아래 표에서 **아직 아무도 안 맡은 번호**를 하나 고른다 (`axmap status` 로 지금
   누가 어느 번호를 잡고 있는지 한 번 더 확인 — 이 표는 갱신이 늦을 수 있다).
2. 선점한다 (파일이 실제로 없어도 axMap 은 받아 준다 — 경고만 뜬다):
   ```bash
   axmap claim "bigData/research/data/combined-results/chunk-<번호>" \
     --task S15P21E201-1414 --intent "가격조사 청크<번호> (<인덱스범위>)" --ttl 30m
   ```
3. 돌린다 (`bigData/` 에서):
   ```bash
   node research/price-queue.mjs --chunk <번호>
   ```
   이미 끝난 곳은 청크 안에서도 자동으로 건너뛴다. `agy` 가 이 컴퓨터에 없으면
   먼저 설치·로그인해야 한다 — 절차는 janghyojoon 에게 문의(쪽지로 온 요청 있음).
4. **Gemini 5시간 할당량이 막히면** 다른 모델로 이어간다 (할당량이 따로 논다):
   ```bash
   node research/price-queue.mjs --chunk <번호> --model claude-sonnet-4-6
   ```
5. 끝나면 결과를 커밋해서 올린다 (`research/data/combined-results/*.json` 은
   `.gitignore` 예외로 커밋 대상이다):
   ```bash
   git add -f bigData/research/data/combined-results/*.json
   git commit -m "[S15P21E201-1414] chore: [Data] 가격 조사 청크 <번호> 결과 (<몇> 곳)"
   axmap release
   git push origin bigData/dev
   ```
   🔴 **표는 이 조사와 무관하다** — 이건 governance 정족수 대상이 아니라(`bigData/dev`
   로 가는 커밋), 바로 push 하면 된다.
