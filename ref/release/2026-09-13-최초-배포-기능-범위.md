# 최초 배포 기능 범위

2026-09-13 기준. 브랜치 코드(`back/dev`·`front/dev`)와 운영 서버를 직접 대조해서 정리했다.
기획서나 흐름도가 아니라 **지금 실제로 돌아가는 것**이 기준이다.

막고 있는 것은 대부분 코드가 아니라 자료다. 화면 61개 중 서버까지 이어져 실제로 값이
나오는 것과, 화면은 있는데 보여줄 자료가 없는 것이 갈린다.

## 넣는 것

| 기능 | 확인한 근거 |
|---|---|
| 로그인·가입 (구글·네이버·카카오·애플) | 네 곳 다 실기기 확인. 애플만 남아 있던 오류는 `S15P21E201-893` 으로 고쳐 배포됨 |
| 장소 검색 | 운영에서 2,355곳 조회됨 |
| 출발지 검색 | `GET /api/v1/origins` 정상 |
| 여행 만들기 · 일정 생성 · 일정 보기 · 수정 | 화면과 서버가 양쪽 다 붙어 있음. 단 아래 **취향 갈래** 항목을 함께 볼 것 |
| 길찾기 · 경로 상세 | `GET /api/v1/routes/directions` 정상 |
| 택시 카드 · 현장 말하기 | 서버 조회와 기기 기능(음성·복사·지도 열기)으로 완결됨 |
| 여행 기록(스토리) 피드 · 작성 · 공동 작성 | 서버 경로 전부 있음 |
| 신고 접수와 운영자 검토 | 서버·화면 모두 있음 |
| 공유 링크 · 동행자 초대 | 서버·화면 모두 있음 |

## 빼거나 감추는 것

### 서버가 없다

**지금 갈 곳** (`/now`). 화면이 부르는 `POST /api/v1/recommendations/now` 가 운영에서 404 다.
화면은 404 를 받으면 오류를 띄우지 않고 예시 후보 세 곳에 "샘플" 배지를 붙여 보여준다 —
깨지지는 않지만 진짜 값이 아니다. API 를 붙이는 것 자체는 작은 일인데, 붙여도 지금 자료로는
식당만 나오고 이 화면의 핵심 값인 "영업 종료까지 남은 시간" 이 대부분 비어 나간다.

### 자료가 없다

로컬 탐색 여덟 갈래 중 여섯이 0건이다. 운영 실측이다.

| 갈래 | 장소 | 갈래 | 장소 |
|---|---|---|---|
| 음식 | 2,355 | 축제 | 0 |
| 카페·힐링 | 26 | 야시장 | 0 |
| | | 전통시장 | 0 |
| | | 액티비티 | 0 |
| | | 산책 | 0 |
| | | 자연 | 0 |
| | | 야경 | 0 |
| | | 기념품샵 | 0 |

- **축제 화면** — `GET /api/v1/festivals` 가 0건. 축제 일정을 넣는 프로그램이 저장소에 없다(`S15P21E201-895`)
- **기념품샵 화면** — 해당 갈래 0건이라 빈 목록
- **로컬 탐색** — 갈래를 지우지 말고 0건인 것만 목록에서 빼면 음식 탐색은 그대로 쓸 수 있다

### 취향 갈래 — 고르면 반드시 실패하는 선택지

추천 엔진은 앱이 보낸 갈래 코드를 장소의 갈래 값과 글자 그대로 비교한다. 운영에 적재된
장소가 음식뿐이라 나머지를 고르면 후보가 0 이 되고 일정 생성이 실패한다. 후보가 모자랄 때
조건을 완화하지 않는 것이 엔진 규칙이라 다시 눌러도 안 된다.

| 취향 갈래 | 후보 (광안리 반경 15km) |
|---|---|
| 맛집 & 먹거리 | 2,104 |
| 바다 & 해변 · 도심 탐험 · 카페 & 힐링 · 문화 & 사찰 · 자연 & 산책 | 각 0 |

맛집을 고르거나 취향을 건너뛰면 정상으로 일정이 나온다. 서버에 `GET /api/v1/places/categories`
를 열어 뒀으므로(`S15P21E201-896`) 화면이 그 응답에 있는 갈래만 보여 주면 이 실패 경로가
사라진다. 갈래를 코드에서 지우지 말고 걸러만 둔다 — 적재가 돌면 저절로 다시 나타난다.

### 화면은 있는데 알맹이가 없다

- **현장 도구** — 메뉴판 촬영 번역과 음성 통역은 업체가 안 정해져서 눌러도 이동하지 않는다
- **방문 인증** — "위치 기반 방문 인증 완료" 배지가 고정 값이다. 실제 위치 판정이 없다
- **여행 기록·회고** — 통계와 타임라인이 전부 고정 값이다
- **부슐랭 리스트** — 폰 안에만 저장된다. 앱을 지우거나 다른 기기로 옮기면 사라진다

## 서버는 있는데 화면이 안 부르는 것

여기는 화면 쪽만 이으면 되는 자리라 적어 둔다 — 번역 중계, 방문 인증, 홈·커뮤니티 피드,
후보 장소, 숙소 조회, 갈래 열람 기록.

## 확인 방법

익명 세션을 받아 공개 조회를 부르면 누구나 같은 숫자를 다시 잴 수 있다.

```bash
TOKEN=$(curl -s -X POST https://j15e201.p.ssafy.io/api/v1/auth/anonymous \
  -H 'Content-Type: application/json' -d '{"deviceId":"scope-check"}' \
  | python -c 'import sys,json;print(json.load(sys.stdin)["data"]["sessionToken"])')

# 로컬 탐색 갈래별 장소 수
curl -s -H "X-Session-Token: $TOKEN" https://j15e201.p.ssafy.io/api/v1/places/facets

# 취향 갈래별 후보 수 (categories 를 바꿔 가며)
curl -s -X POST https://j15e201.p.ssafy.io/api/v1/places/candidates \
  -H 'Content-Type: application/json' -H "X-Session-Token: $TOKEN" \
  -d '{"center":{"lat":35.1585,"lng":129.1598},"radiusM":15000,
       "categories":["SEA_BEACH"],"limit":50000}'

# 적재된 장소 갈래와 수
curl -s -H "X-Session-Token: $TOKEN" https://j15e201.p.ssafy.io/api/v1/places/categories
```

## 아직 안 잰 것

- 로그인한 사용자로 일정 생성을 끝까지 돌려 보지 않았다. 익명 세션으로는 생성이 막혀 있다
- 날씨 조회는 익명 세션으로 확인할 수 없어 응답을 못 봤다
- 실기기에서의 화면 동작은 이 문서의 근거가 아니다 — 서버 응답과 저장소 코드만 봤다
