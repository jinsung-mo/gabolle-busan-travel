# 최초 배포 기능 범위

2026-09-13. 브랜치 코드와 운영 서버를 직접 대조했다. 기획서가 아니라 지금 도는 것이 기준이다.

관광공사 장소 적재를 이날 돌렸다. 아래 숫자는 적재 뒤 운영에서 실제로 받은 값이다.

## 넣는다

로그인·가입(구글·네이버·카카오·애플) · 장소 검색 · 여행 만들기와 일정 생성·수정 · 길찾기 · 택시 카드와 현장 말하기 · 여행 기록 피드와 작성 · 신고와 운영자 검토 · 공유 링크와 동행자 초대.

여기에 적재로 살아난 것을 더한다.

## 켜되 빈 자리를 걸러야 한다

목록을 지우지 말고 0인 항목만 화면에서 뺀다. 자료가 들어오면 그대로 돌아온다.

- **취향 갈래** — 카페 & 힐링이 아직 0곳이다. 0곳인 갈래를 고르면 일정 생성이 실패하고 다시 눌러도 안 되므로 **반드시 걸러야 한다.** `GET /api/v1/places/categories` 가 지금 장소가 있는 갈래를 내준다
- **로컬 탐색** — 야시장과 기념품샵이 0건이다. 그 둘만 목록에서 뺀다
- **추천 개인화** — 현지도·조용함·그늘·경사·관광객비율·분위기 여섯 축이 모두 비어 있다. 추천은 돌지만 이 축들은 점수에 반영되지 않는다. 화면에 드러나는 것은 없다

## 이번엔 뺀다

| 기능 | 왜 |
|---|---|
| 지금 갈 곳 | 부르는 서버 주소가 없다(404). 지금은 샘플 세 곳을 보여준다 |
| 축제 기간으로 찾기 | 가진 축제 기간 14건이 전부 2026-02-22 이전에 끝났다. 새로 수집해야 한다 |
| 기념품샵 | 해당 갈래 장소가 0곳이다 |
| 메뉴판 번역 · 음성 통역 | 업체 미정이라 눌러도 안 넘어간다 |
| 방문 인증 | 완료 배지가 고정 값이다. 위치 판정이 없다 |
| 여행 회고 통계 | 숫자와 타임라인이 고정 값이다 |
| 부슐랭 리스트 | 폰 안에만 저장돼 앱을 지우면 사라진다 |

축제는 두 가지가 다르다. **로컬 탐색의 축제 갈래는 켠다** — 축제 장소 14곳이 태그돼 있다. 빠지는 것은 **기간으로 찾는 화면**이고, 그건 장소가 아니라 일정 자료가 필요하다.

## 서버는 있는데 화면이 안 부른다

나중에 이을 때 찾기 쉽게 적어 둔다 — 번역 중계 · 방문 인증 · 홈/커뮤니티 피드 · 후보 장소 · 숙소 조회 · 갈래 열람 기록.

## 숫자를 다시 재려면

익명 세션을 받아 공개 조회를 부르면 누구나 같은 값을 얻는다.

```bash
TOKEN=$(curl -s -X POST https://j15e201.p.ssafy.io/api/v1/auth/anonymous \
  -H 'Content-Type: application/json' -d '{"deviceId":"scope-check"}' \
  | python -c 'import sys,json;print(json.load(sys.stdin)["data"]["sessionToken"])')

curl -s -H "X-Session-Token: $TOKEN" https://j15e201.p.ssafy.io/api/v1/places/categories
curl -s -H "X-Session-Token: $TOKEN" https://j15e201.p.ssafy.io/api/v1/places/facets
```

## 안 잰 것

로그인한 사용자로 일정 생성을 끝까지 돌려 보지 않았다(익명 세션으로는 막혀 있다). 날씨 응답도 못 봤다. 실기기 동작은 이 문서의 근거가 아니다 — 서버 응답과 저장소 코드만 봤다.

적재 절차(`backend/docs/PLACE-DATA-LOAD.md`)는 기동할 때 `GABOLLE_JWT_SECRET` 을 요구하는 검사가 뒤에 생겨 그대로 따라 하면 첫 적재가 실패한다. 적재기는 토큰을 만들지 않으므로 임시값을 주면 된다. 문서 반영은 따로 한다.
