브랜치: $ARGUMENTS

## 🔴 이 명령이 슬래시 명령인 이유

**표는 "최소 두 사람이 봤다" 는 증거다.** `governance/policy.json` 이 정족수를
2로 못 박은 이유가 그것뿐이다 — *"한 사람이 올리고 한 사람이 눌러 준다"* 를 막는 것.

그래서 이것은 **MCP 도구가 아니다.** 도구면 에이전트가 스스로 부를 수 있고,
그러면 에이전트 둘이 사람 둘의 이름으로 정족수를 채운다. 게이트는 통과라고
말하는데 **아무도 안 본 상태**가 된다. 그리고 그렇게 통과하는 것이 `governance/`
와 `.gitlab-ci.yml` — 규칙 그 자체다.

**사람이 직접 쳐야 실행되는 자리에 둔다. 그게 이 명령의 전부다.**

## 순서 — 이 순서를 지킨다

### 1. 브랜치를 정한다

인자가 비었으면 `/ax-ballot` 을 대신 돌려 무엇이 표를 기다리는지 보여주고 **멈춘다.**
아무거나 골라서 던지지 않는다.

### 2. 먼저 보여준다 — 아직 던지지 않는다

```bash
git fetch origin --quiet
git diff --stat origin/main origin/<브랜치>
git log --format='%h %an <%ae>%n  %s' origin/main..origin/<브랜치>
npx -y axmap-cli@latest gate --source <브랜치> --target origin/main
```

사람에게 이것을 정리해서 보여준다.

- **무엇이 바뀌나** — 파일과 줄 수. 3줄 넘으면 실제 diff 도 보여준다
- **누가 올렸나** — 커밋 저자
- **지금 몇 표인가** — 그리고 몇 장이 더 필요한가
- **내가 던질 수 있나** — 내 이메일이 소스 브랜치 커밋의 저자에 있으면 못 던진다
  (자기 표 배제). 그 경우 **여기서 멈추고** 왜 못 던지는지 말한다.
  🔴 **딱 하나 예외가 있다** — 아래

### 🔴 아무도 못 던지는 상태면 자기 표가 풀린다 (`axmap-cli@1.2.0` 부터)

자기 표 배제를 적용하고 남은 사람이 정족수보다 **적으면**, 게이트가 그 판정
하나에 한해 배제를 **해제한다.** 저자 본인의 표도 센다.

오래 쌓는 `<파트>/dev` 브랜치에서는 시간이 갈수록 커밋한 사람이 늘어 던질 수
있는 사람이 0 으로 수렴한다. 그건 "표가 모자라다" 가 아니라 **표를 더 모아도 안
풀리는 교착**이라, 거기서 멈추면 사람이 영영 못 여는 것을 계속 기다리게 된다.

**`gate` 출력에 이 줄이 보이면 멈추지 않는다.**

```
🔴 G1(자기 표 배제)이 해제된 판정입니다 — 유효 투표권자 0명 < 정족수 2.
```

그 줄을 **사람에게 그대로 보여주고** 3번(물어보기)으로 간다. 예외였다는 사실을
사람이 알고 던져야 한다. 정족수 숫자는 그대로이고, G3(표는 커밋에 묶인다)·
G4(같은 사람의 두 번째 표)도 그대로 도는 것을 함께 말해준다.

### 3. 🔴 사람에게 물어본다

**"이대로 찬성표를 던질까요?"** 를 묻고 **답을 기다린다.** 자동으로 넘어가지 않는다.
사람이 내용을 읽지 않았으면 이 명령은 아무것도 지키지 못한 것이다.

### 4. 던진다

```bash
npx -y axmap-cli@latest vote \
  --branch <브랜치> \
  --sha $(git rev-parse origin/<브랜치>) \
  --vote approve \
  --target origin/main \
  --note "<사람이 확인한 내용을 한 줄로>"
```

**두 인자는 반드시 이렇게 준다.**

| 인자 | 생략하면 |
|---|---|
| `--sha $(git rev-parse origin/<브랜치>)` | 로컬에 그 브랜치 사본이 없으면 실패한다 |
| `--target origin/main` | 판정 프로그램이 **낡은 로컬 `main`** 을 본다. 알려진 버그다 |
| `--source` 에 `origin/` **안 붙임** | 표를 0장으로 센다. 아래 경고 |

> 🔴 **`--source` 에는 `origin/` 을 붙이지 않는다. 붙이면 표가 0장으로 세어진다.**
>
> 표 파일은 `votes/<브랜치>/…` 에 쌓이는데, 게이트가 소스 이름을 **그대로** 경로에
> 넣는다. `origin/` 을 붙이면 `votes/origin/<브랜치>/…` 를 뒤지고 거기엔 아무것도 없다.
>
> **두 인자의 규칙이 서로 반대라서 특히 잘 틀린다** — `--target` 에는 붙여야 하고
> `--source` 에는 붙이면 안 된다. 사람은 둘에 같은 규칙을 적용한다.
>
> 실측 (같은 커밋 · 같은 표):
>
> ```
> --source origin/hotfix/… --target origin/main   →  표 0장 · 합의 미달 · 종료 코드 2
> --source hotfix/…        --target origin/main   →  표 2장 · 합의 충족 · 종료 코드 0
> ```
>
> 종료 코드가 **2**(= "사람이 아직 안 눌렀다, 정상 상태")로 나오는 것이 고약하다.
> 이미 다 모인 표를 없다고 하므로, 읽는 사람은 **이미 던진 사람에게 또 부탁하러 간다.**
> 통과가 잘못 나가지는 않지만 **정상 상태를 고장으로 보고한다.**

> 🟢 **판정 전에 표 브랜치를 받아 둔다.** 안 받아온 상태에서도 0장으로 나온다.
>
> ```bash
> git fetch origin refs/heads/axmap/votes:refs/remotes/origin/axmap/votes
> ```


### 5. 세어졌는지 확인한다

```bash
npx -y axmap-cli@latest gate --source <브랜치> --target origin/main
```

`유효 찬성` 이 하나 늘었는지 본다. 안 늘었으면 **성공했다고 말하지 않는다** —
판정문의 `무효` 목록에 이유가 적혀 있으니 그것을 그대로 전한다.

## 알려줘야 하는 것

정족수가 찼으면(`유효 찬성 N / 필요 N`) **브랜치를 올린 사람에게 알린다** —
"이제 MR 을 여시면 됩니다".

아직 모자라면 **누가 던질 수 있는지**를 말한다. 소스 브랜치에 커밋하지 않은
투표권자만 던질 수 있다.

## 🔴 마지막에 반드시 덧붙이는 경고

> **표는 커밋 하나에 묶인다.** 그 브랜치에 커밋이 하나라도 더 올라가면 —
> 오타 하나를 고치는 것이라도 — 앞서 모인 표가 전부 효력을 잃는다.
> 표를 다 모은 뒤에 내용을 몰래 바꾸는 것을 막으려고 그렇게 만들었다.
> 고칠 것이 보이면 **먼저 사람들에게 알리고**, 브랜치는 그대로 둔다.

## 반대할 때

반대는 `--vote reject` 다. 다만 **반대표는 정족수 계산에 들어가지 않는다** —
이 층은 "찬성이 몇 장인가" 만 센다. 판정문에 보이기만 한다.
그래서 **반대는 표보다 쪽지가 낫다** (`/ax-tell`). 반대하는 이유는 숫자가 아니라
글로 전해져야 상대가 고칠 수 있다.
