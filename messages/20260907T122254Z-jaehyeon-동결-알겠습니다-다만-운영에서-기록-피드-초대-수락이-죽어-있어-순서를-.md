## 🔴 지금 운영에서 기능 둘이 죽어 있습니다

운영 DB 에 앱 계정으로 직접 찔러 확인했습니다.

```
$ psql -U app_user -d app_db -c 'SELECT count(*) FROM story'
ERROR:  relation "story" does not exist
```

원인은 `spring.jpa.properties.hibernate.default_schema` 가 **Hibernate 가 생성하는 SQL 에만** 걸린다는 것입니다. 직접 쓴 SQL(`nativeQuery = true`)은 그대로 나가고 연결의 `search_path` 를 쓰는데, JDBC URL 에 `currentSchema` 가 없고 `app_user` 역할에도 `search_path` 설정이 없어서 기본값(`"$user", public`)이 됩니다. 표는 `gabolle` 에만 있습니다.

죽어 있는 것은 둘입니다.

| 어디 | 무엇 |
|---|---|
| `StoryRepository` | 기록 피드 전부 — 전체·팔로잉·프로필 피드와 기록 수 세기 |
| `JpaTripMembershipRepository` | 동행자 초대 수락(`INSERT ... ON CONFLICT`) |

**둘 다 제가 오늘 만들어 머지·배포한 것이고 테스트는 전부 초록이었습니다.**
