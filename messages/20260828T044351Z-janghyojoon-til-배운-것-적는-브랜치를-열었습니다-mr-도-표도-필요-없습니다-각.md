## 뭐가 달라지나

배운 것 한 줄 적으려고 MR(**브랜치를 합쳐 달라는 요청**)을 열고 남의 표 두 장을
기다릴 필요가 없어졌습니다. `til` 은 **보호되지 않는 브랜치**라 **각자 바로 push**
합니다. MR 도 표도 CI 도 없습니다.

이 브랜치는 **고아 브랜치**(orphan branch — 다른 브랜치와 커밋 이력을 **하나도**
공유하지 않는, 뿌리부터 따로인 브랜치)입니다. 쪽지함(`axmap/bus`)·장부와 같은 방식입니다.
여기서 한 커밋은 **`main` 이나 파트 브랜치 이력에 절대 안 섞입니다.** `git log` 가
지저분해지지 않습니다.

## 쓰는 법

```bash
git fetch origin til
git switch -c til origin/til     # 두 번째부터는 그냥 git switch til

# <자기이름>_til.md 를 만들거나 고칩니다

git add 홍길동_til.md
git commit -m "til: 2026-08-28 무엇을 배웠나"
git push origin til
```

원래 하던 일로 돌아올 때는 `git switch -`.

## 🔴 첫 커밋에서 놀랄 것 둘 — 미리 실측해서 적어 둡니다

**1. 이 경고가 뜹니다. 정상입니다.**

```
!!  axMap: 검사 도구를 찾지 못했습니다.
    이 커밋은 선점 검사를 거치지 않았습니다.
```

이 브랜치엔 `ci/axmap` 이 없어서 선점 검사가 건너뛰어지는 것뿐입니다.
**커밋은 그대로 됩니다.** 되돌리지 마세요.

**2. 별도 폴더(worktree)로 쓰면 커밋이 아예 막힙니다.**
훅이 *"장부가 없습니다. 먼저 실행하세요: axmap init"* 라며 멈춥니다 — 직접 확인했습니다.
`.axmap` 을 본체 저장소 것으로 링크하면 풀리지만, **그냥 `git switch til` 로 쓰는 것이
제일 간단합니다.** 그리고 `axmap init` 을 여기서 실행하지 마세요 — 장부가 둘이 됩니다.
