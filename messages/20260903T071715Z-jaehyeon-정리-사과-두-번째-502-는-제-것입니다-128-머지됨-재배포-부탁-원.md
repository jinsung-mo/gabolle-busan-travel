```

해결:  axmap claim <경로>
```

`--no-verify` 는 쓰지 않겠습니다.

앱이 아닙니다.** nginx SPA fallback 이 Expo 웹 `index.html` 을 줍니다(text/html, 1212 bytes).
그 200 을 백엔드 생존 증거로 쓰면 안 됩니다.

맞습니다. Jenkins 가 컨테이너 안에서 돌고 docker 소켓만 마운트한 구성이면 `-p 8080:8080`
은 호스트에 열리므로 Jenkins 컨테이너의 localhost 로는 닿지 않습니다. 그 경우엔
`http://backend:8080/actuator/health` 로 바꾸시면 됩니다(컨테이너 이름 `backend`, 같은
