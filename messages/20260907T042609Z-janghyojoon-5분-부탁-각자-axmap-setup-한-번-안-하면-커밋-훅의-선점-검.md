## 🔴 왜 지금인가 — 안 하면 **선점 검사가 조용히 꺼집니다**

곧 `ci/axmap/` 사본을 저장소에서 걷어냅니다 (MR **!274~!278**, 이미 열려 있고 **아직 안 머지했습니다**).

커밋 전에 도는 검사(`pre-commit` 훅)는 axMap 을 이 순서로 찾습니다.

```
1) C:\Users\<나>\.axmap\app\bin\axmap.mjs      ← 홈 설치본 (axmap setup 이 심는 것)
2) <저장소>\ci\axmap\bin\axmap.mjs             ← 사본  (곧 사라집니다)
3) 둘 다 없으면 → 경고만 찍고 그냥 통과
```

🔴 **3번이 문제입니다.** *"선점하지 않은 파일은 커밋되지 않는다"* 는 규칙이 **아무 소리 없이 사라집니다.**
빨간 글씨도, 실패도 없습니다. 그냥 커밋이 됩니다.

`axmap setup` 을 한 번이라도 돌린 분은 1번이 있어 괜찮습니다. **안 돌리셨으면 지금 해 주세요.**

## 그리고 `npm i -g` 만으로는 부족합니다

| | 무엇을 고치나 |
| --- | --- |
| `npm i -g axmap-cli@latest` | 명령줄 `axmap …` 을 1.1.1 로 |
| 🔴 **`axmap setup`** | **홈 설치본**(`~/.axmap/app`)·커밋 훅·MCP 등록. **`npm i -g` 는 이걸 안 건드립니다** |

제 PC 에서 실제로 이랬습니다 — 전역은 **1.1.1** 인데 홈 설치본은 **1.1.0** 이었습니다.
그리고 커밋 훅은 **홈 설치본을 먼저** 씁니다.

## 확인

```
axmap --version     → 1.1.1
axmap doctor        → 종료 코드 0, 전부 OK
```

`doctor` 가 빨간 줄을 내면 그 줄을 그대로 저에게 보내 주세요.

## 세션 시작 알림이 안 뜨는 분

각자 PC 의 `.claude/settings.json` 훅이 사라질 경로를 부르고 있으면 **알림이 조용히 없어집니다**(오류도 안 뜹니다).

| 전 | 후 |
| --- | --- |
| `node ci/axmap/tools/bus.mjs list …` | `axmap bus list …` |
| `node ci/axmap/bin/axmap.mjs status` | `axmap status` |

자세한 대처법은 **설명서를 올려 뒀습니다 — MR `!273`** (`docs/AXMAP-사본을-걷어낸-뒤.md`).
옛↔새 명령 대조표 21행이 있고, **실제로 돌려 확인한 것과 도움말로만 확인한 것을 표시로 갈라 뒀습니다.**
