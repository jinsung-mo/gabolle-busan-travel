subject: [발표 9/28 시연] 전체 화면 단축키·모서리 해결 — 상주 스크립트와 쓰는 법

재현 님 PC 에서 **전체 화면(F11)에서 Ctrl+Alt+S 로 폰 화면이 바로 뜨는 것**을 확인했습니다. 모서리도 틀에 맞춰 둥글게 잘립니다. 어떻게 했는지와 스크립트를 보냅니다.

## 바꾼 방식
전에는 바탕화면 바로 가기의 단축키가 누를 때마다 scrcpy 를 새로 켰습니다. 그 단축키는 윈도 탐색기가 대신 받아서 전체 화면일 때 전달이 안 됐고, 새로 켜느라 2~3초가 걸렸습니다.

지금은 **상주 스크립트 하나**(`시연-단축키.ps1`)가 맡습니다.
- 발표 전에 실행하면 scrcpy 를 **화면 밖(x=-4000)에 미리 켜 둡니다.** 켜는 2~3초를 발표 전에 써 버립니다
- Ctrl+Alt+S 를 **스크립트가 윈도에 직접 등록**합니다(`RegisterHotKey`). 탐색기를 안 거쳐서 전체 화면에서도 받습니다
- 누르면 켜 둔 창을 폰 틀 자리로 **옮기기만** 합니다(`SetWindowPos`). 그래서 바로 뜹니다. 한 번 더 누르면 다시 화면 밖으로 치웁니다
- **모서리**: 창을 둥근 사각형으로 잘라 둡니다(`SetWindowRgn`). 틀 반지름 44 가 화면 자리보다 14 바깥이라 화면은 44−14 = 30(무대 기준)으로 굽혀 틀과 나란하게 했습니다
- 케이블이 빠져 scrcpy 가 꺼졌으면 다음 Ctrl+Alt+S 때 다시 켭니다. 이때만 2~3초 걸립니다
- 검은 명령창은 안 뜹니다 — zip 에 든 `scrcpy-noconsole.vbs` 로 켭니다
- Ctrl+Alt+Q 로 끝내면 scrcpy 도 같이 닫힙니다

## 쓰는 법
1. scrcpy 압축을 푼 폴더(`scrcpy-win64-v4.1`)의 **바로 위 폴더**에 아래 파일을 `시연-단축키.ps1` 로 저장
2. 바탕화면 바로 가기에 Ctrl+Alt+S 를 걸어 뒀으면 **지웁니다** — 같은 키를 두 곳이 잡으면 스크립트가 등록을 못 합니다
3. 터미널에서 `pwsh -ExecutionPolicy Bypass -File "<경로>\시연-단축키.ps1"` → 「준비됐습니다」가 뜨면 창을 최소화
4. 발표 파일을 F11 → 시연 장면에서 Ctrl+Alt+S

**발표 화면이 다르면 14번째 줄의 `$X $Y $W $H` 네 값만 바꿉니다.** 시험 페이지를 그 화면에서 열었을 때의 명령 ② 값을 그대로 옮기면 됩니다. 지금 값은 재현 님 노트북(1440×900, 배율 200%)의 명령 ② 입니다.

## 확인한 것과 안 한 것
- 확인: 재현 님 노트북 화면에서 전체 화면 단축키, 빠르게 뜨는 것, 모서리
- 안 한 것: **발표장 프로젝터·다른 모니터**(좌표를 다시 맞춰야 합니다), 회전 고정 옵션(`--capture-orientation=@0` 이 들어 있지만 폰을 돌려 보는 확인은 안 했습니다), 케이블을 빼고 다시 꽂았을 때 스크립트가 다시 켜는 것
- PowerShell 7(`pwsh`)에서만 돕니다. 윈도 기본 `powershell`(5.1)은 폼 부품 참조가 달라 컴파일이 안 됩니다

## 스크립트
```powershell
# 발표 시연용 — scrcpy 를 화면 밖에 미리 켜 두고, Ctrl+Alt+S 로 폰 틀 자리에 넣었다 뺐다 한다.
#
#   실행:  pwsh -ExecutionPolicy Bypass -File 시연-단축키.ps1   (PowerShell 7 — 윈도 기본 powershell 5 에서는 컴파일이 안 된다)
#   끝:    Ctrl+Alt+Q (scrcpy 도 같이 닫는다)
#   점검:  -SelfTest  (단축키 없이 넣기 → 자리 재기 → 빼기를 한 번 하고 끝낸다)
#
# 바탕화면 바로 가기의 단축키는 탐색기가 대신 받아서 전체 화면(F11)일 때 안 먹고, scrcpy 를 매번 새로 켜서
# 3초쯤 걸렸다. 여기서는 단축키를 이 스크립트가 윈도에 직접 등록하고, 창은 미리 켜 둔 것을 옮기기만 한다.
param([switch]$SelfTest)

$ErrorActionPreference = 'Stop'
$Bin = Join-Path $PSScriptRoot 'scrcpy-win64-v4.1'
# 폰 화면 자리 — 시험 페이지의 명령 ②(물리 px, 배율 200%) 값. 모니터나 배율이 바뀌면 여기만 고친다.
$X = 1142; $Y = 230; $W = 624; $H = 1318
$Away = -4000   # 치워 둘 때의 x. 어떤 모니터에도 안 걸리는 자리.
# 모서리 반지름 — 시험 페이지의 폰 틀(반지름 44)이 화면 자리보다 14 바깥에 있어서, 화면은 44-14=30 으로 굽혀야 틀과 나란하다.
# 30 은 무대(416 폭) 기준이라 창 폭에 맞춰 늘린다.
$Radius = [math]::Round(30 * $W / 416)

Add-Type -ReferencedAssemblies System.Windows.Forms, System.Windows.Forms.Primitives @"
using System; using System.Runtime.InteropServices; using System.Windows.Forms;
public class DemoKeys : NativeWindow, IDisposable {
  [DllImport("user32.dll")] static extern bool RegisterHotKey(IntPtr h, int id, uint mod, uint vk);
  [DllImport("user32.dll")] static extern bool UnregisterHotKey(IntPtr h, int id);
  [DllImport("user32.dll")] public static extern bool SetWindowPos(IntPtr h, IntPtr after, int x, int y, int w, int hh, uint f);
  [DllImport("user32.dll")] public static extern bool SetProcessDPIAware();
  [DllImport("gdi32.dll")] public static extern IntPtr CreateRoundRectRgn(int l, int t, int r, int b, int w, int h);
  [DllImport("user32.dll")] public static extern int SetWindowRgn(IntPtr h, IntPtr rgn, bool redraw);
  [StructLayout(LayoutKind.Sequential)] public struct R { public int L, T, Ri, B; }
  [DllImport("user32.dll")] public static extern bool GetWindowRect(IntPtr h, out R r);
  public event Action<int> Pressed;
  public DemoKeys() { CreateHandle(new CreateParams()); }
  public bool Add(int id, uint mod, uint vk) { return RegisterHotKey(Handle, id, mod, vk); }
  protected override void WndProc(ref Message m) { if (m.Msg == 0x0312 && Pressed != null) Pressed(m.WParam.ToInt32()); base.WndProc(ref m); }
  public void Dispose() { UnregisterHotKey(Handle, 1); UnregisterHotKey(Handle, 2); DestroyHandle(); }
}
"@
[DemoKeys]::SetProcessDPIAware() | Out-Null

$script:proc = $null
function Start-Mirror {
  $argLine = "--window-borderless --always-on-top --no-control --no-audio --capture-orientation=@0 --window-title=gabolle-demo " +
          "--window-x=$Away --window-y=$Y --window-width=$W --window-height=$H"
  # 검은 명령창 없이 켠다 — zip 에 든 scrcpy-noconsole.vbs 가 명령창을 숨긴 채 scrcpy 를 띄운다.
  # (scrcpy.exe 를 -WindowStyle Hidden 으로 켜면 폰 화면 창까지 숨겨질 수 있다.)
  $before = @(Get-Process scrcpy -ErrorAction SilentlyContinue | ForEach-Object Id)
  Start-Process -FilePath "$env:WINDIR\System32\wscript.exe" -ArgumentList ("`"$(Join-Path $Bin 'scrcpy-noconsole.vbs')`" " + $argLine) -WorkingDirectory $Bin | Out-Null
  # 창이 생길 때까지 기다린다(보통 2~3초). 이 시간은 발표 전에 쓰고, 단축키를 누를 때는 안 쓴다.
  for ($i = 0; $i -lt 50; $i++) {
    Start-Sleep -Milliseconds 200
    $script:proc = Get-Process scrcpy -ErrorAction SilentlyContinue | Where-Object { $before -notcontains $_.Id -and $_.MainWindowHandle -ne 0 } | Select-Object -First 1
    if ($script:proc) {
      # scrcpy 창은 네모라 둥근 폰 틀 모서리 밖으로 삐져나온다 — 창을 둥근 사각형으로 잘라 둔다. 자른 모양은 창을 옮겨도 따라간다.
      $rgn = [DemoKeys]::CreateRoundRectRgn(0, 0, $W + 1, $H + 1, $Radius * 2, $Radius * 2)
      [DemoKeys]::SetWindowRgn($script:proc.MainWindowHandle, $rgn, $true) | Out-Null
      return $true
    }
  }
  return $false
}
function Test-Mirror { return ($script:proc -and -not $script:proc.HasExited -and $script:proc.MainWindowHandle -ne 0) }
function Move-Mirror([int]$x) { [DemoKeys]::SetWindowPos($script:proc.MainWindowHandle, [IntPtr](-1), $x, $Y, $W, $H, 0x0040) | Out-Null }
$script:shown = $false
function Toggle-Mirror {
  if (-not (Test-Mirror)) {   # 케이블이 빠져 꺼졌으면 다시 켠다 — 이때만 2~3초 걸린다.
    $script:shown = $false
    if (-not (Start-Mirror)) { Write-Host '폰에 연결하지 못했습니다. 케이블과 USB 디버깅 허용을 확인하세요.'; return }
  }
  $script:shown = -not $script:shown
  Move-Mirror ($(if ($script:shown) { $X } else { $Away }))
}

if (-not (Start-Mirror)) { Write-Host '폰에 연결하지 못했습니다. adb devices 로 device 가 보이는지 확인하세요.'; exit 1 }

if ($SelfTest) {
  Toggle-Mirror; Start-Sleep -Milliseconds 300
  $r = New-Object DemoKeys+R; [DemoKeys]::GetWindowRect($script:proc.MainWindowHandle, [ref]$r) | Out-Null
  "넣은 자리: x=$($r.L) y=$($r.T) w=$($r.Ri - $r.L) h=$($r.B - $r.T)  (목표 x=$X y=$Y w=$W h=$H)"
  Toggle-Mirror; Start-Sleep -Milliseconds 300
  [DemoKeys]::GetWindowRect($script:proc.MainWindowHandle, [ref]$r) | Out-Null
  "치운 자리: x=$($r.L)"
  Stop-Process -Id $script:proc.Id; exit 0
}

$keys = New-Object DemoKeys
# 수식 키: Alt=1, Ctrl=2, 반복 안 함=0x4000. S=0x53, Q=0x51
if (-not $keys.Add(1, 0x4003, 0x53)) { Write-Host 'Ctrl+Alt+S 를 다른 프로그램이 쓰고 있습니다. 바탕화면 바로 가기의 단축키를 지우고 다시 켜세요.'; exit 1 }
$keys.Add(2, 0x4003, 0x51) | Out-Null
$keys.add_Pressed({ param($id) if ($id -eq 1) { Toggle-Mirror } elseif ($id -eq 2) { [System.Windows.Forms.Application]::Exit() } })
Write-Host '준비됐습니다. Ctrl+Alt+S = 폰 화면 넣기/빼기, Ctrl+Alt+Q = 끝. 이 창은 최소화해 두세요.'
[System.Windows.Forms.Application]::Run()
$keys.Dispose()
if (Test-Mirror) { Stop-Process -Id $script:proc.Id }

```
