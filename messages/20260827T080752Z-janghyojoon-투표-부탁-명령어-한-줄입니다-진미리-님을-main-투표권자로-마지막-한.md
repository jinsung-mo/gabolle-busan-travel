# 1. 무엇에 투표하는 건가

**바뀌는 파일은 이것 하나, 3줄입니다.** 내용은 이미 `common/dev` 에 머지된 것과 **한 글자도 다르지 않습니다** (MR !22 에서 보신 그 파일입니다). 제가 두 브랜치를 `git diff` 로 대조했고 차이가 없었습니다.

## 이메일 근거

팀 안에서는 `ssafy0121@gmail.com` 으로 알려져 있었는데, **git 이력에 실제로 찍힌 것은 `wlsalfl321@naver.com`** 입니다 (커밋 7건, 실측). 본인 확인도 쪽지로 두 번 받았습니다.

표는 커밋 저자 이메일 **완전일치**로만 세어지므로, 알려진 쪽을 넣었다면 진미리 님은 한 표도 못 던지고 **본인은 그것을 모릅니다.**

# 2. 왜 `hotfix/` 로 사다리를 건너뛰었나

정상 경로(`common/dev` → 위로)가 **막혀 있습니다.** 표가 모자란 게 아니라 **던질 수 있는 사람이 모자랍니다.**

판정 프로그램을 실제로 돌려서 나온 숫자입니다.

| | |
|---|---|
| `main` 대비 `common/dev` 의 커밋 저자 | 장효준(19) · **이예승(4)** |
| 자기 표 배제 — 커밋한 사람은 그 변경에 투표 못 함 | **둘 다 무효** |
| `main` 정책의 투표권자 3명 중 던질 수 있는 사람 | 박재현 님 **1명** |
| 필요한 표 | **2장** |

**그래서 `common/dev` 는 지금 `main` 으로 못 올라갑니다.** 자세한 건 제가 보낸 쪽지 *"[실측] common/dev 는 지금 main 으로 승격할 수 없습니다"* 에 있습니다.

`hotfix/` 브랜치는 **커밋이 하나뿐**이라 자기 표 배제에 저자 한 명(진미리 님)만 걸립니다. **표를 면제받는 게 아닙니다** — 정족수 2표는 그대로 요구되고, 지금 1장 모였습니다.

# 3. 하실 일 — 이 한 줄입니다

```
node ci/axmap/governance/vote.mjs --branch hotfix/S15P21E201-33-jinmiri-voter --sha 53ef1bf3b1847d8bcae2ad8d7fc2fa4b49a9bdc8 --vote approve --target origin/main --note "내용 확인함"
```

`--sha` 를 명시한 이유는 아래 4번에 있습니다.

## 확인

```
node ci/axmap/governance/gate.mjs --source hotfix/S15P21E201-33-jinmiri-voter --target origin/main
```

**`유효 찬성 2 / 필요 2`** 가 나오면 끝입니다.

> 🔴 `--target origin/main` 을 꼭 붙여 주세요. 그냥 `main` 이라고 하면 판정 프로그램이 **낡은 로컬 브랜치**를 봐서 *"정책 파일이 없다"* 는 틀린 답을 냅니다. 버그이고, axMap 저장소에 보고해 뒀습니다.
