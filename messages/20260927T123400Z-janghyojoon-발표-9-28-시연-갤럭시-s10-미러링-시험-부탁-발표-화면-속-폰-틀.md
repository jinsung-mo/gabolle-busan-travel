## 무엇을 하려는가
발표 중 기능 소개가 끝나면 **시연**이 있습니다. 이때 발표 화면의 탭바가 가운데 ⊕ 로 오므라들었다가 **폰 틀**로 자라고, 그 화면 자리에 **실제 갤럭시 S10 화면**을 겹쳐 띄웁니다.
- 폰 화면은 **scrcpy**(폰 화면을 USB 로 PC 에 띄우는 무료 공개 프로그램)가 **테두리 없는 창**으로 그 자리에 딱 맞춰 올라옵니다.
- 발표 화면(크롬 전체 화면)은 그대로이고 그 위에 창 하나가 얹히는 방식이라, 청중에게 **창이 바뀌는 모습이 안 보여야** 합니다.
- 덱스(DeX)는 못 씁니다 — 폰을 USB 로 노트북에 붙여 쓰는 방식이 One UI 7 부터 없어졌습니다.

**확인하고 싶은 것: 발표 파일 안에서 폰만 연결해 두면 시연까지 부드럽게 이어지는가.**

## 한 번만 — 준비 (자세한 건 페이지 오른쪽 안내판, H 로 켜고 끔)
1. PC: github.com/Genymobile/scrcpy → Releases → `scrcpy-win64-…zip` 받아 압축 풀기(adb 포함)
2. S10: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 연속 누르기** → 개발자 옵션 → **USB 디버깅 켜기**
3. USB 연결 → 폰에 뜨는 「USB 디버깅 허용」 → **이 컴퓨터에서 항상 허용**
4. 확인: 압축 푼 폴더에서 cmd → `adb devices` → `device` 로 보이면 됨

## 시험 순서
1. 시험 페이지를 **발표에 쓸 모니터·프로젝터**에서 크롬으로 열고 **F11**(전체 화면)
2. 클릭 → 탭바가 폰 틀이 됨 → 안내판의 **명령 ①** 복사 → scrcpy 폴더 cmd 에 붙여 실행
3. **G** 빨간 정렬선으로 폰 화면 네 변이 맞는지. 어긋나면 **Alt+F4** 로 닫고 **명령 ②**(윈도 배율을 곱한 값)
4. 발표처럼 흘려 보기: 맞은 명령을 `시연.bat` 로 저장 → 바탕화면 바로 가기 → 속성 → **바로 가기 키 Ctrl+Alt+S** → 전체 화면 그대로 Ctrl+Alt+S → 폰 조작 → **Alt+F4** → 계속 넘기기. **작업 표시줄·검은 창·다른 창이 번쩍 보이는지** 봐 주세요.
