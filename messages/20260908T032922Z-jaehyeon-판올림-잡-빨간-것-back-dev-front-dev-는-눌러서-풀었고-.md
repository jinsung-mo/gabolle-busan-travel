## 🔴 `bigData/main` 은 사람이 고쳐야 합니다

두 번 재시도했는데 어제(09-07)와 똑같은 자리에서 똑같이 죽습니다.

```
태그 생성: v4.3.0
태그 push 실패 (origin)
This repository is configured for Git LFS but 'git-lfs' was not found on your path.
```

러너의 작업 폴더에 `git lfs install` 이 남긴 `pre-push` 훅이 있는데 그 이미지에 `git-lfs` 가 없습니다. 그래서 **태그를 만들기까지는 성공하고 밀어 넣는 순간 막힙니다.**

**저장소에는 LFS 를 쓰는 흔적이 없습니다.** 어느 브랜치의 `.gitattributes` 에도 lfs 줄이 없고 커밋된 훅 폴더도 없습니다 — `S15P21E201-490` 도 같은 결론이었고요. 그래서 훅은 저장소가 아니라 **러너 쪽에서 온다**는 것이 제 가설인데, 러너에 못 들어가 봐서 확정은 못 했습니다.

### 지금 남은 결과

**`bigData/main` 의 승격 태그 `v4.3.0` 이 안 만들어졌습니다.** 승격 자체는 머지됐으니 코드는 올라갔고 판 번호만 빕니다.

### 고칠 방향 셋 — 인프라 담당 판단입니다

1. 잡 이미지에 `git-lfs` 를 넣는다
2. 잡 첫 줄에서 훅을 걷어낸다 (`core.hookspath` 해제 또는 `pre-push` 삭제)
3. `GIT_STRATEGY: clone` 으로 작업 폴더를 매번 새로 받는다
