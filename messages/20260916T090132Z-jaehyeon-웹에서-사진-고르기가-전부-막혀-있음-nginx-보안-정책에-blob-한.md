subject: 웹에서 사진 고르기가 전부 막혀 있음 — nginx 보안 정책에 blob 한 줄 (S15P21E201-1112)

메뉴판 읽기를 화면에서 확인하다가 찾았습니다. **웹에서 사진을 고르는 기능이 전부 안 됩니다.** 메뉴판, 기록 사진, 컬렉션 장소 사진, 프로필 사진 넷 다입니다. 네이티브 앱은 해당 없습니다.

증상이 조용해서 눈에 안 띕니다. 사진을 고르면 서버로 요청이 **한 건도 안 나가고** 바로 「사진을 읽지 못했어요」가 뜹니다. 콘솔에도 아무것도 안 남습니다 — 줄이기 단계에서 던진 오류를 부르는 쪽이 받아서 사용자 문구로 바꾸기 때문입니다.

원인은 운영 nginx 가 내려보내는 `Content-Security-Policy` 에 `blob:` 이 없는 것입니다. 사진 고르기는 웹에서 고른 파일을 `blob:` 주소로 넘기는데, 그 주소를 이미지로 읽는 것도 `fetch` 하는 것도 정책이 막습니다. 브라우저에서 둘 다 직접 확인했습니다.

고칠 것은 한 줄입니다 — `img-src` 와 `connect-src` 에 `blob:` 을 더하면 됩니다. 저장소가 아니라 EC2 안에 있는 설정이라 접속 권한자만 할 수 있습니다. 찾는 방법은 `frontend/docs/MAP-RECOVERY.md` 에 카카오 지도 때문에 이미 적혀 있습니다.

**서버 쪽 메뉴판은 정상입니다.** API 로 사진을 직접 보내면 200 으로 네 줄을 읽고 `새우튀김`·`계란말이` 에서 알레르기 낱말까지 잡습니다. 막혀 있는 것은 화면에서 서버로 가는 길뿐입니다. 시연에서 웹으로 사진 기능을 보여 주실 계획이면 이것부터 풀어야 합니다.
