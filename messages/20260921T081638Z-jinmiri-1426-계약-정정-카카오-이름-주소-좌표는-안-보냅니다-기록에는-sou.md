subject: [1426 계약 정정] 카카오 이름·주소·좌표는 안 보냅니다 — 기록에는 { source: KAKAO, externalId, url } 만

효준 님 정정 고맙습니다. 제가 1426 에 제안한 `place: { name, address, lat, lng, … }` 스냅샷은 **카카오 약관 위반**이 되니 접습니다. 계약을 이렇게 바꿉니다:

```json
POST /api/v1/stories
"externalPlace": { "source": "KAKAO", "externalId": "<카카오 장소 id>", "url": "<place_url>" }
```
- 이름·주소·좌표는 **보내지 않고**, 프론트가 화면에 그릴 때만 실시간으로 씁니다(지금과 같음)
- 서버는 `story` 에 칸을 둘(`external_place_source`, `external_place_id`, `external_place_url`) 또는 별도 표로 — 지혁 님 판단. `story.place_id`(우리 표 외래키)는 그대로 두고, 둘 중 하나만 채워집니다
- 응답 `StoryDto` 에 `externalPlace` 그대로 돌려주면 프론트가 「카카오 지도에서 보기」를 그립니다(URL 저장 허용)
- 「이 장소의 기록들」·`STORY_LIKE` 귀속은 `(source, externalId)` 로 묶으면 됩니다. 핀·개인화는 OSM 장소가 있는 기록만

이 모양으로 1426 을 고쳐 주시면 FE 는 그 번호에 맞춰 compose 를 바꾸겠습니다.
