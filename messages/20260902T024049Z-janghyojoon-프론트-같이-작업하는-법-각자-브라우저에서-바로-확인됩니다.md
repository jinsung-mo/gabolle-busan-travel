**결론부터 — 서로 방해 없이, 각자 브라우저에서 바로바로 확인됩니다.** 특별한 설정은 없습니다.
화면을 그리는 건 git 이 아니라 각자 컴퓨터의 개발 서버라, git 은 파일만 주고받고 그림은 각자 그립니다.

## 1. 시작 (처음 한 번만)

```bash
git switch front/dev
git pull
git switch -c feature/front/S15P21E201-<티켓번호>-<짧은설명>

cd frontend            # 🔴 반드시 frontend 안에서
npm install
npx expo start --web   # → localhost:8081 에 내 브랜치가 뜹니다
```

파일을 저장하면 **브라우저가 알아서 다시 그립니다.** 커밋도 push 도 필요 없습니다.

## 2. 서로의 화면을 보고 싶을 때 — 셋 중 하나

| 방법 | 어떻게 |
|---|---|
| ⭐ 터널 열기 | 보여줄 사람이 `npx expo start --web --tunnel` → 나온 주소를 보냅니다. 받는 쪽은 **링크만 열면 끝** |
| 같은 와이파이 | 터널 없이 `http://<상대 IP>:8081` 로도 열립니다 |
| 나란히 놓고 비교 | 폴더를 하나 더 폅니다 — `git worktree add ../front-2 <상대브랜치>` 후 그 폴더에서 `npx expo start --web --port 8082` |

세 번째가 편한 이유는, **내 브랜치를 갈아타지 않아도 되기** 때문입니다.
`git switch` 로 갈아타면 하던 작업을 먼저 커밋하거나 `git stash` 해야 합니다.

## 3. 충돌을 미리 막는 법

같은 파일을 둘이 동시에 고치면 나중에 git 이 충돌을 냅니다. **화면 단위로 갈라 가지면** 안 납니다.
고치기 전에 한 줄 잡아 두시면 서로에게 보입니다.

```bash

  --task S15P21E201-<번호> --intent "여행 조건 입력 화면"
```

지금 제가 잡고 있는 것은 **`frontend/app/index.tsx`(웰컴 화면) 하나**입니다. 나머지는 비어 있습니다.
