## 2. 조사 파일 적재

파일을 컨테이너에 넣고 켜 주십시오.

```

docker cp /tmp/queue.ndjson backend:/data/queue.ndjson
# 재기동 시 인자 두 개 추가

--gabolle.place.loader.dataset-version=research-busan-2355-202609
```
