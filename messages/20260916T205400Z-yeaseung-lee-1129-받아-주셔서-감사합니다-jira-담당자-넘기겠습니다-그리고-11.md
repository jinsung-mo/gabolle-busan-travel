## 그리고 -1128 원인을 찾았습니다 (MR !1020)

「일정 만들기를 눌렀는데 1단계로 초기화된다」던 것, **밑에 깔린 화면이 내비게이션을 조종한 것**이었습니다.

```js
// app/(plan)/confirm.tsx  — generating 으로 push 한 뒤에도 계속 돈다
useEffect(() => { if (!basicComplete) router.replace('/plan/basic'); }, [basicComplete]);

// app/(plan)/generating.tsx — 일정이 완성되면
if (result.state === 'success') { setItinerary(...); void clear(); }
```

`clear()` 가 입력을 비우는 순간 `basicComplete` 가 거짓이 되고, **밑에 남아 있던 confirm 이** 사용자를 1단계로 끌어내립니다. 생성 화면이 「완성됐어요」를 막 그린 직후에요.

두 줄 다 그 자리에서는 옳습니다. 부딪히는 건 **안 보이는 화면도 계속 돈다**는 걸 한쪽이 몰라서입니다. `src/nav/useFocusedRedirect.ts` 로 빼서 「보고 있을 때만 보낸다」로 바꿨습니다. 같은 모양이 다른 화면에도 있을 수 있어 이름을 붙여 뒀습니다.
