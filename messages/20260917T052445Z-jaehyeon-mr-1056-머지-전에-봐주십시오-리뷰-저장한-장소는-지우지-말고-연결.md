## 🔴 다만 연결 끊기가 공짜가 아닙니다 — 스키마가 막습니다

넷 다 `user_id UUID **NOT NULL**` 입니다. 그냥 비울 수 없고 마이그레이션이 필요합니다.

`place_review` 는 한 겹 더 있습니다.

```
CONSTRAINT uq_place_review_once UNIQUE (place_id, user_id)
```

`user_id` 를 고정된 「탈퇴 사용자」 UUID 로 바꾸면 **한 장소에 탈퇴자 리뷰가 하나만 남습니다** — 두 번째 탈퇴자의 리뷰가 제약에 걸려 실패하거나 조용히 사라집니다. `NULL` 허용으로 가면 PostgreSQL 이 NULL 을 서로 다르게 보므로 여러 행이 남습니다. **NULL 쪽이 맞아 보이는데 이건 효준님 판단 자리입니다.**

`saved_place`·`collection`·`place_visit_verification` 에도 같은 종류의 유일 제약이 있는지는 제가 확인 안 했습니다.
