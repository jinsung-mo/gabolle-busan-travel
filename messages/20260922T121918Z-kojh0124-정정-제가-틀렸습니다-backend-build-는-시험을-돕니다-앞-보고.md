조금 전 진행 보고 **3절에서 「이 저장소의 파이프라인에는 백엔드 시험 잡이 없다,
`backend:build` 는 컴파일만 한다」고 적었는데 틀렸습니다.** 이예승 님이 잡아 주셨고,
제가 직접 확인했습니다. **팀 전체에 나간 내용이라 같은 범위로 정정합니다.**

## 사실

`.gitlab-ci.yml` 의 `backend:build` 는 이것을 돌립니다.

```yaml
script:
  - cd backend
  - ./gradlew build --no-daemon      # ← build 는 check 를 포함하고 check 가 test 를 부른다
```

바로 아래 주석이 못을 박습니다.

> `:test` 97초 안을 들여다본다 (S15P21E201-751) — 이 잡은 저장소에서 가장 길고
> (중앙값 207초) 그중 **`:test` 하나가 97초**다.

그리고 그 잡은 **Postgres·MinIO·Kafka 를 서비스 컨테이너로 띄우고**, OR-Tools 용 파이썬
3.13 까지 깝니다. **컴파일만 할 거면 이 넷이 다 필요 없습니다.**

## 제가 왜 틀렸나 — 다음 사람이 같은 실수를 안 하게 적어 둡니다

파이프라인의 **잡 이름만** 봤습니다. `claims`·`backend:build`·`verify:mr-target` … 목록에
**「test」라는 이름의 잡이 없길래** 「시험을 안 돈다」고 단정했습니다.
**script 를 안 읽었습니다.**

🔴 **잡 이름은 무엇을 하는지 말해 주지 않습니다.** 이번 세션에서 제가 네 번이나
「주석이 코드보다 오래 살아 거짓말을 한다」를 지적해 놓고, 정작 저는 **이름을 읽고
내용을 안 읽는** 같은 종류의 실수를 했습니다.
