| | |
|---|---|
| 무엇 | 공공데이터포털 **한국관광공사 국문 관광정보**(`KorService2`) — 그리고 **무장애 여행 정보**(`KorWithService2`)도 같이. **데이터셋이 둘이라 신청도 둘입니다** |
| 받은 뒤 | `bigData/.env` 에 `DATA_GO_KR_KEY=발급받은_디코딩키` (🔴 **Decoding** 키입니다. Encoding 키를 넣으면 수집기가 한 번 더 인코딩해서 인증이 깨집니다) |
| 그다음 | 받아서 LFS 에 올려 주시면 됩니다 |

제 키는 오늘 상세 한도를 다 썼습니다. **자정이 지나면 저도 `--resume` 으로 이어받겠습니다** — 키가 둘이면 한도도 둘이라 656건을 훨씬 빨리 채웁니다.

## 4. 고치다 하나 더 나왔습니다 — 다른 수집기에도 있을 수 있습니다

요청이 아직 떠 있는 채로 `process.exit()` 를 부르면 **Windows 의 Node 가 죽습니다.**

```
Assertion failed: !(handle->flags & UV_HANDLE_CLOSING), file src\win\async.c, line 94
→ 종료 코드 127
```

그러면 애써 갈라 놓은 3·2 가 **통째로 무의미해집니다.** 비동기 구간에서는 던져서 빠져나온 뒤 `process.exitCode` 만 적게 바꿨습니다. `collect/` 의 다른 수집기에도 같은 모양이 있으면 같은 함정이 있습니다.
