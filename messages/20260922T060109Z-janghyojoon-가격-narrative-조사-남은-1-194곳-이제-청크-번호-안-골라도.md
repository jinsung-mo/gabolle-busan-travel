가격+narrative 조사 — 남은 1,194곳, 이제 청크 번호 안 골라도 됩니다

지난 주 공유한 !1411(가격+narrative 조사)이 지금 806/2,000곳(40.3%)까지 왔습니다.
남은 1,194곳을 여러분과 나눠서 끝내고 싶습니다. **아래 한 줄이면 됩니다.**

## 1. 이것만 하면 됩니다

```bash
git pull                         # bigData/dev
cd bigData
node research/work-chunk.mjs
```

예전엔 청크 번호를 직접 고르고 `axmap claim`을 손으로 불러야 했는데, 이제 이
스크립트가 다 합니다 — 아직 아무도 안 잡고 안 끝난 청크를 스스로 찾아 선점하고,
오래 걸려도(청크 하나 최대 30분+) 알아서 TTL을 늘리고, 끝나면 반납까지 합니다.
**axmap을 몰라도 됩니다.** 여러 명이 동시에 여러 번 돌려도 청크 번호가 겹치지
않게 나눠 갑니다.

끝나면 화면에 커밋 명령이 그대로 나옵니다:

```bash
git add -f bigData/research/data/combined-results/*.json
git commit -m "[S15P21E201-1414] chore: [Data] 가격 조사 청크 <번호> 결과"
git push origin bigData/dev
```

표(governance) 필요 없습니다 — `bigData/dev`로 바로 가는 커밋이라 push만 하면
끝입니다.

## 2. `agy`(Antigravity CLI)가 있어야 돕니다

이 스크립트는 `agy`를 웹검색용 조사원으로 씁니다. PC에 없으면:
- `agy install`로 PATH를 잡고, `agy`를 한 번 대화형으로 띄워 구글 계정으로
  로그인하면 그 뒤로는 헤드리스(`-p=...`)로 바로 됩니다.
- 🔴 **설치 파일 자체를 어디서 받는지는 제가 확인 못 했습니다** — 이 PC엔 이미
  깔려 있어서요. 못 찾으시면 저한테 쪽지 주세요, 받은 경로 확인해서 드리겠습니다.
- **할당량은 계정별입니다.** 각자 자기 구글 계정으로 로그인하면 제 Gemini 5시간
  한도와 안 겹칩니다 — 미리 님이 물어보신 게 이겁니다.

## 3. 뭐가 같이 모이나

가격만이 아닙니다. 한 곳 조사하면 가격·영업시간·혼잡·현지인비중·메뉴다양성·
"왜 가는지" narrative가 한 파일에 다 담깁니다. **이번에 사진 주소(photoUrls)도
추가했습니다** — 이미지 자체는 안 받고, agy가 읽은 페이지에 있던 사진의 URL만
기록합니다(이미지를 직접 저장하면 저작권 문제가 있어서요). 청크 17번부터
적용되고, 이미 끝난 1~16번은 다시 안 돕니다.

## 4. 결과를 DB에 넣는 건 제가 합니다

쓰셔도 됩니다 — 매핑 규칙이 한 곳에서만 바뀌어야 나중에 추적이 되기 때문에,
그 단계는 제가 모아서 일관되게 하겠습니다.
