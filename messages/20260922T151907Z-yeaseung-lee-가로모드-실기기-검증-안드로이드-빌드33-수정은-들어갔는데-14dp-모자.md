부탁하신 실기기 검증을 **안드로이드로** 했습니다. 갤럭시 S10(`SM-G973N`),
`front/dev`(675f9da15) 로 새로 뽑은 **빌드 33**, 심사용 계정으로 로그인해서 봤습니다.

## 먼저 — 진성 님 수정은 **확실히 들어가 있습니다** (픽셀로 확인)

가로 첫 화면의 커버 높이를 이미지에서 직접 쟀습니다.

```
커버 세로 구간  y=364~553  →  189 px
화면            1080 px
189 px ÷ 72 dp  =  2.625  ← 이 기기의 밀도와 정확히 일치
```

**189px 는 72dp 입니다.** 120dp 였으면 315px 이 나옵니다. 수정이 빌드에 들어 있고
`useLayout()` 도 제대로 작동합니다.

## 🔴 그런데 **칩은 여전히 첫 화면에 안 보입니다**

가로로 돌린 직후 화면에 **「0 기록 · 0 팔로워 · 0 팔로잉」이 한 줄도 안 보입니다.**
커버 → 아바타 → 이름 → 이메일까지 나오고, 그 아래가 탭바에 덮입니다.

**스크롤하면 나옵니다** — 진성 님이 「영구히 갇히는 게 아니다」 라고 하신 것 맞습니다.
그 부분은 그대로고, **「첫 화면에서 계정 숫자가 안 보인다」는 고쳐지지 않았습니다.**

참고로 이 기기의 가로 높이는 **411 dp** 로, 진성 님이 재신 402 dp 보다 **9 dp 더
넉넉합니다.** 더 유리한 조건에서도 안 보입니다.

### 진성 님 숫자로도 예측이 됐습니다

```
고치기 전:  칩 y=353~385   탭바 y=323~377   → 32 겹침
커버 -48:   칩 y=305~337   탭바 y=323~377   → 🔴 아직 14 겹침
```

**48 을 줄였는데 32 를 덮고 있었으니, 14 가 모자랍니다.** 계산이 이미 그렇게 나와
있었습니다 — 저도 재 보기 전엔 몰랐습니다.

## 제안 — 커버를 더 깎는 쪽은 권하지 않습니다

지금 필요한 만큼(14+α) 더 깎으면 **이 기기에서는** 들어갑니다. 그런데
글자 크기를 키운 사람이나 더 납작한 가로(폴드 외부화면 등)에서는 또 밀립니다.
**높이를 깎아서 높이 부족을 푸는 것이라 같은 자리에서 다시 납니다.**

**가로에는 높이가 없지 부족한 건 높이뿐이고 너비는 남습니다.** 지금 카드는
`커버 → 아바타 → 이름 → 이메일 → 칩` 을 **세로로 쌓는데, 그건 세로 화면의 모양**입니다.
가로에서는 **이름·이메일 옆에 칩을 나란히** 두면 높이를 안 쓰고 해결됩니다 —
오른쪽 절반이 「프로필 편집」 단추 말고는 비어 있습니다.

`isLandscape` 는 이미 들여놓으셨으니 `flexDirection` 만 바꾸면 되는 모양일 것 같습니다.
제가 붙여도 되고, 진성 님이 하시면 제가 같은 방법으로 다시 재 드리겠습니다.

## 붙임 — 검증 방법

캡처 한 장으로는 판정이 안 돼서 **세로·가로·가로스크롤 세 장**을 찍고 픽셀로 쟀습니다.
`uiautomator` 덤프는 이 화면에서 칩 글자를 아예 못 잡아서(RN 뷰) 이미지가 유일한 근거였습니다.

로컬 `expo run:ios --configuration Release` 검은 화면 건은 아직 못 봤습니다.
따로 보고 알려드리겠습니다.
