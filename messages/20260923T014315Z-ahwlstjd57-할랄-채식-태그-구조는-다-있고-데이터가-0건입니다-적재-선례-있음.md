## 3. 적재 방법 — 🔴 선례가 있습니다

`V20260918160000__market_cuisine_tag.sql` 이 **똑같은 상황을 이미 풀었습니다.**
온보딩에서 음식 취향 「시장」을 고른 사람이 9명인데 짝지을 장소가 0곳이던 걸
51곳 붙였고, 그 패턴을 할랄에 그대로 쓸 수 있습니다:

- **이름 자동 매칭 금지.** 후보 60곳 중 9곳을 사람이 뺐는데, 그중 하나가
  `수정동시장횟집` — **상호에 「시장」이 든 식당**입니다. 자동이면 들어갔을 오류
- **`place` 테이블과 JOIN해서 INSERT.** `place_id` 를 그대로 넣으면 CI 의 빈 시험 DB
  에서 외래키 위반으로 마이그레이션이 통째로 죽습니다. JOIN 하면 빈 DB 에선 0행,
  운영에선 51행
- **`NOT EXISTS`** 로 두 번 돌려도 안전하게
- **`source_version`** 을 박아서 한 줄로 되돌리기

### 🔴 다만 할랄엔 제약이 하나 더 붙습니다

`V20260907003000` 이 안전 피처 넷(`ALLERGEN_TAG`·`DIETARY_SUPPORT_TAG`·
`ACCESSIBILITY_TAG`·`STAIRS_PRESENT`)은 **`ESTIMATED`(추정) 등급으로 저장하는 것
