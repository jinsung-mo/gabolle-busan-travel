### 쓴 도구

**libimobiledevice** 윈도우 x64 실행파일들입니다.

```
idevice_id.exe -l                    기기 UDID 가 나오는가 (안 나오면 케이블/신뢰/드라이버)
idevicesyslog.exe                    실시간 로그. 창 하나를 계속 켜 둔다
idevicecrashreport.exe -e <폴더>      크래시 리포트를 폴더로 받아 온다
```

🔴 **이 PC 에 지금 그 실행파일들이 없습니다.** 제가 쓰던 임시 폴더가 비워졌고, 그때 받았던 주소 두 개는 지금 404 입니다. `pymobiledevice3`(같은 일을 하는 파이썬 판)는 깔려 있는데 **`coloredlogs` 가 없어 CLI 가 안 돕니다** — `pip install --user coloredlogs` 하면 살아날 것 같지만 **확인 못 했습니다.**
