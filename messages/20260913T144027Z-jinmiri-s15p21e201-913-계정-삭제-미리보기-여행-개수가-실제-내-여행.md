subject: [S15P21E201-913] 계정 삭제 미리보기 여행 개수가 실제 "내 여행" 목록과 안 맞는다

운영 사이트에서 마이페이지 → 계정 삭제 화면 직접 확인 중 발견. 이 계정 "내 여행"엔 1개뿐인데 삭제 1단계 화면은 "3 내가 만든 여행이 삭제돼요"로 뜬다.

**원인**: `AccountDeletionService.java:127-139`의 `preview()`가 쓰는 `ownedTripCount`·`itineraryCount` 두 질의 다 소프트 삭제(`Trip.deletedAt`)를 안 거른다. 바로 아래 `recordCount` 질의는 `AND s.deletedAt IS NULL`을 붙이는데 트립·일정 쪽만 빠져 있다 — 같은 메서드 안에서 기준이 다르다. "내 여행" 목록(`JpaTripRepository.findTripsForMember`)은 `findByTripIdInAndDeletedAtIsNullOrderByUpdatedAtDesc`로 정확히 거르므로, preview()가 여기 안 맞춰서 생긴 불일치다.

실제 delete() 쪽 `ownedTripIds()`도 같은 필터가 없지만 그쪽은 DELETE가 0행에 적용돼 기능상 무해 — preview() 화면 숫자만 사용자에게 실질적으로 보이는 문제.

**막힌 지점**: 이 저장소 로컬에 JDK 17이 없어서(설치된 건 8뿐) Gradle 빌드·테스트를 못 돌렸다. 코드 diff는 한 줄 추가(`AND t.deletedAt IS NULL`, `recordCount`와 같은 패턴)라 간단하지만, 직접 고치고 검증까지 하려면 백엔드 빌드 환경이 있는 쪽이 빠를 것 같아 Jira만 올리고 넘긴다.
