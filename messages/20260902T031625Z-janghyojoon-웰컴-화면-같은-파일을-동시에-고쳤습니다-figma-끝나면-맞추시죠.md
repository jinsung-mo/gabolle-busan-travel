## 🔴 다음에 또 부딪히지 않으려면 — 한 줄만 쳐 주세요

```bash
axmap hook install
```

**이게 없으면 선점(claim) 없이 커밋이 그냥 통과합니다.** 그래서 이번에 서로 몰랐습니다
(장부에 진미리 님 기록이 없었습니다). 앞으로는 고치기 전에 이렇게 잡아 두시면
제 쪽에서 바로 보입니다.

```bash
AXMAP_AGENT=jinmiri axmap claim frontend/app/index.tsx \
  --task S15P21E201-537 --intent "웰컴 화면"
```

> 커밋이 *"장부가 없습니다"* 로 막히면 그것도 `axmap hook install` 한 줄로 풀립니다.
> 저장소 안의 옛 사본이 아니라 **npm 으로 깐 axmap** 을 가리키게 하는 것이 요점입니다.
