# 1. 🔴 Xcode 시뮬레이터로는 안 됩니다

Apple 은 심사용 영상에 **실제 기기 녹화**를 요구합니다. 시뮬레이터 화면은 반려 사유가 됩니다.

**맥북은 다른 데 씁니다 — QuickTime 으로 아이폰 화면을 «케이블로» 녹화하는 것이 핵심입니다.**

| | 아이폰 자체 화면 기록 | **QuickTime + 케이블 (권장)** |
|---|---|---|
| 상태바 빨간 녹화 표시 | 남습니다 | **안 남습니다** |
| 해상도 | 기기 해상도 | **기기 해상도 그대로, 깔끔** |
| 파일 | 아이폰 사진 앱 → 옮겨야 함 | **맥에 바로 .mov** |
| 알림 배너 끼어듦 | 위험 | 방해금지로 동일하게 막음 |

## 방법

```
1. 아이폰을 케이블로 맥에 연결 → 아이폰에 뜨는 「이 컴퓨터를 신뢰」 누르기
2. 맥에서 QuickTime Player 실행
3. 파일 → 새로운 동영상 녹화
4. 빨간 녹화 버튼 «옆의 ∨» 클릭
     카메라 : 진성 님 아이폰 선택
     마이크 : 없음 (소리 필요 없습니다)
5. 맥 창에 아이폰 화면이 그대로 비칩니다
6. 녹화 시작 → 그다음부터는 «아이폰을 손으로» 조작합니다 (맥 창을 클릭하지 않습니다)
```
