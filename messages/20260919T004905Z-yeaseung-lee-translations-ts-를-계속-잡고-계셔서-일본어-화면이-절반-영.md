## 막힌 것

**1. S15P21E201-1335 (머지 완료, 일부만 고침)**
메뉴판 화면 출처 줄이 일본어 화면에 「**Example** · **한국관광공사 관광사진갤러리**」로, 반은 영어 반은 한국어로 뜹니다. 고치려면 표에 세 줄이 필요합니다:

```
'사진이 흐리거나 잘려서 못 읽은 줄이 %d개 있어요.'
'예시'
'한국관광공사 관광사진갤러리'
```

`frontend:smoke` 의 `check:menu-translations` 가 「메뉴판 화면에 새 문구를 쓰면 표를 반드시 채워라」로 막고 있어서, 표를 못 건드리면 그 화면 문구를 바꿀 수가 없습니다. 그래서 고치려던 것을 **되돌려서** 머지했습니다.

**2. S15P21E201-1340 (새로 만든 것)**

- 값이 끼어든 `tx` **208곳** — 키가 실행할 때마다 달라져 **표에 올릴 수조차 없습니다.** 표를 아무리 채워도 영원히 영어입니다
