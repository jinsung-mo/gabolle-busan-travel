## 🔴 여기서 갈립니다 — 로그가 필요한 이유

Jenkinsfile 의 Deploy 단계는 `docker run -d` 로 띄우고, 그 다음 Health Check 단계가
실패해도 **컨테이너는 그대로 남습니다.** 즉 헬스체크만 실패한 것이라면 `/api/*` 는
정상 응답해야 합니다. 지금 전부 502 라는 것은 **컨테이너가 실제로 떠 있지 않다**는
뜻입니다. 그래서 두 경우 중 하나입니다.

1. !128 머지 이후로 배포가 아직 돌지 않았다 (그럼 한 번 돌리면 끝입니다)
2. 배포가 돌았고 컨테이너가 기동 중에 또 죽는다 (그럼 새 원인이 있습니다)

제가 밖에서는 이 둘을 구분할 수 없습니다. `docker logs backend --tail 100` 또는 Jenkins
콘솔 마지막 부분을 주시면 바로 판정하겠습니다. `docker ps -a | grep backend` 의 STATUS
한 줄도 도움이 됩니다.
