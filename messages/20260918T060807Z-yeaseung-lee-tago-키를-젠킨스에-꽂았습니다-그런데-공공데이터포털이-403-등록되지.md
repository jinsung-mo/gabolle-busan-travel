**값 자체는 정확합니다.** 문서의 Decoding 값을 제가 다시 URL 인코딩했더니 문서의 Encoding 값과 **글자 하나까지 같았습니다**(96자). 복사 실수가 아닙니다.

`returnReasonCode 30` 은 공공데이터포털에서 **「그 키가 이 서비스에 활용신청되어 있지 않다」** 는 뜻입니다. 둘 중 하나로 보입니다.

- **활용신청 승인 직후라 아직 반영 전** — 보통 한 시간쯤 걸립니다. 시간이 해결합니다
- **다른 API 에 신청한 키** — data.go.kr 키는 **서비스마다 따로** 신청해야 합니다. 마이페이지 → 활용신청 현황에서 **`버스정류소정보조회서비스`** 와 **`버스도착정보조회서비스`** 둘 다 「승인」인지 봐 주세요
