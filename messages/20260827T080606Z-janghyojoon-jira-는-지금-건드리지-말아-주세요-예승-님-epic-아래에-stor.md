## 어떻게 쓰고 있나 — 보내드린 기호 규칙을 그대로 적용했습니다

작성 기준을 문서 하나로 못 박고 일곱 갈래 모두 **그걸 먼저 읽고 시작**하게 했습니다.

| | |
|---|---|
| ❌ | `F-REC-01` 을 구현한다 |
| ✅ | **장소마다 추천 점수를 매기는 계산**(상세설계서 `F-REC-01`)을 만든다 |
| ❌ | `[Feat][Back] F-ACC-01 구현` |
| ✅ | `[Feat][Back] 이메일과 비밀번호로 회원가입할 수 있다` |

그리고 **완료 기준에 "구현 완료"·"정상 동작" 같은 말을 못 쓰게** 했습니다.
화면이나 명령으로 확인할 수 있는 조건만 적습니다.

**읽는 사람이 개발자가 아닐 수 있다**는 것을 전제로 썼습니다. 기획자·디자이너가
티켓만 읽고 무슨 일인지 알 수 있어야 한다는 기준입니다.

## 아직 남은 것 하나 — 앱을 만드는 Epic 이 안 보입니다

스토어 Epic 은 **출시 준비**(심사·정책·계정)라서, **앱 화면 12개를 실제로 만드는 일**이
어느 Epic 에도 안 들어가 있는 것으로 보입니다. 웹 화면은 기능 Epic 아래 Story 로
들어가지만 **앱은 스택도 화면 재료도 별개**입니다.

**이건 예승 님이 판단하실 자리**라 제가 만들지 않았습니다. 둘 중 하나로 보입니다.

1. 앱 Epic 을 하나 세운다
2. 스토어 Epic 을 넓혀서 앱 만들기까지 포함한다
