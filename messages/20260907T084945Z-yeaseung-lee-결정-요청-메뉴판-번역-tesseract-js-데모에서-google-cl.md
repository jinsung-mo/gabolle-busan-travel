## 지금 상태

메뉴판 번역이 Tesseract.js(**브라우저·서버에서 도는 오픈소스 OCR — 사진에서 글자를 읽어내는 라이브러리**)
+ 수작업 메뉴 사전으로 만든 데모 수준입니다. 실제 사진은 폰트·각도·조명 때문에 인식 오류가 잦아
클라우드 OCR 전환이 필요합니다.

## 제안

- **OCR**: Google Cloud Vision `DOCUMENT_TEXT_DETECTION`(**문서형 텍스트에 최적화된 Google의 OCR
  모드 — 글자 위치 좌표까지 같이 줍니다**)
- **번역**: 검수된 한식 메뉴 사전을 우선 적용
- **미등록 메뉴**: Cloud Translation Advanced + 음식명 Glossary(**번역이 매번 흔들리지 않게
  고정해 두는 용어집 — "김치찌개"가 항상 같은 영문명으로 나오게 함**)
- **장애 시**: 기존 Tesseract.js로 자동 전환하고 화면에 "간이 인식"이라고 표시
- **생성형 AI(ChatGPT·Gemini 등)는 최종 메뉴명·가격·알레르기 판정에 안 씀** — 확정 정보는 전부
  사전 대조나 신뢰도 높은 OCR 결과에서만 나온다는 뜻입니다

선정 이유: 한국어 OCR과 글자 위치 좌표 지원 / 모델 학습 없이 API 바로 연결 / Translation 용어집으로
음식명 번역 고정 가능 / 현재 UI·메뉴 사전 재사용 가능 → 2~3일 내 웹 MVP 가능.

## ⚠️ 정확성 원칙 — fail-closed(**확실하지 않으면 아예 안 보여주는 방식** — 틀린 정보를
확정적으로 보여주는 것보다 "모른다"고 보여주는 쪽이 안전하다는 원칙)

- 신뢰도 낮으면 결과 안 보여주고 재촬영 요청
- 사전에 정확히 매칭된 메뉴만 확정 번역
- 미등록·불확실 메뉴는 원문 + "번역 정보 없음"
- 불확실한 가격은 숨기고 "가격 확인 필요"
- 알레르기 정보는 검수된 DB에 있을 때만 제공
- 성분 정보 없으면 "성분 미확인·직원에게 확인 필요"
- 메뉴명과 원본 이미지 영역을 같이 보여줘서 사용자가 대조 가능하게

AI·데이터: 메뉴 사전 정리·테스트 사진 준비

**Day 2** — OCR 좌표로 메뉴명·가격 구조화, 사전 정확일치+보수적 유사매칭 / FE: 기존 메뉴판 모달을
서버 OCR 응답에 연결, 실패·저신뢰·미등록 상태 UI

**Day 3** — 실제 메뉴판 사진 30~50장 회귀 테스트, API 실패 시 Tesseract 폴백 검증, 요청 제한·24시간
이미지 해시 캐시, 오역 사례 수정·시연 범위 확정

## ✅ MVP 완료 기준

API 오류·흰 화면 0건 / 인식 실패가 잘못된 번역으로 나오는 사례 0건 / 검수된 대표 메뉴는 정확한
영문명 / 미확인 메뉴·가격·성분은 명확히 "확인 필요" / 테스트 이미지별 예상·실제 결과 기록 /
참고치 — 메뉴명 인식 80%+, 가격 인식 70%+

**범위 제한**: 2~3일로는 웹 기반 안전한 MVP까지입니다. 전체 메뉴판 지원·300종+ 사전 검수·정확한
알레르기 판정·네이티브 앱은 별도 일정이 필요합니다. 이번엔 "전부 무조건 번역"이 아니라 "확실한
