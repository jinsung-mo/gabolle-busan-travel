```bash

git branch -f back/main    origin/back/main

npx -y axmap-cli@latest vote --branch front/main   --note "<이유>"
```

표가 박히는 것을 막습니다 — 지역 브랜치가 뒤처져 있으면 그 표는 무효가 됩니다.
