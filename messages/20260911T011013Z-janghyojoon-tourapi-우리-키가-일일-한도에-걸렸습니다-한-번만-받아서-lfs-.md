## 2. 🔴 돌리시기 전에 꼭 보셔야 할 것 — 안 보시면 재현 님 할당량도 똑같이 날아갑니다

저희가 받은 상세 330건이 **한 건도 안 남았습니다.** 수집기(`bigData/collect/tourapi.mjs`)에 흠이 셋 있습니다.

| 흠 | 실측 |
|---|---|
| 🔴 **저장을 맨 끝에 한 번만 한다** | `writeFile` 이 파일 전체에 딱 한 줄(245행). 중간에 끊기면 **전부 날아갑니다** |
| 🔴 **429 를 따로 안 다룬다** | 코드에 `429` 문자열이 **없습니다**. 한도 초과를 일반 네트워크 오류로 넘깁니다 |
| 🔴 **실패인데 종료 코드가 0** | 아무것도 못 받았는데 "성공" 으로 끝납니다. CI 에 걸면 초록으로 지나갑니다 |

**저희가 이 셋을 고쳐 드릴 수 있습니다.** 받는 족족 파일에 붙이고(끊겨도 남게), 429 를 알아보고 멈추고, 실패하면 0이 아닌 종료 코드를 내도록요. **고친 뒤에 돌리시는 편이 안전합니다** — 원하시면 오늘 중에 고쳐서 `bigData/dev` 로 MR 올리고 쪽지 드리겠습니다.

## 3. 부탁드리는 것

재현 님 키로 **한 번만** 받아서 **Git LFS**(**큰 파일을 git 본체가 아니라 옆 창고에 두고 자리표만 커밋하는 것** — BIMS 때 쓰신 그것)에 올려 주실 수 있을까요. 그러면 저희를 포함해 전원이 `git lfs pull` 한 번으로 같은 자료를 봅니다.

**명령**

```bash
# bigData/.env 에  DATA_GO_KR_KEY=발급받은_디코딩키   (Decoding 키입니다. Encoding 키를 넣으면 인증이 깨집니다)
node bigData/collect/tourapi.mjs --dry-run   # 키·주소만 검사. 호출 안 함
node bigData/collect/tourapi.mjs
node bigData/collect/tourapi-barrier-free.mjs
```

**나올 파일 두 개**

```
bigData/data/raw/tourapi/tourapi-busan.ndjson
bigData/data/raw/tourapi/tourapi-barrier-free-busan.ndjson
```

**🔴 `.gitignore` 는 통째로 풀지 말아 주세요.** `bigData/.gitignore` 의 `data/` 한 줄이 막고 있는데, 거기 적힌 이유(*"OSM 추출본만 285MB 다… 되돌릴 수 없다"*)가 타당합니다. **TourAPI 것만 예외로 뚫는 게** 맞다고 봅니다 — `!data/raw/tourapi/` 한 줄이면 됩니다. 두 파일은 몇 MB 수준입니다.

## 4. 왜 이게 급한지 — 재현 님이 어제 겪으신 것과 같은 자리입니다

- *"사용자가 바다·자연을 골랐는데 후보가 전부 밥집입니다"* → 적재된 곳의 표식이 `FOOD` 뿐이라 그렇습니다. 이 파일의 **관광지 138 + 레포츠 29** 가 들어가야 고를 것이 생깁니다
- **접근성 조건이 결과 0건**인 것도 같은 이유입니다. 무장애 파일 181곳에 값이 든 칸이 23개 있습니다 (출입구 83% · 이동경로 82% · 주차 61% · 엘리베이터 52%). 지금 이걸 메울 자료가 이것 하나뿐입니다

받아 봐야 아래가 그대로입니다. **관광공사 쪽이 비어 있는 것**이라 다시 받아도 같습니다.

- **체류시간 4곳(0.6%)** — 그중 둘은 값이 시간도 아닙니다 (`"공연 및 전시별 상이"`, 영업시간이 잘못 들어감)
