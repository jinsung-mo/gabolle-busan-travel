🔴 **그런데 잡은 초록이었습니다.** 스크립트가 일부러 그렇게 만들어져 있습니다(설정이 없다고 팀 머지를 막지 않는다). 그래서 **로그를 열어보지 않으면 아무도 모릅니다.** 다들 그동안 손으로 옮기고 계셨을 겁니다.

오늘 `JIRA_BASE_URL`·`JIRA_EMAIL`·`JIRA_TOKEN` 셋을 넣었고, 잡을 다시 돌려 **966 이 실제로 「해야 할 일 → 진행 중」으로 가는 것을 확인**했습니다.

## 🟢 각자 설정할 것은 없습니다

프로젝트 단위 CI 변수라 **누가 머지하든, 누구 이름으로 MR 을 올리든 똑같이 동작합니다.** 개인 토큰도, 로컬 설정도 필요 없습니다.

전환 기준은 이렇습니다.

| 어디에 머지되나 | 카드가 가는 곳 |
| --- | --- |
| 파트 `dev` · 파트 브랜치(`back/main` 등) | **진행 중** |
| 최상위 `main` | **완료** |
| 기능 브랜치 | 아무것도 안 함 |

뒤로는 안 갑니다 — 이미 완료인 카드를 나중 dev 머지가 되감지 않습니다.
