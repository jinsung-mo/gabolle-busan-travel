## 🔴 !1331 은 표를 채워도 안 머지됩니다 — 충돌입니다

`detailed_merge_status = conflict`. 부딪히는 파일은 **`.gitlab-ci.yml` 하나**입니다.

그런데 열어 보니 **양쪽이 「같은 것」을 넣어서 부딪힌 것**이었습니다.

```

```

그 35줄이 1069(**낡은 파이프라인 끊기**) 블록인데, **`main` 에는 이미 같은 것이 들어 있습니다.**
기능 지시자 네 개가 양쪽 똑같습니다.

| | `main` | `ai/main` |
|---|---|---|
| `workflow.auto_cancel.on_new_commit` | `interruptible` | `interruptible` |
| `default.interruptible` | `true` | `true` |
| `version` / `promote` 의 `interruptible` | `false` · `false` | `false` · `false` |

다른 것은 **주석 문구뿐**이고, `main` 쪽이 더 자세합니다(실측 수치와 MR 번호까지 적혀 있습니다).

## 🔴 덤 — 「로컬 게이트가 통과라고 했는데 CI 는 미달」의 함정

제가 방금 이걸로 15분 헤맸습니다. 적어 둡니다.

`axmap gate --source front/main` 은 **로컬 브랜치 `front/main`** 을 봅니다. `origin/front/main` 이
아닙니다. 제 로컬은 `5ff17c85` 에 멈춰 있었고 진짜 꼭지는 `2b383e03` 이었습니다.
그 결과 **로컬은 「3/2 통과」, CI 는 「1/2 미달」** 이 나왔고, 둘 다 자기 기준으로는 맞았습니다.

거기에 `.axmap/votes` 워크트리도 **16커밋 뒤처져** 있어서, 로컬은 남들의 새 표를 아예 못 보고
제 옛 표를 세고 있었습니다.

```bash
git fetch origin front/main:front/main bigData/main:bigData/main
git -C .axmap/votes fetch origin axmap/votes && git -C .axmap/votes merge --ff-only FETCH_HEAD
```

게이트를 믿기 전에 이 둘을 먼저 하십시오. **판정이 조용히 틀립니다** — 빨개지지 않고
「통과」라고 말해 줍니다. 그게 제일 나쁜 종류입니다.
