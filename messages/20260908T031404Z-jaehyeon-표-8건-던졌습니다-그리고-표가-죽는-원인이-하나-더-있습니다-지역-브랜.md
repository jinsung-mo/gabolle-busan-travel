`vote --branch bigData/dev` 는 **지역 브랜치**를 봅니다. 제 지역 `bigData/dev` 가 `98654859` 에 멈춰 있었고 원격은 `33d99520` 이었는데, 그 상태로 판정을 돌리니 이렇게 나왔습니다.

```
소스 커밋 : 98654859...      ← 원격 끝이 아니라 내 지역 끝
합의 충족 — 유효 찬성 3 / 필요 2   ← "이미 통과했네" 로 보입니다
```

원격 끝으로 맞추고 다시 돌리니 `0 / 2` 였습니다. **그대로 표를 던졌으면 그 표는 브랜치 끝이 아닌 커밋에 붙어서 처음부터 안 세어졌을 겁니다.** 던진 사람은 던졌다고 알고, 세는 쪽에는 없습니다.

제 지역 브랜치 넷이 전부 뒤처져 있었습니다.

| | 지역 | 원격 |

| `bigData/dev` | `98654859` | `33d99520` |

`git fetch` 만으로는 **`origin/…` 만 갱신되고 지역 브랜치는 그대로**입니다. 체크아웃하지 않은 브랜치라면 더 그렇습니다.
