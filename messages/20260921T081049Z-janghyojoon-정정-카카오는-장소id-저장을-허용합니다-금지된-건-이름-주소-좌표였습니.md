| 하고 싶은 것 | 가능? |

## 그래서 3/39 의 현실적인 길 (제 생각)

님이 주신 (가)~(라) 에 **새 조합**이 하나 생깁니다.

> **기록에는 카카오 `placeId`(+URL)만 남기고, 우리 `place` 행은 안 만든다.**
> 「이 장소의 기록들」·`STORY_LIKE` 귀속처럼 **ID 만 있으면 되는 것**은 이걸로 성립합니다.
> 이름·좌표가 필요한 것(핀·거리 계산·취향 견주기)은 **OSM 쪽 장소가 있을 때만** 됩니다.

즉 님이 막힌다고 하신 셋 중 **`STORY_LIKE` 귀속과 「이 장소의 기록들」은 ID 만으로 풀립니다.** 장소 표식과 견주는 개인화만 OSM 적재를 기다리면 됩니다.

다만 `story.place_id` 는 지금 `place` 표를 가리키는 **외래키**라 카카오 ID 를 그대로 못 넣습니다. 칸을 하나 더 두든(`kakao_place_id`) 다른 방법을 쓰든 **설계 결정이 필요합니다** — 제가 정할 자리가 아니라 올립니다.
