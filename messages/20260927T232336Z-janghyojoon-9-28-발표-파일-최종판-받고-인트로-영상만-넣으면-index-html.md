## 2. 인트로 영상 넣기 (이것 하나뿐)
- 1장면 2분 영상(팀 소개 영상 `영상포폴.mp4`, 2.7GB)만 커서 저장소에 없습니다.
- 받은 폴더의 `assets` 안에 **`intro.mp4`** 라는 이름으로 넣으면 끝입니다. **코드의 경로는 안 고쳐도 됩니다** — 모든 그림·영상을 발표 폴더 기준(`assets/…`)으로 찾아서, 어느 컴퓨터 어느 폴더에 받아도 그대로 열립니다.
- 안 넣으면 1장면 영상 자리에 자리표시만 보이고 나머지는 다 보입니다. 다른 영상(8장면 둘)은 저장소에 들어 있습니다.

## 3. 열기
- `index.html` 을 크롬으로 엽니다.
- 특정 장면부터: 주소 끝에 `#장면.단계` — 예: `…/index.html#8.5`. 앞부분(`file:///C:/Users/…`)은 받은 자리에 따라 사람마다 다르고 `#8.5` 는 같습니다.
- 인터넷은 글꼴을 받을 때만 씁니다(없으면 맑은 고딕).

## 4. 넘기는 법
- 클릭 · → · 스페이스: 다음 / 오른쪽 클릭 · ←: 이전 / F: 전체 화면 / N: 발표자 메모(대사 · 시간 · 주의할 숫자)
- 1-0 에서 첫 클릭은 **영상 재생**입니다(넘기기 아님).
- 흐름: 1장면(영상 · 사진 카드 · 대화) → 2장면(설문) → 4장면(홈 · 피드 · 데스크톱 · 시연 · 내 여행 · 큰 지도) → 6장면(경사 · 가게 · 그림자) → 8장면(메뉴판 AI · 카프카 · 새벽 스파크) → 10장면(만든 것 · axMap · 감사합니다)
- 시연: 4-9 시연 폰 틀에서 Ctrl+Alt+S(시연.bat 바로 가기 키)로 폰 화면 → 시연 → 폰 화면 창 Alt+F4 → 클릭으로 다음.
- 오른쪽 아래 장면 번호와 하단 진행 막대는 뺐습니다.
