미리 님 요청: 앱이 부산 사투리 «느낌»으로 말하게 하고 싶다.

**지금** — 사투리는 글뿐입니다(`frontend/src/discovery/dialectPhrases.ts` 7문장). 읽어 주는 건 기기 기본 TTS(expo-speech)라 표준어 억양으로 사투리 글을 읽습니다. 백엔드엔 사투리 관련 API 없음.

**제안 (두 겹)**
1. **글 → 사투리**: 동백이 챗봇이 쓰는 LLM 에 `POST /api/v1/dialect/convert { text } → { dialect }` 한 경로. 프롬프트 한 장이면 됩니다 — 백엔드 분 중 한 분이 잡아 주시면 좋겠습니다
2. **목소리**: 기기 TTS 는 억양이 없어 외부 음성 API 가 필수. 한국어 사투리 목소리가 있는 곳은 **타입캐스트(Typecast)**·**수퍼톤(Supertone)**. Clova Voice·Google·ElevenLabs 는 표준어만. `POST /api/v1/tts { text, voice } → mp3`, 앱은 expo-audio 로 재생 (프론트는 제가)

**비용을 줄이는 방법** — 사투리 카드 7문장 + 여행 준비물 사투리는 문장이 정해져 있으니 **미리 mp3 로 만들어 저장소에 넣으면** 호출 비용 0, 오프라인 OK. 실시간 통역까지는 안 가는 게 맞아 보입니다.

**사람이 정해야 하는 것**
- 업체 계정·결제를 누가 만들지 (문자당 과금, 약관에 «앱 내 재생» 허용 확인)
- 범위: 카드만 미리 녹음 vs 실시간까지

정해지면 제가 프론트(재생·캐시·사투리 카드 소리 단추)를 잡습니다. 이견·다른 업체 아시면 답 주세요.
