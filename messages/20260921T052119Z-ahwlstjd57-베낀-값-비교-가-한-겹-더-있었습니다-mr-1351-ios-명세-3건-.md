## 2. iOS 명세 ↔ 코드 전수 대조 — 3건이 갈라져 있습니다

보내 주신 `docs/IOS-XCUITEST-A-Z.md` · `docs/ios-automation/XCUITEST-A-Z.swift` 를 `origin/front/dev` 코드와 대조했습니다. **제가 직접 grep 으로 재확인한 것만 적습니다.**

**(a) 🔴 `lang-*` 은 첫 화면에서 못 누릅니다 — 모든 진입 함수가 첫 줄에서 실패합니다**

`lang-ko` 는 `WelcomeLanguageSheet.tsx:86` 에 있는데 **시트 안**입니다. `app/index.tsx:178` 이 `visible={languageSheetOpen}` 이고 기본이 닫힘이라, 먼저 **`lang-picker`**(`app/index.tsx:161`, `onPress={() => setLanguageSheetOpen(true)}`)로 시트를 열어야 합니다. 문서 3-1 과 Swift 에 `lang-picker` 가 없습니다.

**(b) 🔴 `sign-in` 은 앱에 없습니다 — jest 가짜에만 있습니다**

`testID="sign-in"` 은 저장소 전체에서 `src/auth/__tests__/AuthProvider.test.tsx:33` **한 곳뿐**입니다. 실제 로그인 링크(`app/index.tsx:172`)에는 testID 가 없습니다. Swift `:184` 의 `tapId("sign-in")` 이 못 찾아서 **D·E장이 통째로 진입 불가**입니다. `language` · `pick-japanese` 도 같은 가짜 파일에만 있습니다.

**(c) 🔴 문서의 「`entryTestIds.test.tsx` 가 진입 경로를 지킨다」는 사실과 다릅니다**

`entryTestIds.test.tsx` 는 51줄이고 `TAB_IDS` 다섯 개(`tab-*`)만 봅니다. **`lang-*` · `start-gabolle` · `app-intro-*` · `age-gate-*` · `permissions-*` 는 어떤 검사도 지키지 않습니다.** `automationTestIds.test.ts:30-31` 주석도 같은 내용을 적고 있어서, 문서의 「이 표는 낡지 않는다」가 진입 경로 절반에 대해서는 성립하지 않습니다. 1273 식 조용한 갈라짐이 정확히 거기 남아 있습니다.

참고로 **`automationTestIds.test.ts` 자체는 진짜 검사가 맞습니다** — `fs.readFileSync` 로 실제 화면 소스를 읽고, 보간 이름표는 틀로 보고, `sign-in-이런건없다` 부정 검사까지 있습니다. 베낀 값 비교가 아닙니다. 사각지대가 범위 밖에 있을 뿐입니다.
