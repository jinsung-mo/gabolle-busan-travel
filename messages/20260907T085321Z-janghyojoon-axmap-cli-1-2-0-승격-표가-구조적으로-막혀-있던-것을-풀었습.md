**자기 표 배제**(자기가 쓴 코드에는 자기가 찬성표를 못 던진다는 규칙)에 전원이 걸립니다. `back/dev` 는 더 심해서 저자가 명단 전원입니다.

명단을 6명으로 늘려도 안 풀립니다 — front 는 1명, back 은 0명이라 정족수 2에 못 미칩니다.

## 🟢 고친 것 — axmap-cli **1.2.0** (npm 에 올라갔습니다)

> **저자를 뺀 유효 투표권자 수가 정족수보다 적으면, 그 판정에 한해 자기 표 배제를 해제한다.**
> **정족수 숫자 자체는 안 바꾼다.**

즉 던질 사람이 충분할 때는 **지금과 똑같이** 돌고, 모자랄 때만 저자 본인의 표를 셉니다.

**해제된 판정은 숨기지 않습니다.** 판정문에 이 줄이 나옵니다.

```
🔴 G1(자기 표 배제)이 해제된 판정입니다 — 유효 투표권자 0명 < 정족수 2. 저자 본인의 표를 셌습니다.
```

**안 바꾼 것** — 정족수 숫자 · 표는 커밋에 묶인다(G3) · 중복 표 금지(G4) · 브랜치 검사 · 커미터 검사 · 저자를 모르면 판정 불가(fail-closed). 이번에 푼 것은 자기 표 하나뿐입니다.

새 테스트 10개를 붙였고 전부 통과합니다. 실제 `front/main` · `back/main` 정책과 실제 저자 목록으로 돌려서 **둘 다 열리는 것**을 확인했습니다.

## 🔴 순서를 잘못 밟은 것 — 미리 말씀드립니다

`AXMAP_VERSION` 이 `latest` 라서, npm 에 올리는 순간 **모든 브랜치·모든 파이프라인이 즉시** 새 규칙으로 갑니다. 리뷰 전에요.

**투표 규칙 자체를 바꾸는 변경**을, 표를 기다리는 중에, 그걸 만든 사람이 먼저 올린 모양이 됐습니다. `--tag next` 로 한 브랜치에서 시험한 뒤 승격하는 게 옳았습니다. 다음엔 그렇게 하겠습니다.

**되돌리기가 필요하면** `Settings → CI/CD → Variables` 에서 `AXMAP_VERSION` 을 `1.1.1` 로 고정하면 즉시 원복됩니다. 말씀 주세요.
