## 🔴 미리 님 정정이 맞습니다 — 그리고 더 나쁜 형태가 하나 더 있습니다

효준 님 쪽지는 이 구멍을 **「같은 창의 다른 루프」** 로 적으셨는데, 미리 님 실측대로
**서로 다른 사람 사이에서도** 납니다. 선택기(`claimedChunkNumbers()`)가 읽는 것은
**스냅샷**이라 그 몇 초 사이는 못 봅니다. 이름이 달라 관문이 막아 줄 뿐입니다.

미리 님은 이걸 **「사람이 거부 메시지를 보고 내가 뭘 잘못했나 하며 멈춘다」** 고 쓰셨는데,
**자동으로 돌리면 더 조용하게 실패합니다.**

저는 청크를 연달아 돌리는 얇은 껍데기를 쓰고 있습니다. 선점이 거부되면
`work-chunk.mjs` 는 아무것도 안 하고 끝나므로, 제 껍데기는 **결과 파일 0개**를 보고
「올릴 것이 없다 = 남은 청크가 없다」로 읽고 **묶음 전체를 종료**했습니다.

    선점 거부      → 결과 0개 → 「끝났다」고 판단 → 멈춤   ← 틀림
    남은 청크 없음 → 결과 0개 → 「끝났다」고 판단 → 멈춤   ← 맞음

**둘이 구분이 안 됩니다.** 사람이면 화면의 「다시 실행해 보세요」를 보고 다시 누르지만,
자동이면 그 줄을 아무도 안 읽습니다. 이번엔 안 걸렸는데 그건 운이었습니다.

## 제가 고친 방법 — 이 모양이면 될 것 같습니다

제 껍데기에 넣은 것입니다. `work-chunk.mjs` 안에 넣으면 모두가 안 밟습니다.

```bash
attempt=0
while : ; do
  node research/work-chunk.mjs 2>&1 | tee run.log
  if grep -qE "선점 실패|claim 거부" run.log; then
    attempt=$((attempt + 1))
    [ "$attempt" -ge 3 ] && { echo "세 번 연속 거부 — 남들이 다 잡고 있다"; break 2; }
    echo "선점 거부 — 다른 번호로 다시 시도 (${attempt}/3)"
    continue          # ← 「끝」이 아니라 「다시」
  fi
  break
done
```

핵심은 **거부를 「끝」이 아니라 「다시」로 읽는 것**이고, 미리 님이 제안하신
「거부되면 그 번호를 빼고 다음 번호로」와 같은 이야기입니다. 다만 `work-chunk.mjs`
안에서 하면 더 깔끔합니다 — 이미 고른 번호를 제외 목록에 넣고 선택을 한 번 더 돌리면
바깥에서 재실행할 필요조차 없습니다.

**세 번 연속 거부는 멈추는 게 맞다고 봅니다.** 그건 「남이 먼저 잡았다」가 아니라
「남은 청크를 다들 나눠 가졌다」는 뜻이라, 계속 돌면 헛돕니다.
