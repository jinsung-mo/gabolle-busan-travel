효준님, 예승입니다(Claude 가 대신 적습니다). 시험 페이지(!1823)로 실제 S10 을 붙여 봤고 **폰 화면이 틀 안에 딱 맞게 떴습니다.** 사용자가 눈으로 확인했습니다.

**환경**
- PC: 이예승 노트북(Windows 11) · 모니터 2880×1800 · **윈도 배율 200%** · 크롬 확대 100%(Ctrl+0) · F11 전체 화면
- 페이지 「지금 값」 기준: 창 1440×900 · 배율 200% · 무대 배율 0.750
- scrcpy **v4.1** (win64) · S10 SM-G973N, Android 12, USB

**결과**
- ❌ 명령 ①(논리 px `564,120,312,659`): 창이 **정확히 절반 크기·절반 위치**(왼쪽 위)에 떴습니다. → 이 PC 의 scrcpy 는 좌표를 **물리 px(실제 화소)** 로 받습니다.
- ✅ 명령 ②(물리 px `--window-x=1128 --window-y=240 --window-width=624 --window-height=1318`): 틀에 딱 맞음.
- 그래서 **배율 100% 가 아닌 PC 에서는 ② 가 기본**으로 보입니다(배율 100% 면 ①=② 라 상관없음).

**알게 된 것 두 가지**
1. PC 에 이미 Android SDK adb 가 있으면 scrcpy 에 들어 있는 adb 와 버전이 달라 서로 끊을 수 있습니다. 배치 파일에 `set ADB=C:\android-sdk\platform-tools\adb.exe` 로 한쪽만 쓰게 했습니다.
2. 모진성 님 지적대로 크롬 확대가 100% 가 아니면 페이지의 「배율 %」와 좌표가 같이 틀어집니다. 시험 순서 1번에 「Ctrl+0」을 넣는 게 안전합니다.

**아직 못 본 것**: 단축키(Ctrl+Alt+S) 흐름, 창이 뜨기까지 걸린 초, 케이블 뺐다 꽂기. 창은 배치 파일 더블클릭 뒤 2~3초 안에 떴습니다(체감). 발표 모니터·프로젝터 해상도가 다르면 좌표도 다시 뽑아야 합니다.
