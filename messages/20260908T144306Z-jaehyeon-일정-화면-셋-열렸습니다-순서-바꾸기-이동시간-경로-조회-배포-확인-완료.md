## ① 방문 순서 바꾸기 — 끌어 옮기기 화면(-277) 붙이실 수 있습니다

```
POST /api/v1/itineraries/{itineraryId}/days/{dayIndex}/reorder
{ "itemKeys": ["...", "...", "..."], "baseVersion": 3 }
```

🔴 **그날 항목을 전부, 원하는 순서대로 보내십시오.** "이 항목을 3번째로" 가 아닙니다. 하나라도 빠지거나 겹치면 400 입니다 — 빠진 것을 서버가 조용히 뒤에 붙이면 **보내지 않은 순서를 돌려받게** 되기 때문입니다.

응답은 더하기·고정과 같은 모양(**200**, 바뀐 일정 전체 + 새 판 번호)이라 다시 조회하실 필요 없습니다.

| 상황 | 응답 |
|---|---|
| 목록이 그날 항목과 안 맞음 | 400 `ITINERARY_DAY_ORDER_MISMATCH` (빠진 개수·모르는 개수가 함께 옵니다) |
| 고정된 항목을 옮기려 함 | 409 `ITINERARY_LOCKED_ITEM_MOVED` (어느 항목인지 옵니다) |
| 낡은 `baseVersion` | 409 |
| VIEWER | 403 · 비회원·없는 일정 | 404 |

**고정된 방문지는 자리를 못 옮깁니다.** 제자리면 나머지는 얼마든지 바꿀 수 있습니다. 화면에서는 그 항목을 끌 수 없게 막거나, 409 를 받으면 "고정을 먼저 푸세요" 로 안내하시면 됩니다.

시각은 **자리에 붙어 있습니다.** 9시·11시·13시 세 자리가 있으면 그 시각은 그대로고 누가 어느 자리에 앉는지만 바뀝니다.

## ② 일정 항목에 이동시간이 실립니다

`days[].items[]` 에 둘이 붙었습니다(맨 뒤라 옛 앱은 무시합니다).

- `travelDurationMin` — 이 방문지로 **오는 데** 걸리는 분. 그날 첫 방문지 앞에는 구간이 없어 `null`
- `travelDataStatus` — 그 값을 얼마나 믿을 수 있는지

🔴 **`travelDataStatus` 를 반드시 보셔야 합니다.**

| 값 | 뜻 | 화면 |
|---|---|---|
| `VERIFIED` | 길찾기 실제 응답 | 그대로 |
| `ESTIMATED` | 직선거리 어림값 | **"예상"** 이라고 밝혀 주십시오 |
| `UNKNOWN` | 좌표가 없어 못 쟀다 | 아무것도 안 띄웁니다 |
| `null` | 이 기능 이전에 만들어진 판 | 아무것도 안 띄웁니다 |

참·거짓이 아닌 이유가 이겁니다 — 뒤의 둘을 참·거짓으로는 구분할 수 없는데, **어림값은 보여줘야 하고 못 잰 것은 숨겨야** 합니다.

지금은 **대부분 `ESTIMATED` 로 나올 것**입니다. 자동차 경로만 실제 응답이 오고 도보·대중교통은 어림값입니다(아래).

## ③ 경로 조회 창구

```
GET /api/v1/routes/directions?originLat=&originLng=&destLat=&destLng=&mode=CAR|TRANSIT|WALK
```

경로 상세·내비 화면(`-208`·`-214`)에 쓰실 수 있습니다. 거리·소요시간·택시요금·통행료·경로 좌표·단계별 안내가 옵니다.

🔴 **`path` 는 `[경도, 위도]` 순서입니다**(GeoJSON 과 같습니다). 뒤집으면 지도에 엉뚱한 곳이 그려집니다.

🔴 **`estimated` 가 참이면 실제 경로가 아닙니다.** 요금은 그때 `null` 로 옵니다 — 지어내지 않았습니다. `0` 과 `null` 은 다릅니다(0 은 "돈이 안 든다").

**대중교통은 아직 진짜 경로가 아닙니다.** 카카오가 자동차 길찾기만 공개하고 지하철·버스 경로를 주는 공개 API 가 없습니다. 지금 대중교통·도보로 부르면 직선거리 어림값이 오고 환승 수는 비어 있습니다. 업체를 정하는 것이 먼저라 `-753` 으로 나눠 뒀습니다.
