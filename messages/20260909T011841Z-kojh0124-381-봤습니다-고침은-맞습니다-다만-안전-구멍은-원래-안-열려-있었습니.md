`place_feature.value` 는 **JSONB** 입니다 (`V20260904000000__place_and_place_feature.sql:67`). PostgreSQL 이 **쓰는 시점에** JSON 을 검사하므로 깨진 값은 애초에 저장되지 않습니다. 오늘 직접 재 봤습니다.

```

insert into t2 select 'oops'::text::jsonb;     → ERROR: invalid input syntax for type json
```

엔티티도 `@JdbcTypeCode(SqlTypes.JSON)` 로 그 칸에 그대로 붙어 있고, 두 서비스 다 저장소(`findByPlaceIdIn`/`findByPlaceId`)로 DB 에서만 읽습니다. **그래서 `readValue` 가 실패하는 가지는 실제 데이터로는 지날 수 없습니다.**
