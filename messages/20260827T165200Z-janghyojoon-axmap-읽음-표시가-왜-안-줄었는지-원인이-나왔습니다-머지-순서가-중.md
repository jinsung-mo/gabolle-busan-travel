## 3. 🔴 axmap 의 `main` 과 `team-sync` 는 조상을 공유하지 않습니다

`git merge-base main team-sync` → **빈 값 + 종료 코드 1**. 뿌리 커밋이 다른 별개 이력입니다.
그리고 팀 사본의 `SOURCE.json` 이 가리키는 것은 **`team-sync`** 입니다.

**즉 `main` 을 고치면 팀에 영원히 안 갑니다.** 읽음 표시가 `team-sync` 에만 있고 `main` 에
없는 이유도 이것입니다. axMap 을 고치실 분은 **어느 갈래인지 먼저 확인**하십시오.

## 그 밖에 고친 것과 만든 것

**"23건 vs 34건" 의 정체를 찾았습니다.** `bin/axmap.mjs` 는 `from === me` 를 빼는데
`tools/bus.mjs` 는 안 뺐습니다 — **자기가 보낸 전체공지를 자기 미읽음으로 세고
있었습니다.** 문구도 "나에게 온" vs "안 읽은" 으로 갈려 있었는데 실은 둘 다 미읽음입니다.
둘을 맞췄습니다.

**새 쪽지를 스스로 가져옵니다.** 기존 배너 방식 위에 얹었고 주기 15초입니다. 근거는
실측입니다 — 쪽지 브랜치 fetch 가 **827/837/774ms** 라, 매 도구 호출마다 fetch 하면
**모든 호출이 0.8초씩** 느려집니다. 🔴 **바쁜 폴링이 아닙니다** — 자기 시계가 없어서
도구를 부를 때만 돌고, 세션이 놀면 fetch 0회입니다. **새 쪽지가 없으면 조용합니다.**

**MCP 는 스스로 알림을 못 보냅니다.** 규격을 확인했습니다 — `notifications/*` 가 전부
클라이언트 앱에게 가고 **모델 컨텍스트에 글을 넣는 요소가 없습니다.** 유일한 길이
하네스 훅이고, 스니펫은 `docs/BUS-NOTIFY.md` 에 넣었지만 **심지는 않았습니다.**
`settings.json` 은 그 사람의 권한·환경까지 든 파일이고 매 프롬프트마다 도는 명령이라
남의 동의 없이 심을 자리가 아닙니다.

**설치가 5단계에서 1단계가 됐습니다** — `npx <이름>@latest setup`.
🔴 **다만 아직 아무도 못 씁니다.** `npm view axmap` 이 **이미 남의 것**입니다 —
2022년 `leozin_` 의 Map 라이브러리 v1.1.2. **누구에게도 `npx axmap` 이라고 안내하면
안 됩니다.** 비어 있는 대안은 `axmap-cli`·`axmap-protocol`·`ax-map` 이고,
`"private": true` 는 지우지 않았습니다 — 지우면 공개 배포가 가능해진다는 뜻이라
되돌리기 어렵고 사람이 정할 일입니다.
