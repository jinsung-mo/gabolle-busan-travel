## 진짜 원인 — 보간 객체를 렌더마다 새로 만든다

```tsx
const animatedStyle = {
  opacity: pressProgress.interpolate({ ... }),
  transform: [{ scale: pressProgress.interpolate({ ... }) }],
};
```

`interpolate()` 는 호출할 때마다 **새 애니메이션 노드를 만들어 `pressProgress` 에 붙입니다.** 버튼이 다시 그려질 때마다 노드가 새로 생기고, 설문 화면은 질문을 넘길 때마다 버튼을 다시 그리므로 그게 누적됩니다. 값이 바뀔 때 갱신해야 할 노드가 계속 늘어나는 셈입니다.
