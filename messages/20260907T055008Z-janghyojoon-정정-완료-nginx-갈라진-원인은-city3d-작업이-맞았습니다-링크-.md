**아까 "city3d 작업 때문이 아니다" 라고 한 것은 제가 틀렸습니다. city3d 작업이 맞습니다.** 그리고 방금 고쳤습니다.

## 범인은 한 줄이었습니다

```
2026-09-06T02:55:23.947  sudo sed -i '/server_name .../r /tmp/city3d.conf'
                              /etc/nginx/sites-enabled/default
```

🔴 **`sed -i` 는 파일을 고치는 게 아닙니다.** 옆에 임시 파일을 만들고 **이름을 갈아 끼웁니다.**
그래서 바로가기(심볼릭 링크) 이름을 겨누면 **그 자리에 진짜 파일이 놓이고 링크가 사라집니다.**

## 제 추론이 왜 거꾸로였나

저는 *"02:55 백업이 링크였으니 city3d 작업은 무죄"* 라고 했습니다.
그 백업은 **끊어지기 18밀리초 전**에, **같은 스크립트가** 찍은 것이었습니다. 알리바이가 아니라 지문 옆이었습니다.

그리고 `23:43:28` 은 갈라진 순간이 아닙니다 — `sed -i` 는 **돌 때마다 새 파일을 만들어서**, 그날 다섯 번 돈 것 중 마지막 흔적일 뿐입니다.

**근거 넷 (전부 서버에서 실측)**

* 링크는 09-01 `nginx-common` 설치 때 **패키지가** 만든 것 (시각이 초 단위로 일치)
* 02:55:23.929 `cp -a` 백업 결과가 **링크** → 그 순간까지 살아 있었다
* 다음 `cp -a` 백업(04:32)은 **실파일**이고 그 시각이 **02:55:23.949** → 사망이 20밀리초 안으로 좁혀진다
* 서랍(`sites-available`)에 `city3d` 가 **0회** → 09-06 작업이 서랍에 한 번도 안 닿았다

그날 무대를 겨눈 `sed -i` 는 **다섯 번**입니다 — 02:55(city3d 블록) · 04:32(캐시) · 23:40(CORS) · 23:42(always) · 23:43(root). **전부 city3d 타일 작업**입니다.

## 고쳤습니다 (링크 복구)

무대 쪽 내용을 서랍으로 옮기고, 무대 자리를 다시 링크로 되돌렸습니다.
무대 쪽이 서랍 쪽을 **완전히 포함**해서(무대에만 있는 줄 53, 서랍에만 있는 줄 **0**) 잃은 내용이 없습니다.
백업은 `/etc/nginx/backups/` 에 남겼습니다.

**되돌린 뒤 확인**

| | |
| --- | --- |
| `sites-enabled/default` | 다시 **심볼릭 링크** ✅ |
| 프론트 `/` · `/city3d/` · 타일 | **전부 200** ✅ |
| 문법 검사 | 통과한 **뒤에만** 반영(`reload`). `restart` 아님 — 새 설정이 잘못돼도 기존 것이 유지됩니다 |

**이제 서랍(`sites-available`)을 고치면 반영됩니다.** 이예승 님, 보안 헤더 작업 이어가셔도 됩니다.

## 🔴 앞으로 — 이 한 줄이면 다시 안 납니다

| | |
| --- | --- |
| ❌ | `sites-enabled/default` 를 겨눈 `sed -i` |
| ✅ | **`sites-available/default` 를 겨눈다** |
| ✅ | 꼭 무대를 겨눠야 하면 `--follow-symlinks` 를 붙인다 |

`sed -i` 자체가 나쁜 게 아닙니다. 09-02~09-05 에도 여러 번 돌았는데 **전부 서랍을 겨눠서** 아무 일도 없었습니다.
09-06 02:55 가 **처음으로 무대 이름을 직접 겨눈 순간**입니다.

**살리는 것 / 죽이는 것**

* 산다 — 리다이렉션(`>`) · `tee` · 파이썬 `open(w)` · `--follow-symlinks` 붙인 `sed` · 옵션 없는 `cp`
* 죽는다 — **`sed -i`** · `mv` · `cp -a` · `cp -P` · `vim`(설정에 따라)

## 🔴 함정 하나 더

`nginx.conf` 는 `sites-enabled` 폴더를 **확장자를 안 가리고** 통째로 읽습니다.
그 안에 `default.bak` 을 만들면 **nginx 가 그 백업도 설정으로 읽습니다.** 이 서버에서 두 번 났습니다.
**백업은 처음부터 그 폴더 밖에** 만드세요.
