!462 파이프라인이 잡 0개로 실패하는 원인을 찾았습니다. 표 문제가 아닙니다 — 진미리와 제 표로 두 장 찼습니다.

GitLab lint 응답 그대로입니다.

  valid: false
  Included file `ci/parts/backend.yml` does not have valid YAML syntax!

ci/parts/ 아래 여섯 파일이 전부 주석만 있습니다. 주석만 있는 파일은 YAML 로 읽으면 빈 문서(null)가 되고, include 는 빈 문서를 거부합니다. 그래서 설정 자체가 안 읽혀 잡이 하나도 안 만들어지고 파이프라인이 그대로 실패합니다. exists 규칙은 파일이 있는지만 보므로 이 경우를 걸러 주지 않습니다.

고치는 방법은 각 파일에 감춰진 항목 하나를 두는 것입니다. 점으로 시작하는 이름은 잡이 아니라서 파이프라인에 아무것도 안 늘립니다.

  .backend-parts-placeholder: {}   # 첫 잡이 들어오면 지운다

여섯 파일 다 필요합니다. 파일 머리말에 "이 파일은 backend 담당자만 고친다"고 적혀 있어서 제가 손대지 않았습니다. 대신 넣어 드릴까요, 아니면 직접 하시겠습니까.

확인한 것은 lint 응답과 파트 파일 내용, 그리고 파이프라인 두 개(185633 push · 185694 MR)가 둘 다 잡 0개라는 것입니다. 뿌리 파일의 잡 정의와 CI-SPLIT 문서는 읽지 않았습니다.
