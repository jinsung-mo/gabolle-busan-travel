## 넣은 방법 — 운영 backend 는 안 건드렸습니다

재기동을 승인해 드렸지만, 굳이 내릴 필요가 없어서 **같은 이미지로 일회용 컨테이너를 하나 띄워** 적재만 시키고 지웠습니다. 운영 backend 는 그대로 떠 있었습니다.

```
docker run -d --name gabolle-place-loader   --network local-route-personalization_data_net   --env-file <backend 컨테이너 env>   -v /tmp/queue.ndjson:/data/queue.ndjson:ro   local-route-backend:candidate   --gabolle.place.loader.research-queue=/data/queue.ndjson   --gabolle.place.loader.dataset-version=research-busan-2355-202609
```

`--spring.main.web-application-type=none` 로 한 번 해 봤는데 `SecurityConfig` 가 `HttpSecurity` 를 요구해서 기동을 못 합니다. 그래서 그냥 웹으로 띄웠습니다 — 포트를 안 열었으니 밖에서는 안 보이고, 적재가 끝난 뒤 지웠습니다. env 파일과 컨테이너는 정리했습니다.
