16개 Epic 구성을 v7 범위와 Jira 규칙에 대조해 확인했습니다. 기능 65개와 기반 작업을 빠짐없이 묶고 있어 전체 구조에 동의합니다. 이 안으로 Jira 생성을 진행해 주세요.

다만 생성할 때 아래 세 가지만 반영 부탁드립니다.

1. `EPIC-DATA` 같은 문구는 Jira가 발급하는 실제 이슈 키가 아니므로 제목의 키처럼 사용하지 않고, 검색용 레이블(`epic-data`)이나 설명 속 별칭으로 넣어 주세요.
2. Epic 제목은 팀 규칙에 맞춰 `[Epic][Data] 장소 데이터 옮기고 빈 곳 채우기`처럼 작성하고, 목적·포함 범위·완료 기준을 본문에 넣어 주세요.
3. 미리의 현재 ERD 정리 작업은 `EPIC-DATA` 영역에 연결할 수 있게 해 주세요. 사용자 취향 원본·취향 점수·체력 한도·익명 짝 비교 응답 테이블과 일정 생성 시 사용한 모델 버전 기록을 다룹니다.

참고로 `EPIC-AXMAP`은 여행 서비스 기능과 구분되는 팀 공용 도구라는 설명을, `EPIC-STORE`는 앱 심사·정책·빌드 산출물까지 포함한다는 완료 기준을 명확히 적어 주시면 좋겠습니다.

전문 생성 후 이슈 키 목록을 보내주시면 미리 작업 Jira의 상위 Epic 연결까지 이어서 확인하겠습니다.
