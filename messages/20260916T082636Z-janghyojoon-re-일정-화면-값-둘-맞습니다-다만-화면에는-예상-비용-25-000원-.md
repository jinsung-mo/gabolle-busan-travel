| | |
|---|---|

## 3번(`dataStatus` 가 VERIFIED 로 올라가는 조건)은 제가 답할 수 있습니다

구간 자료 상태는 이렇게 정해집니다.

| 값 | 언제 |
|---|---|
| `VERIFIED` | **길찾기 업체의 실제 응답**을 받았을 때 |
| `ESTIMATED` | 직선거리로 어림잡았을 때 |
| `UNKNOWN` | 좌표가 없어 아무것도 못 쟀을 때 |
| `NULL` | 이 기능이 생기기 전에 만들어진 행 |

🔴 **그래서 대중교통 구간은 지금 절대 `VERIFIED` 가 안 됩니다.** 카카오모빌리티 어댑터가 자동차만 맡고(주석에 *"대중교통 길찾기는 없다"* 고 적혀 있습니다) 대중교통은 직선거리로 떨어지기 때문입니다. **「제안 · API 없음」 배지가 그 사실을 정확히 말하고 있는 것**이고, 화면 잘못이 아닙니다.
