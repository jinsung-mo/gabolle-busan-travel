같은 모양이 **두 곳**입니다.

| 위치 | 무엇 |
|---|---|
| **~450행** | 배포 경로 `docker run ... local-route-backend:candidate` |
| **~642행** | **되돌리기 경로** `docker run ... local-route-backend:previous` |

642행도 `-e GABOLLE_EXCHANGE_RATE_AUTH_KEY="..." \` 바로 다음 줄이 `# 🔴 S15P21E201-561 — 카프카…` 입니다.
**한 곳만 고치면 「배포는 되는데 롤백은 안 되는」 상태로 남습니다.** 하필 롤백이 필요한 순간에요.

## 서버 실측 (방금)

```
/api/v1/*            → 전부 HTTP 502 (nginx 는 살아 있음)
8080 포트            → 듣는 프로세스 없음
backend 컨테이너     → 존재하지 않음 (docker ps -a 에 없음)
nginx               → location /api/ → proxy_pass http://localhost:8080
이미지              → local-route-backend:latest · :candidate · :previous 모두 있음
kafka 컨테이너      → Up 1시간 (살아 있음)
```

배포 로그에 `docker stop backend` → `No such container` 가 찍힙니다. 즉 **이전 배포가 컨테이너를 못 만든 뒤로 계속 빈 상태**입니다.

## 왜 이렇게 되나 (확인차)

```sh
-e GABOLLE_EXCHANGE_RATE_AUTH_KEY="$GABOLLE_EXCHANGE_RATE_AUTH_KEY" \
# 🔴 S15P21E201-561 — 카프카 ...
```

`\` 가 다음 줄을 **이어 붙인 뒤** `#` 을 만나므로, 그 뒤 전부가 주석이 됩니다 —
`-e GABOLLE_EVENT_KAFKA_*` 넷, `TRANSIT_SERVICE_KEY`, `INTERNAL_API_TOKEN`, `ADMIN_EMAILS`,
그리고 **이미지 이름 `local-route-backend:candidate` 까지** 통째로. 그래서 인자가 0개가 됩니다.

로그의 마스킹 목록에는 `GABOLLE_TRANSIT_SERVICE_KEY`·`GABOLLE_INTERNAL_API_TOKEN` 이 있는데
실제 명령에는 안 들어간 것이 그 증거입니다.
