## 프로필 — `GET /api/v1/users/{userId}/profile`

```
userId          문자열
displayName     문자열
followerCount   숫자
followingCount  숫자
storyCount      숫자
following       참/거짓   ← 요청자가 이 사람을 팔로우 중인가
```

`following` 이 있어서 프로필 화면에서 팔로우 버튼 상태를 **따로 안 물어봐도** 됩니다.

## 그 사람의 기록 — `GET /api/v1/users/{userId}/stories`

```
items      배열
nextCursor 문자열 또는 없음   ← 이어 보기
```

`items` 한 줄이 아래 모양입니다. 홈 피드(`/feed/home`)와 **같은 모양**이라 카드 컴포넌트를 그대로 쓰시면 됩니다.

```
id          문자열
author      { id, displayName }
body        문자열
region      문자열
place       { id, name }        ← 연결된 장소. 없을 수 있음
tripId      문자열              ← 없을 수 있음
images      [ { url, position } ]
visibility  문자열
publishAt   문자열 (ISO-8601)
createdAt   문자열
updatedAt   문자열
mine        참/거짓             ← 요청자가 쓴 글인가. 수정·삭제 버튼 판단용
published   참/거짓             ← 공개 시점이 지났나
```

🔴 `mine` 과 `published` 를 서버가 이미 판정해서 줍니다. 화면에서 사용자 아이디를 비교하거나 시각을 계산하지 마세요 — 두 곳이 각자 판단하면 갈립니다.

## 리뷰 목록 — `GET /api/v1/places/{placeId}/reviews`

```
reviews      배열
averageScore 숫자 또는 없음     ← 인증된 리뷰만으로 계산한 평균
```

`reviews` 한 줄:

```
placeReviewId       문자열(UUID)
foodScore           숫자 또는 없음   ← 음식
priceScore          숫자 또는 없음   ← 가격
accessibilityScore  숫자 또는 없음   ← 접근성
onsiteScore         숫자 또는 없음   ← 현장 이용 편의
body                문자열 또는 없음
verified            참/거짓          ← 🔴 방문 인증을 한 사람의 평가인가
region              문자열           ← 지역 단위까지만. 정확한 좌표는 저장 안 합니다
createdAt           문자열
updatedAt           문자열
```

🔴 **`verified` 를 화면에 꼭 드러내 주세요.** 인증 안 된 평가도 저장은 되지만 **장소 평균 점수에는 안 들어갑니다.** 그 차이가 화면에 안 보이면 사용자가 "내 별점이 왜 반영이 안 되지" 로 느낍니다.

## 리뷰 제출 — `POST /api/v1/places/{placeId}/reviews`

보내실 것:

```
foodScore           숫자 또는 생략
priceScore          숫자 또는 생략
accessibilityScore  숫자 또는 생략
onsiteScore         숫자 또는 생략
body                문자열, 최대 1000자
region              문자열, 최대 100자
```

🔴 **`verified` 는 보내지 마세요.** 일부러 요청에 안 넣었습니다 — 인증 여부는 서버가 방문 인증 기록을 보고 정합니다. 화면이 보내는 값으로 정하면 아무나 인증된 평가를 만들 수 있습니다.

네 점수 다 생략해도 되는지(글만 남기기)는 제가 서비스 쪽 검증을 안 봐서 **확실하지 않습니다.** 붙여 보시고 거부당하면 알려 주세요 — 맞추겠습니다.

## 기념품샵 facetKey

아직 확인 못 했습니다. `GET /api/v1/places/facets` 를 한 번 불러 보시면 지금 있는 facet 목록이 그대로 나옵니다 — 거기 있으면 그 값을 쓰시면 되고, 없으면 알려 주세요. 데이터 쪽에 만들어 달라고 넘겨야 하는 건인지 제가 확인하겠습니다.
