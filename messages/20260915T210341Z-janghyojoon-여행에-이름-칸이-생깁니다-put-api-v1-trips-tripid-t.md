## 1. 여행 이름 (S15P21E201-1023) — 서버 작업 끝, MR 준비 중

여행 카드 제목이 날짜뿐이라 **같은 날짜로 두 번 계획하면 두 카드가 글자 하나 다르지
않던** 문제입니다. 서버에 이름 칸을 만들었습니다.

### 응답에 칸이 하나 늘어납니다

`GET /api/v1/trips` 의 각 줄과 `GET /api/v1/trips/{id}` 에 `title` 이 생깁니다.

```
{ "tripId": "...", "title": "9월 부산 혼자", "startDate": "2026-09-19", ... }
```

🔴 **`title` 이 `null` 이면 「아직 이름이 없다」입니다.** 서버가 날짜 문자열을 대신
채워 보내지 **않습니다.** 채우면 「사용자가 붙인 이름」과 「서버가 만든 이름」이 같은
칸에서 구분이 안 되고, 화면이 이름 있는 카드를 다르게 그릴 방법이 없어집니다.

그래서 화면은 지금 쓰는 `dateLabel(trip, tx)` 를 **버리지 말고** 이렇게 쓰시면 됩니다:

```
title ?? dateLabel(trip, tx)
```

기존 여행은 전부 `null` 이라 **화면을 안 고쳐도 지금과 똑같이 보입니다.** 고장나는
곳이 없습니다.

### 이름 바꾸기

```
PUT /api/v1/trips/{tripId}/title      { "title": "9월 부산 혼자" }
200 { "tripId": "...", "title": "9월 부산 혼자", "updatedAt": "..." }
```

| 실패 | 답 |
|---|---|
| 보기 전용 동행자(VIEWER)가 시도 | 403 `TRIP_FORBIDDEN` |
| 참여자가 아님 · 없는 여행 | 404 `TRIP_NOT_FOUND` (구분하지 않습니다) |
| 60자 초과 · 줄바꿈 포함 | 400 `TRIP_TITLE_INVALID`, message 에 몇 자인지 들어 있습니다 |

규칙 셋만 알면 됩니다.

- **빈 문자열을 보내면 이름이 지워집니다.** 지우기 전용 경로는 없습니다 — 「빈 이름」과
  「이름 없음」은 화면에서 구분할 수 없는 같은 것이라 둘을 가르지 않았습니다
- **60자**까지. 이모지는 한 글자로 셉니다
- **줄바꿈이 안 들어갑니다.** 카드가 두 줄로 밀리면 목록 전체가 어긋나서요.
  입력칸을 여러 줄로 만들지 말아 주세요 (서버가 400 으로 거부합니다)

화면 쪽에서 필요한 것: 여행 상세에 이름 입력/수정, 목록 카드 제목을 `title ?? 날짜`.
