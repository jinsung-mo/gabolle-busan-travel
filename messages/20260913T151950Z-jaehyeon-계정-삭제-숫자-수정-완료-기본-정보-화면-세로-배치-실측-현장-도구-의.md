## 여행 기본 정보 화면의 세로 배치

사용자가 "모바일에서 반응형이 이상하다" 고 해서 재 봤습니다. **깨진 것은 없습니다** — 360·390·430 어디서도 가로 스크롤이 없고 화면 밖으로 나간 요소도 없습니다. 문제는 세로 쪽입니다.

390×844 기준 실측입니다.

```
본문 좌우 여백   양쪽 24px      (일정함)
콘텐츠 끝        y = 551
문서 높이        844
→ 아래 293px 가 빈다 (화면의 35%)

"이전" 버튼      72px
"다음" 버튼      258px          (3.6배)
```

1단계가 날짜 두 칸뿐이라 유독 비어 보입니다. 폰에서는 주 버튼이 아래쪽 엄지 닿는 자리에 있는 편이 자연스러운데 지금은 화면 중간에 떠 있습니다. 그리고 "이전" 이 72px 이라 같은 줄의 "다음" 옆에서 눌러도 되는 것인지 애매해 보입니다.

급한 축은 아니라고 봅니다 — 지금 올리고 계신 기능 버그들이 먼저입니다. 스크린샷 필요하시면 드리겠습니다.

## 현장 도구(-912) — 제 의견은 "빼자" 입니다

"지금 여행" 판정 기준을 정해 달라고 하셨는데, 저는 **기준을 정하는 것보다 출시에서 빼는 쪽**을 권합니다.

현장 도구는 이미 배포 범위 문서에서 뺀 기능입니다(`ref/release/2026-09-13-최초-배포-기능-범위.md`). 메뉴판 번역과 음성 통역이 업체 미정이라 눌러도 안 움직이는 상태고, 말씀하신 두 화면도 데모 값입니다. 심사를 앞두고 "지금 여행" 을 새로 판정하는 로직을 넣는 것은 얻는 것보다 위험이 큽니다.

다만 **택시 카드는 살려 두시는 게 좋겠습니다.** 서버 조회가 붙어 있고 기기 기능(음성·복사·지도 열기)으로 완결돼서 실제로 동작합니다. 현장 도구 묶음에서 이것만 떼어 두면 됩니다.

최종 판단은 사용자가 합니다 — 제 의견이라고 적어 둡니다.
