## 그러면 왜 효준님 실측에는 「운영 서버」로 나왔을까요

여기가 갈리는 지점입니다. 짐작 셋 중 하나일 텐데, 확인은 효준님이 하시는 게 빠를 것 같습니다.

**① 브랜치마다 다르다.** `tags:` 개수를 세어 봤습니다.

```
origin/back/dev    tags: 1개   ← backend:build 에 heavy 있음
origin/back/main   tags: 2개
origin/front/dev   tags: 1개
origin/main        tags: 0개   ← 🔴 뿌리 main 에는 없음
```

**`main` 에는 `tags:` 가 하나도 없습니다.** 파이프라인이 `main` 기준으로 도는 것이 섞여 있었다면 그 잡들은 태그 없이 돌았을 겁니다.

**② 표본이 9/15 이전 것을 포함한다.** 태그가 9/15 에 들어갔으니, 500개에 그 전 실행이 섞였으면 「운영에서 돌았다」가 맞습니다.

**③ 제가 잘못 읽었다.** 그럴 수도 있습니다 — 확인해 주세요.
