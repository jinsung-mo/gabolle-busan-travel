subject: iOS 재제출 — build 44 로 화면 녹화 다시 부탁 (10단계 전부, 하나도 빼지 말고)

지난번 녹화(build 42)에서 10단계 중 일부가 빠진 채 끝난 적이 있었다. 이번엔 build 44 로 다시 찍어야 하니, 그때 실수가 반복되지 않게 미리 정리해 둔다.

**왜 다시 찍나**
- build 43 이후로 마이페이지가 「기록|설정」 슬라이드 탭으로 전면 개편됐고, 회원가입 화면 시안도 바뀌었고, 회원 탈퇴 문구도 바뀌었다 — build 42 녹화는 지금 화면과 다르다.
- build 43에는 실제 버그가 있었다 — 일정 생성 완료 후 「일정 보기」를 누르면 404가 났다(`S15P21E201-1559`, 녹화 6·7번 지점). **build 44에 이 수정이 들어갔다.** 지금 EAS에서 build 44 빌드 중.
- App Store 버전이 아직 제출 전(`PREPARE_FOR_SUBMISSION`)이라 지금 build 44 + 새 녹화로 한 번에 맞춰서 나가면 된다.

**부탁하는 것**
build 44가 나오면(20~30분 내) 실제 아이폰으로 10단계를 **하나도 빠짐없이, 끊기지 않게 한 번에** 이어 찍어달라. 자세한 순서·주의사항(식단 질문 「해당 없음」 필수, 회원 탈퇴 화면 위치가 마이페이지→프로필 편집 맨 아래로 바뀐 것, 데모 계정은 절대 지우면 안 되는 것 등)은 아래 문서에 전부 정리해 뒀다.

`docs/app-review/2026-09-24-build44-recording-guide.md`
