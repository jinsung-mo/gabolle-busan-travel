## 2. 표 던지는 법

```bash
git fetch origin
git fetch origin refs/heads/axmap/votes:refs/remotes/origin/axmap/votes

# 무엇에 표를 주는지 먼저 본다
git diff --stat origin/main origin/hotfix/S15P21E201-33-self-vote-tip

# 지금 몇 표인가 (읽기 전용 — 투표권 없어도 누구나 볼 수 있습니다)
node ci/axmap/governance/gate.mjs --source hotfix/S15P21E201-33-self-vote-tip --target origin/main

# 던진다
node ci/axmap/governance/vote.mjs --branch hotfix/S15P21E201-33-self-vote-tip \
  --sha $(git rev-parse origin/hotfix/S15P21E201-33-self-vote-tip) \
  --vote approve --target origin/main --note "<확인한 내용 한 줄>"
```

🔴 `--source` 에는 `origin/` 을 **붙이지 않습니다**(붙이면 표가 0장으로 세어집니다).
`--target` 에는 **붙입니다**. 두 규칙이 서로 반대라 특히 잘 틀립니다.

🔴 **표는 커밋 하나에 묶입니다.** 그 브랜치에 커밋이 하나라도 더 올라가면 앞의 표가
전부 무효가 됩니다. 그래서 표를 모으는 동안 그 브랜치는 건드리지 않습니다.
