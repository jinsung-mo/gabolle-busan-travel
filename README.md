# 가볼래 (GABOLLE)

> 부산의 모든 여행, 가볼래?

SSAFY 15기 자율 프로젝트 · 부울경 E201 · 6인 팀

부산에서 어디를 갈지 찾는 것부터 하루 동선을 짜는 것까지 이어 주는 여행 서비스입니다. 여행 날짜와 동행 인원, 출발지, 예산, 이동 방식, 취향을 입력하면 후보 장소와 일정을 살펴볼 수 있습니다. 관광지 이름만 나열하지 않고, 걷는 거리나 경사처럼 실제 이동에 영향을 주는 조건도 함께 다루려 했습니다.

## 어떤 흐름으로 쓰나요?

1. 홈에서 부산의 여행 기록과 축제를 둘러보고, 관심 있는 장소를 후보에 담습니다.
2. 날짜·인원·출발지·숙소·교통수단·예산을 정한 뒤 여행 취향과 이동 조건을 확인합니다.
3. 추천 코스를 고르면 장소 순서와 이동 시간이 들어간 일정이 만들어집니다.
4. 일정표와 지도에서 경로를 확인하고, 여행 중에는 현장 도구와 AI 도우미를 이용합니다.

아래 이미지는 모두 로컬 시연 영상 `가볼래_시연.mp4`의 **앱 화면에서 직접 추출**했습니다. 영상은 용량 때문에 저장소에 넣지 않았습니다. 각 화면이 보여 주는 범위와 서비스 전체 설계 범위는 다릅니다.

### AI 도우미는 무엇을 하나요?

가볼래 AI는 자유 대화로 장소를 확정해 주는 챗봇이 아니라, **사용자의 말을 앱 기능으로 연결하는 도우미**입니다. 시연 영상에서는 “해운대 해변 근처에서 무엇을 먹을까?”라는 질문을 받아 맛집 위주의 여행 일정을 만들 수 있다고 안내하고 `여행 만들기` 버튼을 보여 줍니다. 특정 음식점 목록을 추천한 장면은 아닙니다. 코드상으로는 여행 조건을 찾은 경우 일정을 열어 사용자가 검토하도록 하고, 안전 조건은 AI가 임의로 바꾸지 않도록 했습니다.

## 설계에서 중요하게 본 것

- **취향과 필수 조건을 구분했습니다.** 카테고리나 분위기는 선호도지만, 알레르기·식단과 이동 제약은 마음대로 완화하면 안 되는 조건입니다.
- **모르는 정보는 모른다고 표시합니다.** 장소의 계단·경사·영업 정보가 없을 때는 확인된 정보처럼 보여 주지 않습니다.
- **장소 목록에서 끝내지 않습니다.** 여행 날짜, 체류·이동 시간, 예산을 함께 고려해 일정과 지도까지 이어지는 흐름을 설계했습니다.
- **사용자가 마지막 결정을 합니다.** 여행 조건을 확인하고 수정할 수 있게 했고, AI 도우미도 조건을 적용하기 전에 검토 화면으로 연결합니다.

이 원칙은 [가볼래 팀 공유 문서](docs/gabolle/README.md)의 확정 v1.1 명세를 기준으로 정리했습니다. 명세에 적힌 모든 기능이 위 시연 영상에서 동작하는 것은 아닙니다.

## 기술 구성

| 영역 | 사용 기술 |
|---|---|
| 앱 | Expo · React Native · TypeScript · Expo Router |
| 서버 | Spring Boot · Java 17 · Spring Security |
| 저장소 | PostgreSQL · Spring Data JPA · Flyway |
| 데이터·추천 | Python · 장소/이동 데이터 가공 · 일정 추천 |
| 운영 | Docker Compose · Jenkins · Nginx |

앱 코드는 `frontend/`, 서버 코드는 `backend/`, 장소·교통·지형 데이터 작업은 `bigData/`에 있습니다. 서버는 여행 조건과 장소·일정 데이터를 관리하고, 추천 영역은 후보 선택과 동선 계산을 맡습니다. 기능별 실제 구현과 실행 조건은 각 폴더의 README를 확인해 주세요.

## 로컬 실행

프론트엔드는 Node.js 20 이상이 필요합니다.

```bash
cd frontend
cp .env.example .env
npm install
npm run web
```

백엔드는 Java 17과 Docker가 필요합니다. `.env`의 비밀번호와 비밀키를 설정한 뒤 실행합니다.

```bash
cd backend
cp .env.example .env
docker compose up --build -d
```

환경변수와 OAuth 설정은 [백엔드 실행 안내](backend/README.md)를 참고해 주세요. 비밀값은 저장소에 올리지 않습니다.
