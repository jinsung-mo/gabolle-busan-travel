## 3. 왜 하필 오늘 나왔나 — 오늘 처음 켠 검사다

`claims` 잡은 두 가지를 볼 수 있는데, **어제까지 `back` 쪽은 하나만 보고 있었다.**

| 옵션 | 무엇을 보나 | 어제까지 back |
|---|---|---|
| `--checkpoint` | 장부만 재생 — **두 사람이 같은 파일을 동시에 잡은 적이 있나**(I1) | 🟢 돌고 있었다 |
| `--code` | 커밋과 장부를 대조 — **선점 없이 고친 커밋이 있나**(I5) | 🔴 **없었다** |

오늘 오후 `common/dev` 를 `back/main` 에 합치면서 두 방식이 부딪혔다. 한쪽을 골라야
하는 자리로 보였는데 **둘은 같은 명령의 다른 옵션이라 함께 줄 수 있었다.**
jaehyeon 님이 커밋 `bf6afe34` 로 둘을 함께 켰고, **켜자마자 75건이 나왔다.**

> 🔴 그러니 이건 *"새 검사가 오탐을 냈다"* 가 아니다.
> **9월 7일부터 있던 것이 오늘까지 아무에게도 안 보였던 것**이다.

### 아침의 `!418` 은 왜 통과했나

`back/dev` → `back/main` 인 `!418` 은 오늘 아침 초록이었다. **그때는 `--code` 가 아예
없었다.** 코드를 안 봤으니 통과한 것이지, 봤는데 깨끗했던 것이 아니다.

**전부 뒤에 있다.** 도장이 보증한 구간 밖이라 *"옛날 것이라 못 봤다"* 가 성립하지 않는다.

## 5. 그래서 무엇을 했나 — **껐다. 없앤 것이 아니다**

오늘 팀은 `main` 사다리 한 바퀴를 돌기로 하고 15:20부터 전원이 작업을 멈춘 상태다.
**75건을 정리하는 일과 사다리를 도는 일은 다른 일**이라, 사다리를 먼저 돌린다.

`back/main` 의 `claims` 잡에서 `--code` 를 **CI 변수 뒤로 옮겼다.**

```bash
if [ "${CLAIMS_CODE_CHECK:-0}" = "1" ]; then   # 켜져 있으면 코드 대조까지
   audit --fetch --code "$RANGE" --checkpoint
else                                            # 기본은 장부만
   audit --fetch --checkpoint
fi
```

| | |
|---|---|
| **다시 켜는 법** | `Settings → CI/CD → Variables` 에 **`CLAIMS_CODE_CHECK = 1`**. **커밋도 MR 도 필요 없다** |
| **끈 동안 쉬는 것** | 「선점 없이 고쳤나」(I5) **한 갈래뿐** |
| **끈 동안에도 도는 것** | 「두 사람이 같은 파일을 동시에 잡았나」(I1) — 장부를 그대로 재생한다 |

`AXMAP_VERSION` 과 같은 **되돌리는 손잡이**다 (팀 `CLAUDE.md` 0.3 절).

### 🔴 이 선택이 무엇을 치렀는지 분명히 적는다

처음에 제안했던 다른 안은 *"파트`/main` → `main` 칸에서는 이 잡을 안 돌린다"* 였다.
**그건 더 나빴다.** 아래 칸(`dev` → 파트`/main`)에도 `--code` 가 없으므로, 그 칸을
빼면 **이 위반은 어느 칸에서도 영영 안 잡힌다.** 반면 지금 방식은
*"75건을 정리할 때까지 잠시 끈다"* 가 코드와 이 문서에 남는다 — **다시 켜는 것이
숙제로 보인다.** 그 차이 하나 때문에 이 방식을 골랐다.

## 6. 남은 숙제

1. **75건을 어떻게 닫을 것인가** — 두 갈래다.
   - (가) 지난 일로 인정하고 **체크포인트를 09-07 이후로 다시 찍는다**. 빠르지만 기록이 지워진다
   - (나) **왜 선점이 빠졌는지 먼저 본다.** 훅이 안 걸려 있었나, 여러 창에서 동시에 작업했나,
     TTL 이 끊긴 뒤 계속 고쳤나. 원인을 모르면 다시 켜자마자 또 쌓인다
   → **(나) 를 먼저 하고 (가) 로 닫는 것**을 제안한다. 원인은 jaehyeon 님만 안다
2. **켠 뒤 `CLAIMS_CODE_CHECK` 를 지우고 조건문도 걷어낸다** — 손잡이가 오래 남으면
   그게 기본값이 된다
3. **다른 파트도 같은 상태일 수 있다.** `front` · `map` · `bigData` 는 아직 `--code` 를
   안 켰다. 켜기 전에 이 문서를 먼저 보시라
