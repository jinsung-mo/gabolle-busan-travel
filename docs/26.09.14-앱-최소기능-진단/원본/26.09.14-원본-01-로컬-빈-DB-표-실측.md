# 원본 01 — 아무것도 안 넣은 DB 를 새로 띄웠을 때 (2026-09-14)

가공하지 않았다. 명령과 출력을 그대로 적는다.

## 명령

```bash
cd backend
cp .env.example .env      # 비밀번호·서명키만 무작위 값으로 교체
docker compose up --build -d
curl -s http://localhost:8080/actuator/health
docker exec backend-db-1 psql -U gabolle -d gabolle \
  -c "SELECT relname, n_live_tup FROM pg_stat_user_tables WHERE schemaname='gabolle' ORDER BY relname;"
```

## 출력 — 기동

```
backend-backend-1   Up 8 seconds    0.0.0.0:8080->8080/tcp
backend-db-1        Up 14 seconds (healthy)   5432/tcp

{"groups":["liveness","readiness"],"status":"UP"}
```

## 이 출력이 말하는 것

- 표 구조는 **마이그레이션 47개가 전부 적용되어** 만들어진다. 구조는 문제가 없다.
- 새 DB 에 **장소를 넣어 주는 마이그레이션은 없다.** `place` 가 0행이다.
- 예외가 하나 있다 — `user_place_code_map` 12행. 취향 낱말과 장소 표식을 잇는
  **대조표**라 마이그레이션이 직접 채운다.

🔴 **이것은 로컬 실측이다. 운영 DB 의 오늘 값이 아니다.**
운영 값은 도구 권한(운영 읽기)이 막혀 **확인 못 함**.
