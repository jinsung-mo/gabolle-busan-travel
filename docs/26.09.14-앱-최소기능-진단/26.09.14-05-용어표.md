# 05 — 용어표

모르는 말이 나오면 여기부터. **약어를 늘려 쓰는 것이 아니라 무엇을 하는지**를 적는다.

| 말 | 뜻 |
|---|---|
| **온보딩**(onboarding) | *앱을 처음 켠 사람에게 몇 가지를 물어보고 준비시키는 화면들.* 여기서 받은 취향 답이 추천의 재료가 된다 |
| **추천 파이프라인** | *답을 받아서 장소 목록을 내놓기까지 거치는 단계 전부.* 저장 → 후보 고르기 → 채점 → 결과 |
| **후보**(candidate) | *채점하기 전에 "일단 이 중에서 고른다" 고 추린 장소들.* 후보가 0건이면 채점을 아무리 잘해도 결과가 없다 |
| **재고** | 이 문서에서만 쓰는 말. *지금 DB 에 실제로 들어 있는 갈래별 장소 수.* 상품 재고와 같은 뜻으로 쓴다 |
| **채점**(scoring) | *후보마다 점수를 매겨 순위를 만드는 것.* 거리·갈래·분위기·음식·인기에 각각 무게를 두고 더한다 |
| **차원**(dimension) | *취향을 재는 축 하나.* 갈래·분위기·음식·경사·그늘 … 각각이 한 차원이다 |
| **사전**(dictionary) | *허용된 낱말 목록.* 여기 없는 낱말은 저장 자체가 거부된다. 없으면 오타가 조용히 통과한다 |
| **대조표** | *취향 낱말과 장소 표식을 잇는 표.* "사용자가 말한 「바다」 는 장소의 어느 표식인가" 를 DB 가 답한다 |
| **마이그레이션**(migration) | *DB 표 모양을 바꾸는 명령을 순서대로 적어 둔 파일들.* 앱이 뜰 때 자동으로 순서대로 돈다 |
| **적재기**(loader) | *바깥에서 받은 자료를 DB 에 넣는 프로그램.* 서비스 기능이 아니라 **사람이 한 번 돌리는 것** |
| **CSP**(Content Security Policy) | *브라우저에게 "이 페이지는 어느 주소에서 온 코드만 실행해도 된다" 고 서버가 알려 주는 규칙.* 카카오가 이 목록에 없으면 지도 스크립트가 조용히 막힌다 |
| **웹뷰**(WebView) | *앱 안에 작은 브라우저 창을 띄우고 거기에 웹페이지를 그리는 것* |
| **피드**(feed) | 이 앱에서는 *사람들이 올린 여행 기록이 시간순으로 늘어선 화면.* 홈 화면과 다른 것이다 |
| **조용한 고장** | *오류를 안 내고 결과만 틀리는 고장.* 화면이 멀쩡해 보여서 아무도 모른다. 이 문서에서 제일 자주 나오는 위험 |
| **확인 못 함** | *재보지 않았다는 뜻.* 추측으로 채우지 않기로 한 팀 규칙이다 |
