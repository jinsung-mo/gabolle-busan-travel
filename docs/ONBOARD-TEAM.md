의존성이 0이다. **Node 20+ 와 git 만** 있으면 된다. `npm install` 도 없다.

---

## 1. 붙기 (3줄)

```bash
git clone <저장소> && cd axmap
export AXMAP_AGENT=<자기이름>          # 예: minsu-claude · 세션마다, 남과 겹치지 않게
node bin/axmap.mjs hook install
```

끝이다. `.mcp.json` 이 저장소에 있으므로 **Claude Code 를 이 폴더에서 열면
MCP 도구가 자동으로 붙는다.** 설정 파일을 따로 만들 필요가 없다.

붙었는지 확인:

```bash
node bin/axmap.mjs status      # 지금 누가 무엇을 잡고 있나
```

> ⚠️ `AXMAP_AGENT` 는 **셸이 바뀌면 사라진다.** claim 과 커밋을 다른 셸에서 하면
> 훅이 당신을 다른 사람으로 보고 커밋을 막는다. 커밋할 때도 같은 값을 준다:
> `AXMAP_AGENT=<자기이름> git commit`

## 3. 🔴 알아야 할 것 넷

### ① 왜 claim 부터 하나 — 파일 충돌이 아니라 **의도 충돌**

git 은 같은 줄을 고쳐야 충돌을 안다. 그런데 실제로 더 위험한 것은
**같은 기능을 앞에서부터/뒤에서부터 만드는 두 사람**이다. 경로가 안 겹쳐도
결과가 어긋난다. claim 은 그것을 코드를 쓰기 **전에** 터뜨린다.

### ② 거부당하면 재시도하지 말고 방향을 바꾼다

| 종료 코드 | 뜻 | 할 일 |
|---|---|---|
| 2 | 경로가 겹침 | **다른 작업으로 전환.** 재시도해도 결과는 같다 |
| 3 | claim 없이 커밋 시도 | 그 경로를 claim 하거나 스테이징에서 뺀다 |

`status` 에 점유자·작업·남은 TTL 이 다 나온다. 비어 있는 영역을 찾으면 된다.

### ③ 끝나면 바로 반납한다

안 하면 TTL(30분)이 지나 저절로 풀린다. 그래도 **끝나면 즉시** 반납한다 —
남을 30분 헛되이 세우지 않기 위해서다.

### ④ 좁게 잡고 필요하면 추가한다

claim 은 누적된다. 넓게 잡으면 남의 작업을 헛되이 막는다.

## 4. 코드 규칙 (사람에게도 AI 에게도 같다)

`CLAUDE.md` 가 전문이고, 그중 셋만 미리 알면 된다.

**의존성을 추가하지 않는다.** Node 와 git 만. 필요하다고 판단되면 **추가하기 전에 묻는다.**

**애매하면 거부한다 (fail-closed).** 이 저장소에서 가장 자주 나온 버그는 전부
같은 모양이었다 — **없는 것과 못 읽은 것을 같은 값으로 말한 것.**

```
claims: []      ← "아무도 안 잡고 있다" 로 읽힌다
claims: null    ← "모른다" 다
```

실제로 신입 에이전트가 그 `[]` 를 읽고 "부딪힐 사람 없음" 이라고 확신 있게 틀렸다.
하루에 네 번 같은 유형이 나왔다. **0 을 쓰기 전에 그게 진짜 0 인지 확인한다.**

**주석은 "왜" 를 쓴다.** 무엇은 코드가 이미 말한다.
