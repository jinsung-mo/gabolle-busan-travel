## 4. 화면 녹화 촬영 지시서 — 이 부분만 사람이 한다

🔴 **실제 아이폰**에서 찍는다. 시뮬레이터 녹화는 Apple 이 안 받는다.
🔴 **앱 아이콘을 눌러 실행하는 장면부터** 시작한다. 앱이 이미 열린 상태에서 시작하면 안 된다.
🔴 **제출할 빌드와 같은 빌드**로 찍는다.

### 찍기 전에

```
[ ] 설정 › 제어 센터 › 「화면 기록」 추가
[ ] 기내 모드 끄고 Wi-Fi 또는 셀룰러가 «정상»인지 확인
    (연결이 불안하면 소셜 로그인이 「로그인이 취소되었어요」로 끝난다 — S15P21E201-1480)
[ ] 앱을 «지우고 다시 설치» — 첫 실행 화면부터 찍어야 하므로
[ ] 방해금지 모드 켜기 (알림 배너가 화면에 끼어들지 않게)
[ ] 소리는 없어도 된다. 자막·설명도 필요 없다
```

### 순서대로 찍는다 (한 번에 이어서, 약 3~5분)

| # | 무엇을 | 보여줄 것 |

안 닫힌다면 재제출 전에 고쳐야 한다.
