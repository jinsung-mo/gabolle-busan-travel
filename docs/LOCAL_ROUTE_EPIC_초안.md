## 0. 이 초안을 어떻게 읽나

**Epic 을 기능 영역에서 그대로 뽑았다.** 상세설계서 Part I 이 이미 기능을 영역 11개로
갈라 놓았고, 영역마다 **기능 ID(`F-ACC-01` 같은 것) · 전용 절 · 화면 매핑**이 셋 다
붙어 있다. 그 경계를 새로 그리지 않고 그대로 쓴다 — **문서와 티켓이 같은 선으로
갈려 있어야 나중에 "이 기능이 어느 Epic 이었나"를 찾을 수 있다.**

거기에 **기능 영역에 안 들어가는데 반드시 해야 하는 것 다섯**을 더했다.

| 층 | 무엇 | 개수 |
|---|---|---:|
| **0층 — 기반** | 이게 없으면 나머지가 시작조차 안 된다 | 3 |
| **1층 — 제품** | 기능 영역 그대로 | 11 |
| **2층 — 출시** | 앱과 스토어 | 2 |
| | **합계** | **16** |

> 🔴 **16개는 적은 수가 아니다.** 6명이 5주에 다루기에 많다고 보시면 **합치셔도 된다.**
> 합치기 쉬운 자리를 3절에 적어 뒀다. 다만 **`FLD` 와 `COM` 은 합치기 전에
> 4절(조건부)을 먼저 보셔야 한다** — 그 둘은 크기 문제가 아니라 **착수 조건** 문제다.

### 크기 표기

`기능 수`는 상세설계서 Part I 의 `F-` ID 개수이고, `화면`은 Part II 의 `P-` 번호다.
**이 숫자는 Story 개수가 아니다** — 기능 하나가 Story 여러 개가 될 수 있다.

## 2. 순서 — 무엇이 무엇을 막나

```
E1 껍데기·배포 ──┐
E2 MySQL 스키마 ─┴─→ E4 ACC ─→ E5 PLN ─→ E6 REC ─→ E7 ITN ─→ E8 MAP
                                                      ├─→ E9  DSC
                                                      ├─→ E10 SOC ─→ E11 COL
                                                      └─→ E12 SYS
E3 스토어 (계정 개설) ──────────────────────────────────→ E15 앱 ─→ E3 심사 화면
E16 데이터 채우기 ────────────(E6·E9 의 완료 기준을 막는다)
```

**읽는 법 셋.**

1. **E1·E2 가 안 끝나면 나머지가 전부 대기다.** 제일 먼저 사람을 넣는다
2. **E3 의 계정 개설만 지금 즉시 뗀다.** 나머지 심사 화면은 앱(E15)이 있어야 뜻이 있다
3. **E16 은 아무도 안 막는 것처럼 보이지만 실제로는 완료 기준을 막는다.**
   추천(E6)과 탐색(E9)이 "돌아간다"고 말하려면 데이터가 있어야 한다

## 3. 합치고 싶다면 — 여기가 이음매다

| 합칠 것 | 합친 뒤 크기 | 잃는 것 |
|---|:-:|---|
| **E11 COL 을 E7 ITN 으로** | 12 | 협업 기능이 일정 Epic 에 묻힌다 |
| **E8 MAP 을 E5 PLN + E7 ITN 으로 나눠서** | — | 지도가 여러 Epic 에 걸쳐 주인이 없어진다 |
| **E9 DSC 를 E10 SOC 으로** | 12 | 탐색과 기록은 사용자에게 다른 일이다 |

🔴 **E2 와 E16 은 합치지 않는다.** 스키마 이관은 **코드**이고 데이터 채우기는
**사람 손**이다. 한 Epic 에 넣으면 "이관 끝났는데 왜 안 닫히나" 가 반복된다.

## 4. 🔴 조건부 Epic 둘 — 지금 끊으면 위험하다

### E13 FLD — 현장 도구

기능 6개 중 **3개가 `[견본도 가짜]`** 다. 참고 코드에서조차 동작하는 척만 했다 —
날씨는 날짜 문자코드로 지어냈고, 음성 통역은 *"pork 이라는 글자가 있으면 이 문장"*
식 분기였다. **화면에서는 진짜와 똑같이 보이므로 보고 만들면 가짜까지 옮긴다.**

그리고 **외부 서비스 계약이 착수 조건**이다 (기획서 6.6 · 상세설계서 19.3).
**첫 Story 를 "제공자 선정과 키 발급"으로 두거나, Epic 자체를 뒤로 미룬다.**

### E14 COM — 커머스

**광고주가 없으면 결론이 "화면을 숨긴다"** 이다 (기획서 13.1).
기능 3개 중 2개가 `[견본도 가짜]` 다. **광고주 유무를 먼저 확인하지 않으면
만들고 숨기는 일이 된다.**
