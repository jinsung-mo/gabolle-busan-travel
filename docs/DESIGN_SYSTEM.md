## 1. 검토 결과 — 디자인 시스템을 우리가 만들 이유는 없다

> **[돌려봄 · 이 저장소 밖]** **Astryx** 를 실제로 설치해 화면을 만들고 빌드까지 통과시켰다.
> 색·간격·글꼴·컴포넌트를 **우리가 정의하지 않아도 된다**는 것은 확인됐다.
>
> 🔴 **2026-08-27 보강 — 그 실험은 이 저장소 안에서 한 것이 아니다.**
> 4절이 적어 둔 대로 `npm create vite` 로 만든 **버리는 실험용 프로젝트**(`astryx-trial`)에서 했다.
> 그래서 **이 저장소에는 설치 흔적이 하나도 없다** — `frontend/` 에는 `README.md` 한 장뿐이고,
> lock 파일도 `astryx` 를 담은 커밋도 없다. 4절의 빌드 시간·번들 크기는 **그 실험용 프로젝트의 값**이지
> 우리 `frontend/` 의 값이 아니다.
>
> **저장소만 보고는 이 절을 검증할 수 없다.** FE Epic 의 착수 전제나 완료 기준을
> 여기 걸지 않는다 — 채택은 아직 `[미정]` 이다.
>
> **[미정]** 그것을 쓸지는 아직 팀이 정하지 않았다. `실행계획_v7` 2.6절도 `[미정]` 이다.
>
> **[위험]** 웹을 Astryx 로 가더라도 **앱은 따로다.** Astryx 는 웹 전용이라
> React Native 에서 돌지 않는다. 앱 스택은 **Expo 로 확정**됐으므로(`실행계획_v7` 2.4절)
> 남은 질문은 "앱을 뭘로 만드나" 가 아니라 **"Expo 위에서 어떤 컴포넌트를 쓰나"** 다.

**Astryx** — 메타(Meta)가 2026년 6월에 공개한 디자인 시스템(**색·글꼴·버튼 같은 화면 재료를
한 벌로 묶어 놓은 것**). 페이스북·인스타그램·스레드를 포함해 사내 앱 13,000개를 굴리던 것이고,
라이선스는 MIT(**마음대로 가져다 써도 되고 출처만 남기면 되는 조건**)다.

직접 설치해서 LOCAL ROUTE 여행 홈 화면을 만들어봤다.
**화면 코드에 색을 지정한 줄이 하나도 없다.** 경고 배너는 `status="warning"` 한 마디로
노란 바탕과 삼각형 아이콘이 따라왔고, 타입 검사와 빌드도 통과했다.

## 2. 후보 여섯 개와 판정 [확인함 · 2026-08-27]

우리 조건은 셋이다 — **웹**(사이드바·지도 패널이 있는 본격 데스크톱),
**앱**(React Native + Expo), 그리고 **짧은 기간**.

> **[위험]** 화면 수와 마감일은 여기 적지 않는다. `실행계획_v7` 3절이
> "9/4 · 9/11 일정은 이제 성립하지 않는다" 고 적었고, 백엔드가 Spring 으로 가면서
> **동작하는 API 0개 · 완료된 웹 화면 0개**가 새 출발점이 됐다. 범위를 다시 잡는 중이라
> 여기에 숫자를 적으면 그 줄이 먼저 낡는다. 아래 비교는 **웹이 데스크톱까지 감당해야
> 하고 앱이 웹보다 훨씬 작다**는 두 가지에만 기댄다.

| 후보 | 웹 | 앱 | 판정 |
|---|---|---|---|
| **Astryx** (메타 · MIT) | ◎ 컴포넌트 163개 | ✕ 안 됨 | **웹 채택** |
| **Tamagui** | ○ | ◎ | 모바일 기준으로 만들어져, 본격 데스크톱으로 늘리는 쪽이 더 고생스럽다 |
| **gluestack-ui v5** | ○ | ◎ | 위와 같은 이유 |
| **Backpack** (스카이스캐너 · 여행) | ◎ | ✕ | React Native 판이 **2024-12-02 아카이브**(관리 중단). 토큰 구조 참고용으로만 |
| **shadcn/ui + react-native-reusables** | ◎ | ◎ | **앱까지 한 벌로 가려면 이쪽.** 대신 Astryx 만큼 완성돼 있지 않다 |
| **Airbnb DLS** | — | — | **비공개.** 공개 문서 사이트가 없다. 블로그 글과 팬이 만든 Figma 복제본뿐 |

인스타그램 디자인 시스템을 따로 찾을 필요는 없다 — **Astryx 가 그것이다.**

## 3. Astryx 가 우리에게 주는 것 [확인함 · 2026-08-27]

**디자인 토큰** — 색·간격·글자 크기 같은 **값에 이름을 붙여 한 곳에 모아둔 것**.
`#262626` 대신 `accent` 라고 부른다.

아래가 기본 테마(`theme-neutral`)의 실제 값이다. **우리가 정한 것은 하나도 없다.**

> 🔴 **팀 규칙은 "문서에 색깔 값을 적지 않는다" 이고, 이 표는 그 규칙을 어기는 게 아니다.**
> 규칙이 막는 것은 **우리 색을 문서에 박는 것**이다 — 그러면 테마를 바꾸는 순간 문서가 낡는다.
> 이 표는 반대로 **"우리가 정할 게 없다" 는 것을 보이려고** 남의 값을 옮겨 적은 것이고,
> 그래서 여기 말고 다른 문서에는 옮기지 않는다.
>
> Astryx 는 `0.5.0` **beta** 다. 아래 값과 실제가 다르면 **문서가 아니라
> `npx astryx docs tokens` 을 믿는다.**

| 토큰 | 라이트 | 다크 | 쓰이는 곳 |
|---|---|---|---|
| `--color-background-body` | `#f1f1f1` | `#1b1b1b` | 화면 바닥 |
| `--color-background-surface` | `#ffffff` | `#262626` | 카드 · 사이드바 |
| `--color-text-primary` | `#171717` | `#fafafa` | 본문 글자 |
| `--color-text-secondary` | `#525252` | `#a3a3a3` | 보조 설명 |
| `--color-accent` | `#262626` | `#ebebeb` | 주요 버튼 · 선택 상태 |
| `--color-success` | `#007004` | `#9fe59b` | 확인됨 · 여유 |
| `--color-warning` | `#745b00` | `#fdcf4f` | 지연 경고 · 추정값 |
| `--color-error` | `#a50c25` | `#ffc6c1` | 오류 · 삭제 |
| `--radius-element` / `--radius-container` | 12px / 16px | | 버튼·입력 / 카드·모달 |
| `--spacing-*` | 4px 기본 단위 | | 모든 여백 |
| `--font-family-body` | Figtree · 기본 14px | | 모든 글자 |

그 밖에 따라오는 것:

- **컴포넌트 163개.** 버튼·카드·모달·달력·표·앱 껍데기(`AppShell`)까지 있다
- **라이트/다크 두 벌.** 우리가 다크용 색을 고를 일이 없다
- **접근성이 이미 들어 있다.** 키보드 이동·스크린리더가 컴포넌트 안에 있어,
  기획서의 접근성 최소 기준(대비 · 터치 영역 · 포커스 · 스크린리더)이 대부분 공짜로 따라온다
- **테마 7종** — `neutral` `butter` `chocolate` `gothic` `matcha` `stone` `y2k`

## 4. 실제로 깔아본 결과 [돌려봄 · 2026-08-27 · 이 저장소 밖]

> 🔴 아래는 **버리는 실험용 프로젝트**(`astryx-trial`)에서 잰 값이다. 우리 `frontend/` 가 아니다.

설치부터 화면이 뜨기까지 막힌 곳은 없었다.

```bash
# 프로젝트 만들고 설치
npm create vite@latest astryx-trial -- --template react-ts
npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex
npm install -D @astryxdesign/cli
```

```css
/* CSS 세 줄 — 순서가 중요하다 (reset → 컴포넌트 → 테마 토큰) */
@import '@astryxdesign/core/reset.css';
@import '@astryxdesign/core/astryx.css';
@import '@astryxdesign/theme-neutral/theme.css';
```

```tsx
// 앱을 감싸면 끝. 빌드 플러그인도 설정 파일도 없다
<Theme theme={neutralTheme}><App /></Theme>
```

`npm run build` → **`✓ built in 2.22s`** (타입 검사 포함 통과)

### 4.1 예상 못 했던 수확 — CLI 가 사용법을 뱉는다

Astryx 는 컴포넌트 사용법을 명령어로 출력한다.
우리 팀에 중요한 이유는, **AI 로 화면을 만들 때 제일 자주 나는 사고가
"있을 법한 속성을 지어내는 것"** 이기 때문이다. 그게 구조적으로 막힌다.

```bash
npx astryx component --list              # 컴포넌트 163개 목록
npx astryx component Button              # 속성 · 변형 · 예제 전부
npx astryx template CardWithInnerLayout  # 그걸 쓴 진짜 코드
```

데모 화면을 만들 때 `Banner` 에 `endContent` 가 있는지, `Item` 에 `marker` 가 있는지를
전부 이 명령으로 확인하고 썼다. 추측은 한 번도 하지 않았다.

이 규칙은 `CLAUDE.md` 5절(백그라운드 에이전트에 넘기기 전에 판단이 갈릴 지점을
미리 박는다)과 같은 방향이다 — **에이전트가 지어낼 여지를 없앤다.**

## 5. 아직 정하지 않은 것

### 5.1 앱 컴포넌트를 무엇으로 하나 [위험 · 미정]

**앱 스택 자체는 정해졌다** — React Native + Expo (`실행계획_v7` 2.4절, `[확인함]`).
그래서 남은 질문은 "앱을 뭘로 만드나" 가 아니라 **"Expo 위에서 어떤 컴포넌트를 쓰나"** 다.

**Astryx 는 웹 전용이다.** StyleX(**메타가 만든 CSS 작성 도구**)와 CSS 변수 위에 서 있어서
React Native 에서 돌지 않는다. 앱 화면은 컴포넌트를 따로 구해야 하고,
**같은 색·간격 값을 넣어줘야 한다.**

선택지는 둘이다.

| | 얻는 것 | 잃는 것 |
|---|---|---|
| **웹 Astryx + 앱 별도** | 웹 품질이 가장 높다 | 값이 두 벌이 된다 |
| **웹·앱 모두 shadcn/ui 계열** | 한 벌로 간다 | 웹 완성도를 Astryx 만큼 못 얻는다 |

앱 쪽 후보는 `react-native-reusables`(shadcn/ui 를 RN 으로 옮긴 것) 와
`gluestack-ui` 다. 둘 다 NativeWind(**RN 에서 Tailwind 를 쓰게 해 주는 것**) 위에 선다.

> 이 자리는 **기획자 판단이 필요한 곳**으로 보인다. 웹과 앱이 같아 보여야 하는 정도를
> 정하는 문제이기 때문이다.

> 🔴 **어느 쪽이든 토큰은 한 곳에서 나와야 한다.**
> 색 하나를 손으로 두 번 적는 순간, 한쪽만 고치고 다른 쪽을 잊는 사고가 예약된다.
> 안 깨지고 조금 다르기만 해서 **제일 늦게 발견된다.**
>
> **[미정] 그 "한 곳" 이 어디인지는 다시 정해야 한다.** v6 은 `packages/shared/src/design/`
> 을 잡아 뒀는데, 그건 **서버까지 자바스크립트라는 전제** 위에 있었다. 백엔드가 Spring 으로
> 정해지면서 `실행계획_v7` 이 그 계획을 "다시 써야 하는 것" 으로 분류했다.
> 다만 **웹(React)과 앱(Expo)은 여전히 둘 다 자바스크립트**이므로, 그 둘 사이의
> 공유 자리는 계속 필요하다. 이름과 위치만 새로 정하면 된다.

### 5.2 강조색을 그대로 둘 것인가 [미정]

기본 테마의 강조색은 **거의 검정(`#262626`)** 이다.
화려한 브랜드 색이 아니라 "차분한 최소한"이 기본값이다.
여행 서비스에 맞는 색으로 갈지, 그대로 둘지 정해야 한다.
바꾸는 비용은 크지 않다 — **토큰 하나만 바꾸면 화면 전체가 따라온다.**

### 5.3 여행 전용 컴포넌트는 어차피 우리 몫이다 [확인함]

일정 타임라인, 지도 마커, 장소 카드, 택시 목적지 카드 — **어느 디자인 시스템에도 없다.**
다만 Astryx 의 `Card` · `Item` · `Badge` 를 조합해 만들면 되고, 데모에서 그렇게 만들어봤다.

### 5.4 Astryx 는 아직 beta 다 [위험]

버전 `0.5.0`, 공개된 지 두 달이다. 뒤에 메타가 있고 사내 8년 이력이 있지만
**API 가 바뀔 수 있다.** 버전을 고정해서 쓰고, 올릴 때는 `npx astryx upgrade` 를 쓴다.
