# 웹·앱 공통 디자인 토큰 결정

## 결정

- 공유 자리의 이름은 `design tokens`로 통일한다.
- 정확한 위치는 `frontend/src/design/tokens.ts`이다.
- 화면 코드에서는 상대 경로 대신 `@/design/tokens`로 가져온다.
- 이 파일은 Front 파트가 소유한다. 디자인 변경은 Front 담당자가 반영하고 웹·앱 검증을 함께 수행한다.

GABOLLE 프론트는 Expo Router의 같은 화면·컴포넌트 소스를 웹과 앱으로 빌드한다. 따라서 웹용 토큰 파일과 앱용 토큰 파일을 나누지 않는다. `color`, `spacing`, `radius`, `type`, `fontFamily`, `gutter`가 유일한 출처이며 두 플랫폼 모두 이 모듈을 사용한다.

## 사용 원칙

- 강조색은 `color.action.primary`처럼 역할 이름으로 사용한다.
- 간격은 `spacing`의 단계 이름으로 사용한다.
- 요소 모서리 반경은 `radius`의 크기 이름으로 사용한다.
- 화면이나 문서에 실제 색상 값을 복사하지 않는다.
- 플랫폼 차이가 필요한 경우에도 값을 복제하지 않고 컴포넌트 구현만 플랫폼별로 나눈다.

## 확인 방법

1. 웹과 앱에서 같은 공유 컴포넌트 화면을 연다.
2. 강조색과 간격이 모두 `@/design/tokens`에서 왔는지 확인한다.
3. 토큰 모듈의 역할 이름 하나를 임시로 바꿔 두 플랫폼에 함께 반영되는지 확인한 뒤 원래 값으로 되돌린다.
4. 웹 TypeScript 검사와 Expo 앱 번들 검사를 통과시킨다.

대표 확인 대상은 공용 `Button`, `Screen`, `Text` 컴포넌트다. 이 컴포넌트를 사용하는 웹 화면과 앱 화면은 같은 토큰 출처를 따라야 한다.
