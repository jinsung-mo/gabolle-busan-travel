# S15P21E201-74 권한 실기기 확인 기록

## 구현 원칙

- 위치와 카메라는 온보딩에서 요청하지 않고 해당 기능을 처음 사용할 때 설명 후 요청한다.
- 알림만 온보딩 마지막에서 선택한 사용자에게 요청한다.
- 권한이 거부되면 기능 화면을 유지하고 `권한이 필요합니다 · 설정 열기` 복구 동선을 제공한다.
- 현장 말하기는 현재 기기 TTS 출력 기능이므로 마이크 권한을 요청하지 않는다.
- 메뉴판 촬영 결과를 사진첩에 저장하지 않으므로 사진 권한을 요청하지 않는다.

사용하지 않는 마이크·사진 권한까지 미리 선언하거나 요청하면 최소 권한 원칙과 스토어 심사 취지에 어긋난다. 추후 음성 입력 또는 사진 불러오기 기능을 붙이는 MR에서 같은 사전 설명 패턴으로 추가한다.

## Android 실기기

- [ ] 새 설치 후 온보딩에서 위치·카메라 팝업이 뜨지 않는다.
- [ ] 알림을 선택한 경우에만 알림 권한 팝업이 뜬다.
- [ ] 여행 지도에서 `현재 위치 사용`을 눌렀을 때 위치 권한 팝업과 등록 문구가 보인다.
- [ ] 현장 도구에서 `카메라 사용`을 눌렀을 때 카메라 권한 팝업과 등록 문구가 보인다.
- [ ] 위치·카메라를 거부해도 앱이 종료되지 않고 `설정 열기`가 표시된다.
- [ ] 설정에서 허용 후 앱으로 돌아와 기능 진입 상태를 다시 확인한다.

확인 기기/OS: 미확인
