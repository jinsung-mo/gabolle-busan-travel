## 0. 🔴 어제 왜 40분을 쓰고 기능 검증이 0% 였나

2026-09-17 밤에 7회차를 돌렸고 스크린샷을 95장 찍었다. 그중 **앱 메인 화면은 0장**이다.
이유가 셋이고, **이 문서와 스크립트가 셋을 다 막는다.** 원인을 알면 같은 데서 안 막힌다.

### ① 앱에 들어가는 길을 몰랐다

어제 보고서에 이렇게 적혀 있다.

```
언어 선택 → "GABOLLE 시작하기" → 온보딩 1 → 온보딩 2 → 온보딩 3 → ??? → 메인 화면
                                                                  ↑ 이 부분을 정확히 모름
```

**「???」는 화면 두 개다 — 나이 확인, 그리고 권한 안내.** 온보딩 3페이지에서 「다음」을
계속 눌러도 메인에 안 간다. 정확한 순서는 [2장](#2-앱에-들어가는-길--이-순서-하나뿐이다)에 있다.

### ② 글자로 요소를 찾았다 — 그래서 **없는 성공**을 찍었다

어제 스크립트는 이렇게 찾았다.

```python
(AppiumBy.XPATH, f"//*[contains(@label, '{text}')]")     # ❌
```

그리고 탭바를 `["여행", "일정", "현장", "부슐랭"]` 로 찾았다. 그런데

- **진짜 탭 이름은 그게 아니다** — `홈 · 피드 · 여행 만들기 · 내 여행 · 마이페이지`
- 온보딩 3페이지 **본문**에 「…마음에 든 곳은 **부슐랭**과 꼭 갈 장소에…」가 있다

그래서 온보딩 화면에서 `contains('부슐랭')` 이 걸렸고, 로그는 이렇게 찍혔다.

```
✅ 탭: 부슐랭
✅ 시나리오 6 완료
완료된 시나리오: 6/6
```

**같은 순간 스크린샷은 온보딩 3페이지였다.** 로그가 거짓말을 한 것이다.

### ③ 못 찾아도 다음 줄로 넘어갔다

그래서 아무 데도 못 갔는데 마지막에 「6/6 완료」가 남았다. 보고서 하나는
「20/20 성공」이라 썼고 다른 하나는 「기능 테스트 0%」라고 썼다. **뒤엣것이 사실이었다.**

## 2. 앱에 들어가는 길 — 이 순서 하나뿐이다

```
 ┌─────────────────────────────────────────────────────────────┐
 │ 언어 선택        lang-ko           ← 한국어를 누른다         │
 │      ↓                                                       │
 │ 앱 소개 3장      app-intro-skip    ← 「건너뛰기」 한 번이면   │
 │      ↓                               세 장을 다 넘긴다        │
 │ 나이 확인        age-gate-check    ← 체크 먼저               │
 │                  age-gate-continue ← 그다음 계속             │
 │      ↓                                                       │
 │ 권한 안내        permissions-browse-guest  ← 비회원 둘러보기 │
 │      ↓                                                       │
 │ 🎯 메인          tab-home 이 보이면 도착                     │
 └─────────────────────────────────────────────────────────────┘
```

**「다음」을 세 번 눌러도 된다**(`app-intro-primary` × 3). 하지만 `app-intro-skip` 한 번이
더 짧고 덜 흔들린다.

### 🔴 선택자 표 — 이 이름으로만 찾는다

`testID` 는 iOS 에서 **accessibility identifier** 로 나간다. Appium 에서는
`AppiumBy.ACCESSIBILITY_ID` 로 찾는다. **글자(label/name)로 찾지 않는다.**

| 화면 | 선택자 |
|---|---|
| 언어 선택 | `lang-ko` `lang-en` `lang-ja` `lang-zh-Hans` `lang-zh-Hant` · `start-gabolle` |
| 앱 소개 | `app-intro-skip` (건너뛰기) · `app-intro-primary` (다음/시작하기) |
| 나이 확인 | `age-gate-check` · `age-gate-continue` |
| 권한 안내 | `permissions-browse-guest` · `permissions-continue` · `permissions-later` |
| 탭바 | `tab-home` `tab-feed` `tab-schedule` `tab-map` `tab-me` |
| 장소 사진 출처 | `place-photo-credit` |

이 이름들은 프론트 시험이 지킨다(`entryTestIds.test.tsx` 등). 누가 조용히 바꾸면 CI 가
먼저 빨개지므로, **이 표는 낡지 않는다.**

### 탭바 이름 — 어제 틀렸던 자리

| 선택자 | 화면에 보이는 한국어 | 영어로 바꾸면 |
|---|---|---|
| `tab-home` | 홈 | Home |
| `tab-feed` | 피드 | Feed |
| `tab-schedule` | 여행 만들기 | Create |
| `tab-map` | 내 여행 | My trips |
| `tab-me` | 마이페이지 | Profile |

**「여행」「일정」「현장」「부슐랭」이라는 탭은 없다.** 어제 찾던 이름이다.
그리고 언어를 바꾸면 오른쪽 칸이 통째로 달라진다 — **선택자는 안 바뀐다.** 그래서 선택자로 찾는다.

## 4. 이번에 특별히 봐야 할 것 — 오늘 고친 5건

자동화는 **거기까지 데려다주는 일**만 한다. 아래 판정은 **스크린샷을 보고 사람이** 한다.

| 티켓 | 어느 스크린샷 | 무엇이 보여야 정상인가 |
|---|---|---|
| **1187** 사진 올리기 | 직접 해 본다(아래 5장) | 사진이 미리보기에 뜬다. 「실패 · 다시 시도」가 **안** 뜬다 |
| **1199** 로그인 뒤로가기 | `41-after-back` | 로그인한 상태에서 뒤로 갔을 때 로그인 화면이 **다시 안 뜬다** |
| **1200** 환율·버스 | `31-exchange` | 「**아직 준비 중이에요**」 · 「다시 시도」 단추가 **없다** |
| **1202** 장소 상세 | `21-place-detail` | 경사도가 `2.7%` 처럼 보인다. `{"score":2.7,...}` 같은 **JSON 이 안 보인다**. 영업시간이 「매일 10:00~20:00」처럼 읽힌다 |
| **1203** 사진 위 글자 | `21-place-detail` | 사진 아래쪽 「사진 제공: 한국관광공사 …」가 **읽힌다** |

> 1200 에서 「제공처가 잠시 응답하지 않아요 · **다시 시도**」가 뜨면 **옛 빌드를 깐 것이다.**
> TestFlight 에서 최신 빌드인지 다시 확인한다.

## 5. 자동화로 못 하는 것 — 손으로 해 주면 제일 고맙다

스크립트가 끝난 뒤, **앱을 그대로 두고** 아래 셋만 손으로 봐 주면 된다. 각 5분이면 된다.

### 5-1. 🔴 사진 올리기 (가장 중요 — S15P21E201-1187)

1. 마이페이지 → 로그인 → **구글**로 로그인
2. **뒤로 가기를 한 번** 눌러 본다 → 로그인 화면이 다시 뜨면 **그걸 찍어서 알려 준다** (1199)
3. 피드 탭 → 오른쪽 아래 **연필** 단추
4. 아무 글자나 쓰고 → **+ 사진 추가** → 사진 하나 고름
5. **미리보기에 사진이 뜨는가?**
   - 뜬다 → 🟢 정상
   - 「실패 · 다시 시도」가 뜬다 → 🔴 **괄호 안 영어까지 통째로 찍어서 보내 준다.**
     그 한 줄이 원인이다
6. 「기록 올리기」 → 피드 맨 위에 방금 올린 사진이 보이면 끝까지 된 것이다

### 5-2. 현장 도구에서 소리 나는가

홈 → 현장 도구 → 「장소별 한국어」 → 문장 하나 눌러 재생.
**요소가 있다고 소리가 난 게 아니다** — 자동화로는 판정 못 한다. 귀로 듣는다.

### 5-3. 지도가 실제로 그려지는가

내 여행 → 여행 하나 → 지도.
**회색 네모만 있고 지도 타일이 안 그려지는 경우**가 있다. 눈으로 본다.

## 7. 막혔을 때

| 증상 | 이유와 조치 |
|---|---|
| `element could not be located: lang-ko` | 앱이 **이미 온보딩을 지난 상태**다. 아이폰에서 앱을 지우고 TestFlight 로 다시 깐 뒤 돌린다 |
| `element could not be located: age-gate-check` | **옛 빌드다.** TestFlight 최신 빌드로 업데이트한다 |
| `Could not connect to Appium` | 1-4 의 `appium` 창이 꺼졌다. 다시 띄운다 |
| WebDriverAgent 서명 오류 | Xcode 로 `WebDriverAgentRunner` 를 한 번 직접 빌드해 서명해야 한다. Appium 이 알려 주는 경로를 Xcode 로 열고, Signing 탭에서 본인 Apple ID 팀을 고른 뒤 ⌘B |
| 아이폰에서 「신뢰하지 않은 개발자」 | 아이폰 → 설정 → 일반 → VPN 및 기기 관리 → 본인 계정 → 신뢰 |
| 중간에 아이폰 화면이 꺼짐 | 설정 → 디스플레이 및 밝기 → 자동 잠금 → **안 함** |

## 8. 이 문서가 확인하지 못한 것

- **WebDriverAgent 최초 서명**은 맥북마다 다르다. 이 문서는 그 과정을 실제로 돌려 보지 못했다 —
  어제 이미 성공했다고 들었으므로 그 설정이 남아 있으면 그대로 될 것이다
- 시나리오 중 **장소 상세로 들어가는 부분**은 목록의 셀 순서로 누른다. 데이터가 바뀌면
  다른 장소가 열릴 수 있다 — 그래도 **경사도·영업시간·사진 출처를 보는 목적에는 지장이 없다**
- 자동화가 **판정하는 것은 크래시뿐**이다. 나머지는 전부 사람이 그림을 보고 판정한다.
  그게 이 앱에서 여러 번 확인된 사실이다 — 화면의 결함은 어떤 자동 검사도 안 잡는다
