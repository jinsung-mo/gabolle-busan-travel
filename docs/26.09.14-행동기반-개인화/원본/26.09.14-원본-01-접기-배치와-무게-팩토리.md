## foldSurvey — 설문 답을 성분으로 바꾸는 부분 (787 고침 반영 후)

경로: `backend/src/main/java/com/gabolle/backend/batch/application/TasteVectorFoldService.java`

```java
	private List<UserTasteWeight> foldSurvey(UUID tasteVectorId, SurveySource survey, OffsetDateTime asOf) {
		List<UserTasteWeight> result = new ArrayList<>();
		if (survey == null) {
			return result;
		}

		for (SurveyAnswer answer : survey.answers()) {
			TasteDimension dimension = parseDimension(answer.dimension());
			if (dimension == null) {
				log.warn("모르는 취향 차원이라 성분으로 접지 못했다 dimension={} snapshot={}", answer.dimension(), survey.snapshotId());
				continue;
			}

			List<String> codes = PreferenceJson.parseCodes(answer.valueJson(), this.objectMapper);
			if (!codes.isEmpty()) {
				for (String code : codes) {
					result.add(UserTasteWeight.fromSurvey(tasteVectorId, dimension, code, 1.0, asOf));
				}
				continue;
			}

			Double score = PreferenceJson.parseScore(answer.valueJson(), this.objectMapper);
			if (score != null) {
				result.add(UserTasteWeight.fromSurvey(tasteVectorId, dimension, SCORE_CODE, toWeight(score), asOf));
			}
		}
		return result;
	}

	private static double toWeight(double score) {
		return Math.max(-1.0, Math.min(1.0, (score * 2.0) - 1.0));
	}
```

행동 신호는 이 메서드가 아니라 `countTasteSignals`(개수만 셈)에서만 쓰인다. `fold()` 본문:

```java
		int newEvents = allowsBehaviorPersonalization(userId) ? countTasteSignals(userId, watermark, asOf) : 0;
		...
		UserTasteVector next = UserTasteVector.open(userId, nextVersion, ..., cumulativeEvents, ...);
		this.vectors.save(next);

		List<UserTasteWeight> folded = foldSurvey(next.getTasteVectorId(), survey, asOf);
```

→ `newEvents`(행동 개수)는 벡터의 `observedEventCount` 로만 누적되고, **`UserTasteWeight` 행을 만드는 코드 경로에는 전혀 들어가지 않는다.** 행동을 성분으로 바꾸는 호출은 코드 어디에도 없다.

## UserTasteWeight 의 세 팩토리

경로: `backend/src/main/java/com/gabolle/backend/preference/domain/UserTasteWeight.java`

```java
	public static UserTasteWeight fromSurvey(UUID tasteVectorId, TasteDimension dimension, String code, double weight,
			OffsetDateTime updatedAt) {
		return new UserTasteWeight(new UserTasteWeightId(tasteVectorId, dimension, code), weight, TasteEvidence.SURVEY,
				0, updatedAt);
	}

	/** 앱에서의 행동으로 매긴 값. support 가 0 이면 DB 가 거부한다. */
	public static UserTasteWeight fromInteraction(UUID tasteVectorId, TasteDimension dimension, String code,
			double weight, int support, OffsetDateTime updatedAt) {
		return new UserTasteWeight(new UserTasteWeightId(tasteVectorId, dimension, code), weight,
				TasteEvidence.INTERACTION, support, updatedAt);
	}

	/** 설문 답을 행동으로 보정한 값. */
	public static UserTasteWeight blended(UUID tasteVectorId, TasteDimension dimension, String code, double weight,
			int support, OffsetDateTime updatedAt) {
		return new UserTasteWeight(new UserTasteWeightId(tasteVectorId, dimension, code), weight, TasteEvidence.BLENDED,
				support, updatedAt);
	}
```
