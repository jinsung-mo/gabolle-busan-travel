## event_outbox — 표 하나, 접수 엔드포인트 하나

마이그레이션 `V20260903123000__event_outbox_join_axes.sql`:

```sql
ALTER TABLE event_outbox
    ADD COLUMN request_id UUID,
    ADD COLUMN user_id    UUID,
    ADD COLUMN trip_id    UUID,
    ADD COLUMN producer   VARCHAR(16),
    ADD COLUMN seq        BIGSERIAL;
```

컨트롤러 (`EventIngestController.java`):

```java
@RestController
@RequestMapping("/api/v1/events")
@Profile({ "db", "dev" })
public class EventIngestController {
	@PostMapping
	public ResponseEntity<IngestEventResponse> ingest(@Valid @RequestBody IngestEventRequest req, ...)
```

→ 이벤트 종류별 전용 엔드포인트가 아니라 **모든 종류가 함께 쓰는 엔드포인트 하나**.

## 프론트엔드가 이 엔드포인트를 부르는가

```
$ git grep -rniE "api/v1/events|trackEvent|eventOutbox|EventIngest" origin/back/dev -- frontend/src
(결과 없음)
```

→ **프론트엔드 코드 전체에서 이벤트 전송 관련 호출이 0건.** 취향 신호뿐 아니라 클라이언트가
보내야 하는 이벤트(예: `RECOMMENDATION_IMPRESSION`, `PLACE_VIEW`) 전부 안 보내고 있다는 뜻.
