## 왜 만들었나

이번 대화에서 787 버그(설문 답이 안 접히던 문제)를 리뷰하다가, "그럼 행동 기반
개인화 전체는 어디까지 돼 있나"를 물었더니 — 검증되지 않은 인상("몇 종은 막혀 있다")
정도만 나왔다. 그걸 **실측으로 끝까지 따라가 보니, 문제는 한두 가지가 아니라 파이프라인
전 구간에 걸쳐 있었고, 그중에는 "코드로 못 정하는 결정"과 "이미 다 만들어져 있는데
안 쓰는 것"이 섞여 있었다.** 다음에 이 영역을 다시 열 때(다른 세션·다른 사람이어도)
매번 코드를 처음부터 다시 훑지 않도록, 오늘 확인한 것을 반복되는 모양으로 남긴다.
