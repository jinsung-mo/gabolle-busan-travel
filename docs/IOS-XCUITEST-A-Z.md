## 0. 먼저 읽는다 — 이 문서가 쓰는 말

한 팀에 백엔드·프론트·AI·인프라가 섞여 있어서, 한쪽에 당연한 말이 다른 쪽에는 처음
듣는 말이다. 그래서 **처음 나오는 기술 용어는 그 자리에서 푼다.**

| 말 | 무엇인가 |
|---|---|
| **XCUITest** | 애플이 Xcode 안에 넣어 준 화면 자동조작 시험 도구. Swift 로 「이 버튼을 눌러라 / 이 글자가 보이는지 봐라」를 적으면 시뮬레이터나 실기기를 대신 조작해 준다 |
| **UI Test Target**(UI 테스트 타깃) | Xcode 프로젝트 안에 두는 **시험 전용 묶음**. 앱 본체와 별개로 빌드되고, 앱을 바깥에서 조작한다 |
| **accessibilityIdentifier**(접근성 식별자) | 화면 요소에 붙은 **사람 눈에 안 보이는 이름표**. XCUITest 는 이것으로 요소를 찾는다. 글자와 달리 **언어를 바꿔도 안 변한다** |
| **testID** | 리액트 네이티브(우리 앱이 쓰는 기술)에서 요소에 이름표를 붙이는 속성. iOS 로 나갈 때 위의 accessibilityIdentifier 가 된다 — **둘은 같은 것**이다 |
| **accessibilityLabel**(접근성 레이블) | 화면 낭독기가 읽어 주는 **글자**. 언어를 바꾸면 **같이 바뀐다** |
| **Expo / CNG** | 우리 앱을 만든 틀. `ios/` 폴더를 저장소에 두지 않고 **필요할 때 만들어 쓴다**(Continuous Native Generation). 그래서 Xcode 프로젝트를 먼저 **생성**해야 한다 |
| **prebuild** | 그 `ios/` 폴더(= Xcode 프로젝트)를 실제로 만들어 내는 명령 |
| **딥링크(deep link)** | `gabolle://field/menu-scan` 처럼 **앱 안의 특정 화면을 바로 여는 주소** |
| **시뮬레이터(Simulator)** | 맥 안에서 도는 가짜 아이폰 |
| **simctl** | 그 시뮬레이터를 명령줄에서 조종하는 애플 도구 |
| **게스트(비회원)** | 로그인하지 않고 둘러보는 상태. 우리 앱은 이 상태를 정식으로 지원한다 |
| **ProtectedRoute** | 로그인해야만 볼 수 있는 화면을 막아 주는 장치. 막을 때 **원래 가려던 곳을 기억**해 뒀다가 로그인 뒤 그리로 보낸다 |

### 🔴 항목을 기호로만 부르지 않는다

이 문서 안에서 **「B-3」 같은 번호만 적어 놓고 넘어가지 않는다.** 번호는 되찾기 위한
주소일 뿐이고, 주소만 말하는 것은 아무 말도 안 한 것이다. 버그를 적을 때도 마찬가지다 —
**「C-2 실패」가 아니라 「회원가입 비밀번호 규칙 표시가 안 뜸(C-2)」** 이라고 적는다.

## 2. 준비 — Xcode 에서 자동화가 돌게 만들기

### 2-1. 맥이 필요하다

Xcode 도 XCUITest 도 **macOS 전용**이다. 윈도우에서는 이 문서를 못 쓴다.

### 2-2. Xcode 프로젝트를 만든다

우리 저장소에는 `ios/` 폴더가 **없다**(1절의 CNG). 아래로 만든다.

```bash
git clone https://lab.ssafy.com/s15-bigdata-dist-sub1/S15P21E201.git
cd S15P21E201/frontend
git checkout front/dev          # 시험 대상 브랜치
npm ci
npx expo prebuild --platform ios --clean
cd ios && pod install && cd ..
open ios/GABOLLE.xcworkspace     # 🔴 .xcodeproj 가 아니라 .xcworkspace 를 연다
```

> 🔴 **`.xcworkspace` 를 연다.** `.xcodeproj` 를 열면 CocoaPods(라이브러리 묶음 관리
> 도구)가 넣어 준 것들이 빠져서 빌드가 깨진다. 이건 Expo·RN 프로젝트의 고정된 규칙이다.

> 🔴 **`prebuild --clean` 은 `ios/` 를 통째로 지우고 다시 만든다.** Xcode 에서 손으로
> 넣은 설정(아래 2-3의 UI 테스트 타깃 포함)이 **같이 사라진다.** 그래서 순서는 언제나
> **prebuild 먼저 → 타깃 추가 → 시험** 이다. 다시 prebuild 하면 타깃을 다시 넣는다.
> 타깃 파일(`.swift`)은 `ios/` 바깥(예: `frontend/uitests/`)에 두고 참조만 하면 덜 아프다.

## 3. 🔴 자동화의 최대 약점 — 이것을 모르고 시작하면 어제와 같아진다

### 3-1. 이름표(`testID`)가 있는 자리 — 여기서는 글자로 안 찾는다

```

start-gabolle
app-intro-skip      app-intro-primary
age-gate-check      age-gate-continue
permissions-later   permissions-continue   permissions-browse-guest

── 2026-09-19 에 새로 심은 것 (S15P21E201-1336) ───────────────────

              sign-up-name         sign-up-next         sign-up-submit

              itinerary-save-order itinerary-cancel-order

```

> 🔴 **현장 도구의 이름은 `field-speak`·`field-transit` 이 아니다.** 타일의 이름표는
> 코드에 이미 있던 `key` 로 만들어진다(`menu` `phrase` `exchange` `bus` `weather`).
> 문서에 맞추려고 코드 이름을 바꾸지 않았다 — 코드가 진짜이고 문서가 따라간다.
>
> 🔴 **`sign-up-submit` 은 화면에 두 번 적혀 있다.** 넓은 화면용과 좁은 화면(패널)용
> 가입 버튼이 따로 있고 **한 번에 하나만 그려진다.** `firstMatch` 로 잡으면 맞다.
>
> 🔴 **`itinerary-day-<번호>` 는 1부터 센다.** `itinerary-day-1` 이 1일차다.
> 화면에 보이는 「1일차」와 같은 번호라 헷갈리지 않는다.

이 이름들은 **`frontend/src/components/__tests__/automationTestIds.test.ts`** 가 지킨다.
누가 지우거나 이름을 바꾸면 **CI 가 먼저 빨개진다** — 자동화가 조용히 거짓 성공을
찍기 전에. 그래서 **이 표는 낡지 않는다.**

**아직 이름표가 없는 화면이 둘 있다** — 아래 3-3.
그 밖의 버튼은 **화면에 보이는 글자(accessibilityLabel)** 로 찾고, **그 글자는 언어를
바꾸면 통째로 달라진다.**

### 3-2. 그래서 이 시험은 규칙 셋을 지킨다

1. **언어를 한국어(`lang-ko`)로 고정하고 A~Y 를 돈다.** 글자 기반 선택자가 안정된다
2. **다국어는 Z장에서 따로, 이름표가 있는 요소만으로** 돈다
3. **글자로 찾을 때는 「포함」이 아니라 「완전히 같음」으로 찾는다.**
   `contains` 로 찾으면 다른 화면의 본문 글자에 걸려서 **없는 성공을 찍는다** —
   2026-09-17 밤에 실제로 그랬다. 온보딩 본문의 「부슐랭」이라는 낱말에 걸려서
   로그에는 「✅ 탭: 부슐랭 · 6/6 완료」가 찍혔고, **같은 순간 스크린샷은 온보딩 3페이지**였다

### 3-3. 아직 이름표가 없는 두 화면

다섯 화면에는 2026-09-19 에 심었다(위 3-1). **둘은 못 심었다** — 그때 다른 사람이
그 파일을 잡고 있었다. 선점 장치가 「코드 충돌이 나기 전에 의도 충돌을 먼저 터뜨리는」
일을 한 것이고, 뺏지 않는 것이 규칙이다.

| 화면 | 넣을 이름표 | 왜 아직 없나 |
|---|---|---|
| 여행 만들기 10문항 `app/(plan)/questions.tsx` | `plan-q-<질문키>` `plan-next` `plan-skip` `plan-submit` | 장효준이 `S15P21E201-1337`(날짜 없이 일정 만들기로 못 가게 한다)로 잡고 있었다 |
| 메뉴판 읽기 `app/field/menu-scan.tsx` | `menu-take-photo` `menu-pick-album` `menu-ask-dish-<번호>` `menu-dish-image` | 같은 파일을 `S15P21E201-1335`(그림 시험)이 고치는 중이었다 |

**그래서 K장(여행 만들기)과 W장(메뉴판)은 반자동이다.** 그 두 장은 이름표가 들어올
때까지 **글자로 찾거나 스크린샷만 남긴다.** 결과표에는
**「글자로 찾음 — 언어 바꾸면 깨짐」** 이라고 적는다.

**풀리는 대로 이예승이 넣고 쪽지로 알린다.** 그 전에 필요하면 말해 달라 —
순서를 바꿀 수 있다.

## 4. 자동화 뼈대 — 이 Swift 파일 셋을 먼저 넣는다

### 4-1. `GabolleUITestCase.swift` — 모든 시험의 바닥

```swift
import XCTest

/// 가볼래 UI 시험의 공통 바닥.
///
/// 🔴 여기서 정하는 것 셋:
///   1. 요소를 «이름표»로 찾는다. 이름표가 없으면 «글자가 완전히 같은 것»으로 찾는다.
///   2. 못 찾으면 «그 자리에서 멈춘다». 다음 줄로 넘어가면 없는 성공을 찍는다.
///   3. 단계마다 스크린샷을 남긴다. 로그는 거짓말할 수 있고 사진은 못 한다.
class GabolleUITestCase: XCTestCase {

    var app: XCUIApplication!
    private var shotIndex = 0

    override func setUpWithError() throws {
        continueAfterFailure = false      // 🔴 실패하면 멈춘다
        app = XCUIApplication()
        app.launchArguments += ["-AppleLanguages", "(ko)", "-AppleLocale", "ko_KR"]
        watchSystemAlerts()
        app.launch()
    }

    override func tearDownWithError() throws {
        shot("zz-마지막화면")
        app.terminate()
    }

    // ── 찾기 ────────────────────────────────────────────────────────────

    /// 이름표(testID = accessibilityIdentifier)로 찾는다. 언어를 바꿔도 안 변한다.
    func byId(_ identifier: String) -> XCUIElement {
        app.descendants(matching: .any).matching(identifier: identifier).firstMatch
    }

    /// 화면 글자로 찾는다. 🔴 «완전히 같음»이다 — contains 를 쓰지 않는다.
    func byLabel(_ label: String) -> XCUIElement {
        let exact = NSPredicate(format: "label == %@", label)
        return app.descendants(matching: .any).matching(exact).firstMatch
    }

    /// 글자가 화면 어딘가에 «보이는가»만 볼 때. 누를 때는 쓰지 않는다.
    func textExists(_ text: String, timeout: TimeInterval = 8) -> Bool {
        let contains = NSPredicate(format: "label CONTAINS %@", text)
        return app.descendants(matching: .any).matching(contains).firstMatch
            .waitForExistence(timeout: timeout)
    }

    // ── 누르기 ──────────────────────────────────────────────────────────

    /// 누른다. 못 찾으면 «그 자리에서 실패»하고 멈춘다.
    func tap(_ element: XCUIElement, _ what: String, timeout: TimeInterval = 12) {
        guard element.waitForExistence(timeout: timeout) else {
            shot("실패-\(what)")
            XCTFail("못 찾았다: \(what) — 이 화면에 그 요소가 없다")
            return
        }
        guard element.isHittable else {
            element.coordinate(withNormalizedOffset: CGVector(dx: 0.5, dy: 0.5)).tap()
            return
        }
        element.tap()
    }

    func tapId(_ identifier: String, timeout: TimeInterval = 12) {
        tap(byId(identifier), identifier, timeout: timeout)
    }

    func tapLabel(_ label: String, timeout: TimeInterval = 12) {
        tap(byLabel(label), "「\(label)」", timeout: timeout)
    }

    func type(_ element: XCUIElement, _ text: String, _ what: String) {
        tap(element, what)
        element.typeText(text)
    }

    // ── 남기기 ──────────────────────────────────────────────────────────

    /// 🔴 판정은 사람이 사진을 보고 한다. 자동화는 «거기까지 데려다주는 일»만 한다.
    func shot(_ name: String) {
        shotIndex += 1
        let attachment = XCTAttachment(screenshot: XCUIScreen.main.screenshot())
        attachment.name = String(format: "%03d-%@", shotIndex, name)
        attachment.lifetime = .keepAlways
        add(attachment)
    }

    // ── 시스템 권한 창 ──────────────────────────────────────────────────

    /// 위치·알림·사진 허용 창이 뜨면 대신 눌러 준다.
    /// 🔴 2-4 의 `simctl privacy grant` 를 먼저 해 두면 이 창 자체가 안 뜬다. 이건 보험이다.
    private func watchSystemAlerts() {
        addUIInterruptionMonitor(withDescription: "시스템 권한 창") { alert in
            let yes = ["App을 사용하는 동안 허용", "허용", "확인", "승인",
                       "Allow While Using App", "Allow", "OK"]
            for title in yes where alert.buttons[title].exists {
                alert.buttons[title].tap()
                return true
            }
            return false
        }
    }

    /// 권한 창 감시기는 «앱을 한 번 건드려야» 깨어난다. 권한이 뜰 만한 곳 뒤에 부른다.
    func nudge() { app.tap() }

    // ── 딥링크 ──────────────────────────────────────────────────────────

    /// `gabolle://field/menu-scan` 같은 주소로 화면을 바로 연다.
    ///
    /// 🔴 XCUITest 는 앱에 주소를 직접 못 넘긴다. 사파리를 열어 주소를 치는 길뿐이다.
    ///    사파리의 주소창 이름은 iOS 판마다 다르므로 후보를 차례로 시도한다.
    func openDeepLink(_ url: String) {
        let safari = XCUIApplication(bundleIdentifier: "com.apple.mobilesafari")
        safari.launch()
        let bar = safari.textFields["Address"].exists ? safari.textFields["Address"]
                : safari.textFields["URL"].exists     ? safari.textFields["URL"]
                : safari.textFields.firstMatch
        guard bar.waitForExistence(timeout: 10) else {
            XCTFail("사파리 주소창을 못 찾았다 — iOS 판이 바뀌었을 수 있다")
            return
        }
        bar.tap()
        bar.typeText(url + "\n")
        let open = safari.buttons["열기"].exists ? safari.buttons["열기"] : safari.buttons["Open"]
        if open.waitForExistence(timeout: 5) { open.tap() }
        XCTAssertTrue(app.wait(for: .runningForeground, timeout: 15), "딥링크로 앱이 안 열렸다: \(url)")
    }
}
```

### 4-3. `BackSweep.swift` — 모든 화면에서 뒤로 가기 (Z장에서 쓴다)

```swift
import XCTest

/// 🔴 뒤로 갔을 때 «로그인 창이 뜨거나 앱이 꺼지는» 화면을 전수로 찾는다.
/// 이건 사람이 손으로 못 돈다 — 화면이 79개다.
final class BackSweepTests: GabolleUITestCase {

    /// 딥링크로 열 수 있는 화면 전부. 매개변수가 필요한 화면(`[id]`)은 Y장에서 따로 본다.
    static let routes = [
        "/home", "/feed", "/trips", "/me", "/saved", "/map",
        "/plan", "/plan/basic", "/plan/conditions", "/plan/taste", "/plan/confirm",
        "/explore", "/now", "/festivals", "/notifications", "/chat", "/help",
        "/collection", "/route-detail", "/app-intro",
        "/field/translate", "/field/menu-scan", "/field/speak",
        "/field/exchange-rate", "/field/transit",
        "/feed/compose",
        "/legal/terms", "/legal/privacy", "/legal/data-sources", "/legal/open-source",
        "/privacy",
    ]

    func test_모든_화면에서_뒤로_가면_앱이_살아_있고_로그인창이_안_뜬다() {
        enterAsGuest()

        for route in Self.routes {

            shot("열림\(route.replacingOccurrences(of: "/", with: "_"))")

            // 화면 안의 「뒤로」 단추가 있으면 그것을, 없으면 가장자리 스와이프.
            let back = byLabel("뒤로 가기").exists ? byLabel("뒤로 가기") : byLabel("이전 화면으로 이동")
            if back.exists { back.tap() } else { swipeBackFromEdge() }

            // 🔴 판정 셋
            XCTAssertEqual(app.state, .runningForeground, "뒤로 갔더니 앱이 꺼졌다: \(route)")
            XCTAssertFalse(textExists("로그인", timeout: 2) && textExists("비밀번호", timeout: 1),
                           "뒤로 갔더니 로그인 창이 떴다: \(route)")
            shot("뒤로\(route.replacingOccurrences(of: "/", with: "_"))")
        }
    }

    private func swipeBackFromEdge() {
        let left  = app.coordinate(withNormalizedOffset: CGVector(dx: 0.01, dy: 0.5))
        let right = app.coordinate(withNormalizedOffset: CGVector(dx: 0.80, dy: 0.5))
        left.press(forDuration: 0.05, thenDragTo: right)
    }
}
```

# A부터 Z까지 — 기능 · 화면 · 누를 것 · 통과 기준

> **표 읽는 법**
> `[이름표]` 는 accessibilityIdentifier — **언어를 바꿔도 안 변한다. 이것이 있으면 이것을 쓴다.**
> `「글자」` 는 화면에 보이는 한국어 — 언어를 바꾸면 변한다.
> **👁 사람이 볼 것** = 자동화가 판정 못 하고 **스크린샷을 눈으로 봐야** 하는 것.

---

## A. 앱 최초 실행 · 언어 선택

**기능** — 앱을 처음 켠 사람에게 언어를 묻고 시작시킨다.
**화면** `app/index.tsx`

| 누를 것 | 무엇 |
|---|---|
| `[lang-ko]` `[lang-en]` `[lang-ja]` `[lang-zh-Hans]` `[lang-zh-Hant]` | 언어 5개 |
| `[language]` | 언어 고르는 칸 전체 |
| `[start-gabolle]` | 「GABOLLE 시작하기」 |
| `「가볼래 AI 여행 도우미 열기」` | 시작 화면에서 바로 챗봇 열기 → J장 |

**자동화**
1. 앱을 지우고 다시 깐 상태에서 연다(`xcrun simctl uninstall booted com.gabolle.app` 뒤 재설치)
2. 언어 5개를 차례로 눌러 보고 **그때마다 화면 글자가 그 언어로 바뀌는지** 스크린샷
3. `[lang-ko]` → `[start-gabolle]`

**통과** 다섯 언어가 모두 눌리고, 시작 버튼이 다음 화면으로 넘긴다.
**👁 사람이 볼 것** 언어를 골랐을 때 **이 화면 자체의 글자**가 바뀌는가. 안 바뀌면 버그.

---

## B. 앱 소개 · 나이 확인 · 권한 안내

**기능** — 처음 들어오는 사람에게 앱을 소개하고, 만 14세 확인을 받고, 권한을 설명한다.
**화면** `app/app-intro.tsx` · `app/(auth)/age-gate.tsx` · `app/(onboarding)/permissions.tsx`

| 누를 것 | 무엇 |
|---|---|
| `[app-intro-skip]` | 소개 3장 한 번에 건너뛰기 |
| `[app-intro-primary]` | 「다음」/「시작하기」 — 3번 누르면 끝 |
| `[age-gate-check]` → `[age-gate-continue]` | 🔴 **체크가 먼저다.** 안 하고 계속을 누르면 안 넘어간다 |
| `[permissions-continue]` | 권한 안내 후 계속(→ 로그인) |
| `[permissions-later]` | 나중에 |
| `[permissions-browse-guest]` | 비회원으로 둘러보기(→ 홈) |
| `「개인정보 처리 안내 보기」` | 개인정보 화면으로 |
| `「여행 알림 받기」` | 알림 권한 요청 |

**자동화** `[app-intro-primary]` 를 3번 누르는 길과 `[app-intro-skip]` 한 번 누르는 길을
**둘 다** 돌린다. 나이 확인에서 **체크 없이 계속**을 눌러 보고 **안 넘어가는 것**을 확인한다.

**통과** 세 갈래(`continue`/`later`/`browse-guest`)가 각각 다른 곳으로 간다.
**👁 사람이 볼 것** 나이 확인 체크 안 한 상태에서 계속 버튼이 **흐리게(비활성)** 보이는가.

## C. 회원가입 · 메일 인증

**기능** — 이메일로 가입하고, 메일의 링크로 인증을 마친다.
**화면** `app/(auth)/sign-up.tsx` · `app/auth/email/verify.tsx`

| 누를 것 / 채울 것 | 무엇 |
|---|---|
| `[sign-up-email]` · `「이메일 지우기」` | 이메일 입력 · 지우기 |
| `[sign-up-password]` · `「비밀번호 지우기」` | 자리표시자 `영문·숫자·특수문자 포함 8~64자` |
| `[sign-up-confirm]` · `「비밀번호 확인 지우기」` | 자리표시자 `한 번 더 입력하세요` |
| `[sign-up-name]` · `「이름 지우기」` | 자리표시자 `1~30자` |
| `「언어」` | 가입 시 언어 |
| `「만 14세 이상입니다.」` | 필수 체크 |
| `「이용약관에 동의합니다. (필수)」` | 필수 체크 → 누르면 `/legal/terms` |
| `「개인정보 처리방침에 동의합니다. (필수)」` | 필수 체크 → 누르면 `/legal/privacy` |
| `[sign-up-next]` | 단계 진행(좁은 화면) |
| `[sign-up-submit]` | 가입 — 넓은 화면·좁은 화면에 하나씩 있고 «한 번에 하나만» 그려진다 |
| `「이메일 확인 후 로그인」` | 가입 완료 뒤 |
| `「비회원으로 둘러보기」` | 가입 안 하고 홈으로 |

**비밀번호 규칙 표시** — 입력하는 동안 `「8~64자」` `「영문」` `「숫자」` `「특수문자 (!@#$% 등)」`
네 줄이 조건을 만족할 때마다 바뀐다.

**자동화 — 반드시 실패 경로까지 돈다**

| 넣는 값 | 기대 |
|---|---|
| `abc`(형식이 아닌 메일) | 「이메일」 오류 표시, 다음 안 눌림 |
| `qa+<타임스탬프>@example.com` + `short` | 비밀번호 규칙 네 줄 중 미달 항목이 표시됨 |
| 비밀번호와 확인이 **다름** | 「한 번 더 입력하세요」 자리에 불일치 표시 |
| 체크 셋 중 하나만 안 함 | 다음이 안 눌림 |
| 전부 올바름 | 「이메일 확인 후 로그인」 화면 |
| **같은 메일로 한 번 더** | 「이미 가입된 이메일이에요」 |

**👁 사람이 볼 것** 규칙 네 줄이 **입력에 따라 실제로 색/상태가 바뀌는지**. 안 바뀌면 버그.

**기능** — 이메일 로그인, 비밀번호를 잊었을 때 메일로 재설정.
**화면** `app/(auth)/sign-in.tsx` · `app/(auth)/forgot-password.tsx` · `app/auth/password/reset.tsx`

| 누를 것 | 무엇 |
|---|---|
| `[sign-in]` | 로그인 진입(권한 화면에서) |
| `[sign-in-email]` `[sign-in-password]` `[sign-in-submit]` | 입력 · 로그인 |
| `「이메일 지우기」` `「비밀번호 지우기」` | 지우기 |
| `「비밀번호 찾기」` | → `/forgot-password` |
| `「GABOLLE 홈으로 이동」` | 로고 |
| `「소셜 로그인 처리 중」` | 소셜 진행 표시(E장) |
| 비밀번호 찾기: `「이메일」` → `「재설정 링크 받기」` `「메일 다시 보내기」` `「로그인으로 돌아가기」` | |

2. 로그인 시도를 빠르게 반복 → 「로그인 시도가 너무 많아요」 가 뜨는지 (**속도 제한**)
3. 맞는 계정 → 홈(`[tab-home]`)
4. 🔴 **로그인 직후 뒤로 가기** → **로그인 창이 다시 뜨면 버그**(과거 `S15P21E201-1199`)

**👁 사람이 볼 것** 비밀번호 보기/숨기기 버튼(`「비밀번호 보이기」`/`「비밀번호 숨기기」`)이
실제로 글자를 보여주고 감추는가.

## E. 소셜 로그인 · 계정 연결

**기능** — 소셜 계정으로 가입/로그인하고, 기존 계정에 연결한다.
**화면** `app/(auth)/oauth-signup.tsx` · `app/(auth)/oauth-link.tsx` · `app/oauth/[provider]/callback.tsx`

| 누를 것 | 무엇 |
|---|---|
| `「소셜」` 아래 제공자 버튼들 | 로그인 화면 하단 |
| 가입: `「이름」` · `「만 14세 이상입니다.」` · 약관 2개 · `「로그인으로 돌아가기」` | |
| 연결: `「비밀번호」` 입력 → 연결 · `「로그인으로 돌아가기」` | |

**자동화** 소셜 창은 앱 밖(사파리·애플 로그인 시트)으로 나간다. XCUITest 는 다른 앱을
`XCUIApplication(bundleIdentifier:)` 로 잡아야 하므로 **여기는 반자동으로 둔다.**

**👁 사람이 볼 것 (중요)**
- 애플 로그인으로 가입했을 때 **이메일이 비어 있지 않은가** — 스토어 제출을 막고 있던 항목이다
- 소셜로 들어간 뒤 「연결 정보가 만료됐어요」가 부당하게 뜨지 않는가
- 이미 그 메일로 일반 가입이 돼 있을 때 **연결 화면으로 유도되는가**(새 계정을 만들어 버리면 버그)

## F. 게스트(비회원) 둘러보기 — 로그인 유도가 제자리에서 뜨는가

**기능** — 로그인 없이 앱을 둘러보되, 계정이 필요한 동작에서만 로그인으로 보낸다.
**장치** `ProtectedRoute` — 공개 경로는 `/home` `/feed` `/trips` `/me` 넷.

**자동화 — 게스트로 들어가서(`enterAsGuest()`) 아래를 하나씩 누른다**

| 어디서 | 무엇을 | 기대 |
|---|---|---|
| 피드 | `「기록 남기기」` | 로그인 화면, **돌아오면 피드 작성으로 다시 감** |
| 내 여행 | `「새 여행」` | 로그인 화면 |
| 저장 | 하트/저장 | 로그인 화면 |

**자동화 — 한도가 있다. 이 속도를 반드시 지킨다**

> 🔴 **분당 3회, 하루 20회**가 메뉴판 읽기의 한도이고, AI 그림은 **분당 4회 · 하루 25회**다.
> 이보다 빠르게 부르면 `MENU_SCAN_RATE_LIMITED` 가 뜨는데 **이건 버그가 아니라 우리가
> 너무 빨리 부른 것이다.** 2026-09-19 에 내가 24번 중 21번을 이걸로 날렸다.
> **호출 사이에 22초를 둔다.**

1. 앨범에 메뉴판 사진 3장 이상을 미리 넣어 둔다(2-4의 `simctl addmedia`)
2. 사진 1장 → 결과 → **22초 쉬고** 다음 사진
3. 결과에서 **음식 줄 하나를 골라 `「이건 어떤 음식인가요?」`를 누르고 20초 기다린다**
4. 스크린샷

**🔴 이미 확인된 결함 — 이것들은 다시 올리지 않는다 (7절 참고)**
**👁 사람이 볼 것 (여기가 이 시험의 핵심이다)**

| 봐야 할 것 | 정상 | 결함 |
|---|---|---|
| 음식 이름 옆 소리 버튼 | 「한국어」「日本語」가 **가로로** 나란히 | **세로로 쌓여** 있고 이름 칸이 좁아져 두 줄로 잘림 |
| AI 그림 | 그림이 실제로 보임 | **흰 빈 상자**만 있고 「AI가 그린 그림이에요」 문구만 있음 |
| 첫 번째 메뉴 줄 | 이름·가격이 다 있음 | **가격이 빠지고** 「이건 어떤 음식인가요?」 버튼도 없음 |
| 사진 출처 줄 | 한 언어로 | 「**Example ·** 한국관광공사 관광사진갤러리」처럼 **영어+한국어 섞임** |
| 알레르기 낱말 | 사진에 실제로 적힌 낱말만 | 사진에 없는 낱말(「돼지고기」 등)을 **지어냄** |
| 같은 사진, 다른 언어 | 읽어 낸 줄 수가 같음 | 한국어 13줄 · 일본어 12줄처럼 **언어마다 다름** |

### Z-2. 다국어 — 5개 언어를 한 바퀴

**자동화** 언어마다 A장부터 들어가서 **이름표만으로** 홈까지 간 뒤,
`[tab-home]` `[tab-feed]` `[tab-schedule]` `[tab-map]` `[tab-me]` 다섯 탭과
현장 도구 넷을 열어 **스크린샷만 남긴다.**

```swift
for lang in ["ko", "en", "ja", "zh-Hans", "zh-Hant"] {
    tapId("lang-\(lang)"); tapId("start-gabolle"); tapId("app-intro-skip")
    tapId("age-gate-check"); tapId("age-gate-continue"); tapId("permissions-browse-guest")
    for t in ["home", "feed", "schedule", "map", "me"] { tapId("tab-\(t)"); shot("\(lang)-\(t)") }
    app.terminate(); app.launch()
}
```

**🔴 판정 기준 — 이 셋만 버그로 올린다**

| | 버그인가 |
|---|---|
| 일본어 화면에 **영어**가 섞임 | ❌ 아니다 — `uiTranslated: false` 로 공표된 상태다(1절) |

| 글자가 칸을 넘치거나 **잘림**(「관광사진갤러 / 리」) | ✅ 버그다 |
| 글자가 **겹침**·버튼이 화면 밖으로 나감 | ✅ 버그다 |

### Z-3. 전수 뒤로 가기 — 4-3의 `BackSweepTests`

**31개 화면**에서 뒤로 가기를 눌러 **① 앱이 안 꺼지는가 ② 로그인 창이 안 뜨는가** 를 본다.

### Z-4. 접근성

| 볼 것 | 기준 |
|---|---|
| 누르는 것의 크기 | 44×44 이상 |
| 글자 크게 하기 | iOS 설정에서 최대로 키우고 홈·일정·메뉴판을 열어 **글자가 안 잘리는가** |
| 화면 낭독기(VoiceOver) | 버튼마다 읽을 이름이 있는가(`「」`가 비어 있으면 안 됨) |
| 어두운 모드 | 글자와 배경 대비가 유지되는가 |

### Z-5. 견디기 시험

| 시험 | 방법 | 기대 |
|---|---|---|
| 비행기 모드 | 통신을 끊고 홈·일정·환율 열기 | 「서버 연결을 확인하고 있어요」가 뜨고, **통신이 돌아오면 저절로 복구** |
| 백그라운드 복귀 | 앱을 내렸다가 5분 뒤 올리기 | 있던 화면 그대로 |
| 회전 | 가로로 돌리기 | 깨지지 않음 |
| 연속 조작 | 탭 5개를 30번 빠르게 오가기 | 안 꺼짐 |

# 5. 버그를 올리기 전에 지나는 관문 셋

**여기를 통과 못 하면 티켓을 만들지 않는다.** 가짜 버그 하나가 진짜 버그 열 개를 묻는다.

| | 관문 | 왜 |
|---|---|---|
| **1** | **지금 코드에 아직 남아 있는가** | 이미 고쳐서 머지된 것을 옛 빌드에서 보고 올리는 일이 잦다. 앱 빌드 번호를 먼저 적는다 |
| **2** | **앱이 그린 것인가, 사용자가 올린 사진인가** | 피드의 사진 안에 한국어가 있는 것은 버그가 아니다. 사람이 찍어 올린 사진이다 |
| **3** | **배포 중이었는가** | 서버를 올리는 몇 분 동안은 502 가 난다. 시각을 적고, 5분 뒤 다시 해 본다 |

# 8. 시험 순서 — 하룻밤에 이렇게 돈다

```
1) 준비   prebuild → Xcode 열기 → UI 테스트 타깃 → simctl 권한·위치·사진   (40분)
2) 연기   Entry + BackSweep 만 먼저 돌린다 — 여기가 막히면 나머지가 무의미  (10분)
3) 전수   A~Z 를 순서대로. W장(메뉴판)은 22초 간격을 반드시 지킨다         (3~4시간)
4) 판정   스크린샷을 눈으로 보며 「👁 사람이 볼 것」을 채운다               (1시간)
5) 보고   6절 결과표 + 5절 양식으로 티켓                                    (30분)
```

> 🔴 **2번에서 막히면 3번으로 가지 않는다.** 앱에 못 들어가는데 A~Z 를 「통과」로
> 적는 일이 실제로 있었다.
