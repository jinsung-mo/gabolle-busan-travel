## 🔴 그림으로 그릴 것

이 자료로 만들면 좋은 그림들이다.

1. **두 개의 체** — 원천 728건이 `areaCode` 체에서 4건만, `lDongRegnCd` 체에서 61건이
   떨어지는 그림. 「아무 오류도 안 나는 고장」을 함께 표시
2. **세 단계 사슬** — 지역 필터 → 분류 판정 → 화면. **앞 하나만 고치면 뒤가 안 움직인다**
3. **겹치는 두 원** — `areacode` 빈 곳과 `cat1` 빈 곳이 **정확히 같다**(216=216, 933=933)
4. **띠 그래프** — 2,217곳을 받은 867 / 내일 560 / 미루는 790 으로 나누고,
   미루는 칸에서 **전통시장 45곳만 색을 달리해 빠져나오는** 그림
5. **전달 경로** — 문서 → 세션 → 세션으로 내려오며 추정이 사실이 되는 과정과,
   코드를 열어 되짚는 화살표
6. **갈래별 막대** — 지금 값과 이 원천에서 뽑히는 상한을 나란히. **60에 못 가는 넷**을 표시

## 🔴 읽을 때 주의할 것

- **숫자에는 날짜가 붙어 있다.** 원천은 날마다 조금씩 바뀐다 — 기존 수집본에서도 부산
  장소가 09-08 662곳 · 09-10 659곳 · 09-11 656곳으로 움직였다. 어느 숫자도 틀리지
  않았고 전부 그날의 진실이다
- **정정한 것은 지우지 않고 둘 다 남겼다.** 「639 → 2,218」은 여행코스 1곳을 포함한
  틀린 값이고 바른 값은 「638 → 2,217」이다. 둘 다 적혀 있다
- **「확인 못 함」은 「없다」가 아니다.** 이 자료에서 확인 못 한 것은 한도의 실제 값,
  영문·무장애 서비스의 곳수, 원천이 왜 옛 지역 칸을 안 채우는지다
