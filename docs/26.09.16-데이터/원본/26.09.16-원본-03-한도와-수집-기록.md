## 4. 오늘 부른 것을 오퍼레이션별로 세었다 (저장된 파일에서)

```
=== 오늘 전수 수집이 부른 것 (오퍼레이션별) ===
  areaBasedList2    26
  detailIntro2      867

=== 축제 수집기가 부른 것 ===
  searchFestival2   1
  detailIntro2      61
  detailImage2      61
  photo-check       61
```

`detailIntro2` 합계 = 61 + 867 = **928**. 929번째가 거부됐다.

🔴 **928 은 한도값이 아니다.** 「2026-09-16 에 이만큼은 받아졌다」는 사실이다.
한도가 1,000 이라면 그날 다른 곳에서 72건을 썼다는 뜻이고, 928 그 자체일 수도 있다.
**한도의 실제 값은 아직 확인 못 했다.**

## 6. 수집본 파일이 한 번 비워졌다

`--list-only` 를 `--resume` 없이 돌렸더니 커밋돼 있던 파일이 처음부터 다시 받아졌다.

```
=== 내 실행 전 파일 줄 수 / 지금 줄 수 ===
커밋된 것: 667 줄
지금:      26 줄
되돌린 뒤: 667 줄
```

원인은 설계대로다 — `--resume` 이 없으면 `writeFile(OUT_FILE, '')` 로 파일을 비운다.

```
297:    await writeFile(OUT_FILE, '')
```

`git checkout` 으로 되돌렸고 커밋에는 안 들어갔다.
