## 1. 축제를 지역 필터 셋으로 각각 세어 봤다

한국관광공사 `KorService2` 의 `searchFestival2` 오퍼레이션. 조건은
`eventStartDate=20260101`, `arrange=A`, `numOfRows=1`, `pageNo=1`.

```

areaCode=6 (관광용 부산)            4건
lDongRegnCd=26 (법정동 부산)        61건
```

## 2. 전국 728건을 전수로 받아 칸이 실제로 어떻게 차 있는지 세었다

🔴 **첫 집계는 틀렸다.** 칸 이름을 `areaCode`(카멜)로 세었는데 실제 칸은 `areacode`(소문자)다.
아래가 다시 센 값이다.

```
전국 축제 728건을 실제로 받았다
  areacode(소문자) 가 빈 것    715건
  lDongRegnCd 가 빈 것         0건
  areacode=6 로 세면           4건
  lDongRegnCd=26 로 세면       61건
  lDongRegnCd 로만 잡히고 areacode 로는 놓치는 것 57건
```

## 4. 장소도 같은 방식으로 세었다

`areaBasedList2` 오퍼레이션. 분류(`contentTypeId`)마다 두 필터로 각각 `totalCount` 를 읽었다.

```
분류            areaCode=6   lDongRegnCd=26   차이
관광지               135            351     +216
문화시설               32            120      +88
축제·행사              14             71      +57
여행코스                1              1        0
레포츠                28             62      +34
숙박                 63            118      +55
쇼핑                 47            980     +933
음식점               319            515     +196
합계                639           2218    +1579
```

🔴 **정정 (같은 날)** — 위의 합계 `639 → 2218` 은 **여행코스(`contentTypeId=25`) 1곳을
포함한 값**이다. 수집기(`collect/tourapi.mjs`)의 `CONTENT_TYPES` 에는 여행코스가 없다.
수집기가 실제로 받는 일곱 분류로는 **638 → 2,217** 이다. 차이는 정확히 그 1곳이다.
앞 숫자를 지우지 않고 둘 다 남긴다.
