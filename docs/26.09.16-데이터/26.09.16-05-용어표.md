# 05 — 용어표

모르는 말이 나오면 여기부터 본다. 약어를 늘려 쓰는 것이 아니라 **무엇을 하는지** 적는다.

---

## 원천과 수집

| 말 | 무엇 |
|---|---|
| **원천** | 데이터를 받아 오는 바깥의 출처. 여기서는 한국관광공사가 공공데이터포털로 여는 API |
| **수집기** | 원천에서 자료를 받아 파일로 저장하는 프로그램. `bigData/collect/` 에 있다 |
| **적재기** | 받아 둔 파일을 실제 서비스 DB 에 넣는 프로그램. 백엔드에 있다 |
| **오퍼레이션** | API 안에서 하나의 기능. 「목록 주세요」와 「상세 주세요」가 서로 다른 오퍼레이션이고, **호출 한도가 따로 걸린다** |
| **일일 한도** | 하루에 부를 수 있는 횟수. 넘으면 그날은 더 못 받는다. 자정에 풀린다 |
| **전수 조회** | 몇 건만 보는 것이 아니라 **전부** 받아서 세는 것 |

## 지역과 분류

| 말 | 무엇 |
|---|---|
| **`areacode`** | 관광용 지역코드. 부산은 `6`. 🔴 **대부분 빈 문자열로 온다** |
| **`lDongRegnCd`** | 법정동 시도코드 — 행정구역에 붙은 표준 번호. 부산은 `26`. 전부 차 있다 |
| **`cat1`·`cat3`** | 원천의 **옛** 분류 코드. `A01`(자연) 같은 모양. 2,217곳 중 27.7%에만 있다 |
| **`lclsSystm1·2·3`** | 원천의 **새** 분류 체계. `SH`·`FD`·`NA` 같은 두 글자. **전부에 있다** |
| **`contentTypeId`** | 무엇인지를 가르는 번호. 12 관광지 · 15 축제 · 39 음식점 등 |

## 우리 서비스의 말

| 말 | 무엇 |
|---|---|
| **갈래** | 탐색 화면에서 장소를 나누는 칸. 바다·자연·카페·도심·전통시장·야경·액티비티·산책 |
| **판정표** | 원천의 분류 코드를 우리 갈래로 옮기는 표. `bigData/config/facet-map.json` |
| **후보** | 추천 엔진이 고를 수 있는 장소 묶음. 갈래별로 몇 곳인지가 화면을 좌우한다 |
| **회차** | 축제처럼 **기간이 있는 것**의 한 번. 장소와 달리 시작일·종료일이 있어야 뜻이 있다 |

## 값의 확실함

| 말 | 무엇 | 화면 |
|---|---|---|
| **확인됨** | 실제로 조사했다 | 값 그대로 |
| **추정** | 어림잡았다 | 값 + (추정) |
| **확인 못 함** | **가서 봤는데 못 정했다** | 「알아봤지만 확인 못 했어요」 |
| **아직 안 알아봄** | **조사 자체를 안 했다** | 「? 아직 안 알아봤어요」 |

🔴 이 넷을 뭉개면 사람이 다친다. 2026-09-16에 **아무도 조사 안 한 알레르기 정보를 화면이
「확인됨 · 등록된 유발 성분이 없습니다」로 뒤집어 말하던 것**을 고쳤다.

## 도구와 일하는 방식

| 말 | 무엇 |
|---|---|
| **종료 코드** | 프로그램이 끝나면서 내는 숫자. **0이면 성공**, 그 외는 실패. 판정은 언제나 이것이다 |
| **worktree** | 같은 저장소의 다른 브랜치를 **옆 폴더로 펼쳐 둔 것**. 한 폴더에서 갈아타지 않으려고 쓴다 |
| **선점(claim)** | 파일을 고치기 전에 「내가 여기 잡는다」고 장부에 적는 것. 겹치면 그 자리에서 거부된다 |
| **MR** | 머지 리퀘스트. 내 브랜치를 팀 브랜치에 합쳐 달라는 요청 |
| **NotebookLM** | 문서를 넣으면 **그 문서만 근거로** 답하고 도표·마인드맵으로 바꿔 주는 도구. 넣은 문서 밖의 이야기는 안 한다 |
