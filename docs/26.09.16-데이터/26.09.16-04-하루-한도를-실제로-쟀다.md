# 04 — 하루 한도를 실제로 쟀다 (2026-09-16 실측)

원본: `원본/26.09.16-원본-03-한도와-수집-기록.md`

---

## 한 줄

> **문서 셋이 한도를 서로 다르게 말하고 있었고, 어느 것도 실측과 안 맞았다.**

---

## 1. 무엇이 문제인가

원천 API 는 하루에 부를 수 있는 횟수가 정해져 있다. 그 수를 모르면 **남은 일이 이틀인지
닷새인지 모른다.** 마감이 9/24라 짐작으로 일정을 짤 수 없다.

## 2. 문서 셋이 다 달랐다

| 어디 | 뭐라고 | 언제 적힌 것 |
|---|---|---|
| 수집기 머리말 | 일일 **10,000** | 2026-09-08 |
| 인수인계 문서 | 오퍼레이션당 **1,000** | 2026-09-16 |
| 코드 주석의 사고 기록 | 상세 **330건**에서 걸렸다 | 2026-09-11 |

**유일한 실측값(330)이 나머지 둘 어느 쪽과도 안 맞는다.**

## 3. 그래서 돌려 봤다 — 멈춘 지점이 곧 실측이다

수집기는 한도에 걸리면 **종료 코드 3**으로 깨끗이 멈추고 받은 데까지 파일에 남긴다.
그래서 **그냥 돌리는 것이 재는 방법**이 된다.

```
축제 수집기         상세 조회  61회
장소 전수 수집      상세 조회 867회
                  ─────────────
합계                       928회  →  929번째가 거부됨
```

## 4. 🔴 928은 한도값이 아니다

**「2026-09-16에 이만큼은 받아졌다」는 사실**이다. 두 가지가 가능하다.

- 한도가 **1,000**이고, 그날 다른 곳에서 72건을 썼다
- 한도가 **928** 그 자체다

**어느 쪽인지 확인 못 했다.** 그러니 인용할 때도 「한도는 928」이라고 적으면 안 된다.

한 가지는 확인됐다 — **한도는 오퍼레이션마다 따로 걸린다.** 상세 조회가 막힌 뒤에도
같은 서비스의 다른 오퍼레이션은 그 전까지 정상이었다.

## 5. 그래서 남은 일을 어떻게 나눴나

장소 2,217곳 중 상세를 받은 것은 **867곳**. 남은 **1,350곳**이 하루에 안 들어간다.

처음엔 「쇼핑 980곳은 영업시간 쓰임새가 낮으니 미루자」고 했다. 그런데 화면 코드를 본
결과 **절반만 맞았다.**

🔴 **전통시장 57곳이 쇼핑 980곳 안에 들어 있다.** 전통시장은 **갈래 하나**고, 갈래로 뽑힌
장소는 일정에 들어간다. 일정에 들어가면 영업시간 경고 대상이 된다 — **시장은 파장 시간이
특히 중요하다.**

그래서 이렇게 갈랐다.

```
받는다   음식점 515 + 남은 전통시장 45 = 560곳   ← 하루에 끝난다
미룬다   나머지 쇼핑 790곳                       ← 어느 갈래로도 안 뽑힌다
```

## 6. 미뤄도 거짓말이 안 나는 이유

영업시간이 없으면 화면이 이렇게 말한다.

> **「일부 장소는 영업시간 정보가 없어 확인하지 못했어요.」**

**「모른다」를 「열려 있다」로 바꿔 말하지 않게** 이미 만들어져 있다.
그래서 790곳을 미루는 위험이 생각보다 작다. 이 확인이 없었으면 못 미뤘을 것이다.

## 7. 🔴 하마터면 하루치를 날릴 뻔했다

수집본 파일은 **`.gitignore` 에 있으면서 동시에 git 이 추적한다**(예전에 누가 강제로 넣었다).
그리고 수집기는 `--resume` 없이 돌리면 그 파일을 **비우고 처음부터** 받는다(설계대로다).

그래서 목록만 받는 깃발로 돌렸더니 **667줄짜리 상세 수집본이 26줄짜리 목록 파일이 됐다.**
`git checkout` 으로 되돌렸고 커밋에는 안 들어갔다.

2026-09-11에는 같은 일로 상세 330건이 실제로 사라져 다음 날 다시 받았다. 이번엔 멈춘
867곳을 **브랜치에 커밋해 두고 MR 은 안 열었다** — 부분본이라 머지되면 안 된다.

## 8. 그림으로 그린다면

- **문서 셋이 서로 다른 값을 가리키는 그림**, 그 옆에 실측 화살표 하나
- 2,217곳을 **받은 867 / 내일 560 / 미루는 790** 으로 나눈 띠. 미루는 칸 안에
  전통시장 45곳만 색이 다르게 빠져나오는 그림
- 「한도값」과 「그날 받아진 수」를 나란히 놓고 **같지 않다**고 표시

## 9. 확인 못 한 것

- **한도의 실제 값.** data.go.kr 마이페이지를 사람이 로그인해서 봐야 한다
- 영문·무장애 서비스의 한도와 곳수 — 돌려 보지 않았다
