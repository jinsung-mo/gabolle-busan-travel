# 윈도우 노트북으로 가볼래 iOS 시험하기

**받는 사람: 모진성** — 삼성 윈도우 노트북 한 대로 iOS 시험을 맡게 된 사람.
읽는 데 7분, 준비 20분, 시험 40분.

---

## 0. 🔴 먼저 알아야 할 것 — 노트북은 시험 도구가 아니다

결론부터 적는다. **윈도우에서는 iOS 자동화 시험이 안 된다.** 설정을 잘못해서가 아니라
애플이 그렇게 만들어 두었다.

| 하려던 것 | 윈도우에서 | 왜 |
|---|---|---|
| Xcode 설치 | ❌ **불가능** | Xcode 는 **macOS 전용**이다. 윈도우판이 없다 |
| iOS 시뮬레이터 | ❌ 불가능 | Xcode 안에 들어 있다. 위와 같은 이유 |
| Appium 자동화 | ❌ 불가능 | iOS 를 모는 **XCUITest 드라이버**(**아이폰을 프로그램이 대신 눌러 주는 부품**)가 내부적으로 Xcode 를 부른다. Appium 자체는 윈도우에 깔리지만 **드라이버가 못 뜬다** |
| `.ipa` 를 USB 로 사이드로드 | ❌ 사실상 불가능 | 우리 빌드는 **스토어 서명**(`distribution: STORE`)이라 TestFlight·App Store 밖에서는 아예 안 깔린다. 3uTools 같은 것도 이건 못 연다 |
| **TestFlight 로 아이폰에 깔아 손으로 시험** | ✅ **완전히 된다** | **맥이 아예 필요 없다.** 아이폰과 애플 ID 만 있으면 된다 |

그래서 이 문서가 시키는 일은 이것 하나다.

> **아이폰에 TestFlight 로 앱을 깔고, 손으로 눌러 보고, 화면을 찍어서 보낸다.**
> 노트북은 **문서를 읽고 사진을 모아 보내는 데**만 쓴다.

### 🔴 그래서 꼭 필요한 준비물은 **아이폰 실기기 하나**다

노트북 사양은 상관없다. 아이폰이 없으면 이 시험은 **시작조차 할 수 없다** — 빌린 아이폰도
괜찮다. 없으면 먼저 그 사실부터 알려 주면 된다. 대안은 8장에 적어 두었는데, 셋 다 돈이 들고
이번 스프린트 안에는 못 맞춘다.

### 자동화를 포기해도 손해가 크지 않은 이유

어제 맥북으로 자동화를 돌린 회차에서 **스크린샷 95장 중 앱 메인 화면은 0장**이었다.
그리고 이 앱에서 지금까지 나온 화면 결함 — 같은 것을 두 번 그리기, 시안과 다른 배치,
JSON 이 그대로 보이기 — 은 **자동 검사가 하나도 못 잡았다.** 전부 사람이 그림을 보고 찾았다.

**자동화가 판정하는 것은 사실상 크래시뿐이다.** 손으로 40분 보는 쪽이 오늘은 더 많이 잡는다.

## 1. 준비 — 세 단계

### 1-1. 애플 ID 를 이예승에게 알려 준다 (제일 먼저)

TestFlight 는 **초대받은 사람만** 앱을 받을 수 있다. 아이폰에서 쓰는 **애플 ID 이메일 주소**를
이예승(`yeaseung-lee`)에게 axMap 쪽지나 메신저로 보내면 된다.

- 보내는 것: 애플 ID **이메일 주소 하나**. 비밀번호는 절대 보내지 않는다
- 받는 것: 「GABOLLE 테스터로 초대되었습니다」 메일, 또는 TestFlight 공개 링크

> **TestFlight**(**애플이 만든 「출시 전 앱 나눠 주기」 앱**) — App Store 에 정식 출시하기 전
> 단계의 앱을 정해진 사람에게만 깔아 주는 통로다. 개발자 계정이 없어도 **테스터로 초대만
> 받으면** 쓸 수 있다.

초대는 사람이 손으로 해야 한다 — App Store Connect 웹 화면에서 누른다. **이 화면은 윈도우
크롬에서도 똑같이 열린다.** 초대하는 쪽 이야기라 시험하는 사람이 할 일은 아니다.

### 1-2. 아이폰에 TestFlight 를 깐다

App Store 에서 `TestFlight` 를 검색해 설치한다. 무료다.

### 1-3. 초대를 수락하고 GABOLLE 을 깐다

1. 초대 메일의 **「View in TestFlight」** 를 아이폰에서 누른다
2. TestFlight 가 열리면 **GABOLLE** → **설치(Install)**
3. 홈 화면에 가볼래 아이콘이 생긴다

## 2. 🔴 반드시 **build 26 이상**이어야 한다

번호가 낮으면 **이 시험 전체가 무의미하다.** 오늘 보려는 고침이 그 빌드에는 없기 때문이다.

### 확인하는 법

TestFlight 앱 → GABOLLE → 화면 위쪽에 **`1.0.0 (26)`** 처럼 나온다. 괄호 안 숫자가 빌드 번호다.

| 보이는 숫자 | 뜻 |
|---|---|
| **26 이상** | 🟢 맞다. 3장으로 |
| 25 이하 | 🔴 **낡았다.** TestFlight 에서 「업데이트」가 보이면 누른다. 안 보이면 이예승에게 알린다 |

> **26 은 2026-09-18 오전 10:11 에 올린 빌드**다(커밋 `e98b2028`). 같은 날 10:2x 에
> App Store Connect 로 보냈고, 애플 처리에 보통 **5~10분** 걸린다. 초대 직후에 25만
> 보이면 잠깐 기다렸다가 TestFlight 를 다시 연다.

## 3. 시험 전에 아이폰을 이렇게 맞춰 둔다

| 무엇 | 어떻게 | 왜 |
|---|---|---|
| **앱을 지웠다 다시 깐다** | 홈 화면에서 가볼래 **길게 눌러 → 앱 삭제** → TestFlight 에서 다시 설치 | 🔴 **온보딩(첫 실행 화면)부터 봐야 한다.** 한 번 지난 상태면 언어 선택 화면이 안 뜨고, 이번에 볼 것의 절반이 안 보인다 |
| 자동 잠금 끄기 | 설정 → 디스플레이 및 밝기 → 자동 잠금 → **안 함** | 중간에 화면이 꺼지면 흐름이 끊긴다 |
| 소리 켜기 | 측면 스위치를 무음 해제 | 5장 G(소리)에서 필요하다 |
| 와이파이 | 켠다 | 사진 올리기가 데이터를 꽤 쓴다 |

**스크린샷 찍는 법**: 전원 버튼 + 볼륨 올리기를 **동시에 짧게**. 왼쪽 아래 미리보기가
뜨는데 무시하면 사진 앱에 저장된다.

## 4. 앱에 들어가는 길 — 이 순서 하나뿐이다

어제 맥북 자동화가 40분을 쓰고도 못 넘은 자리가 여기다. **화면이 다섯 개**다.

```
 ① 언어 선택        「한국어」를 누른다
        ↓
 ② 앱 소개 3장      왼쪽 위 「건너뛰기」 한 번이면 세 장을 다 넘긴다
        ↓
 ③ 나이 확인        🔴 체크박스를 먼저 누르고 → 「계속」
        ↓             (체크 안 하면 계속이 안 눌린다. 여기서 많이 막힌다)
 ④ 권한 안내        「비회원으로 둘러보기」
        ↓
 🎯 홈              아래에 탭 다섯 개가 보이면 도착
```

### 탭 이름 — 어제 틀렸던 자리

아래 다섯 개가 **진짜 탭 이름**이다.

```
홈 · 피드 · 여행 만들기 · 내 여행 · 마이페이지
```

「여행」「일정」「현장」「부슐랭」이라는 탭은 **없다.** 어제 자동화가 찾던 이름인데,
「부슐랭」이라는 글자가 온보딩 3페이지 **본문**에 있어서 **온보딩 화면을 메인이라고
착각하고 「6/6 완료」를 찍었다.** 손으로 할 때는 이런 착각이 안 나지만, 이름은 알고 있는 게 좋다.

## 5. 시험 목록 — 이 순서대로 누르고 찍는다

각 줄마다 **찍을 것**이 정해져 있다. 판정은 이예승이 하니, **애매하면 그냥 찍어서 보낸다.**
파일 이름은 안 바꿔도 된다 — 순서대로만 보내면 된다.

### A. 진입 (4장에서 한 대로)

| 찍을 것 | 정상이면 |
|---|---|
| 언어 선택 화면 | 다섯 개 언어가 보인다 |
| 나이 확인 화면 | 체크박스와 「계속」 |
| **홈 화면** | 🎯 아래 탭 다섯 개. **이 한 장이 어제 못 얻은 것이다** |

### B. 탭 다섯 개를 한 번씩 누른다

**다섯 장을 다 찍는다.** 보는 것은 하나다 — **같은 것이 두 번 그려져 있지 않은가.**
제목이 두 줄로 겹쳐 있거나, 같은 카드가 나란히 두 개 있거나, 빈 회색 네모가 남아 있으면
그게 결함이다.

### C. 장소 상세 — 🔴 여기에 오늘 볼 것이 두 개 모여 있다

홈에서 **장소 카드 아무거나** 하나를 누른다. 그리고 **화면을 끝까지 내리면서 2~3장**을 찍는다.

| 티켓 | 무엇을 보나 | 🟢 정상 | 🔴 결함 |
|---|---|---|---|
| **1202** | **경사도** | `2.7%` 처럼 보인다 | `{"score":2.7,...}` 같은 **중괄호가 그대로** 보인다 |
| **1202** | **영업시간** | 「매일 10:00~20:00」 또는 「월 … · 토 …」처럼 읽힌다 | 알 수 없는 영어·기호 덩어리 |
| **1203** | 사진 아래 **「사진 제공: …」** | **글자가 또렷이 읽힌다** | 사진에 묻혀 안 읽힌다 |

### D. 로그인하고 **뒤로 가기** (1199)

1. **마이페이지** 탭 → **로그인**
2. **구글**로 로그인한다
3. 로그인이 끝나 화면이 돌아오면 → 🔴 **뒤로 가기를 한 번 한다**
   (화면 왼쪽 끝에서 오른쪽으로 쓸어넘기기)

| 🟢 정상 | 🔴 결함 |
|---|---|
| 로그인 화면이 **다시 안 뜬다** | 로그인 화면이 **또 뜬다** → 그 화면을 찍는다 |

### E. 🔴 사진 올리기 — **오늘 가장 중요하다** (1187)

어제까지 **100% 실패**하던 자리다. 오늘 고쳤고, 실제 아이폰에서 되는지 아직 **아무도 못 봤다.**

1. **피드** 탭 → 오른쪽 아래 **연필** 단추
2. 아무 글자나 쓴다 (「시험」 정도면 된다)
3. **+ 사진 추가** → 사진 하나 고른다
4. 🔴 **미리보기에 사진이 뜨는가?** ← **여기를 찍는다**

| 🟢 정상 | 🔴 결함 |
|---|---|
| 사진이 네모 안에 보인다 | 「실패 · 다시 시도」가 뜬다 → **괄호 안 영어까지 통째로** 찍는다. 그 한 줄이 원인이다 |

5. 「기록 올리기」를 누른다 → **피드 맨 위에 방금 올린 사진이 보이면 끝까지 된 것이다.** 찍는다

### F. 현장 도구 — 🔴 **이미 아는 고장이 있다. 티켓 새로 만들지 않는다**

홈 → **현장 도구**. 여기 있는 것들을 하나씩 눌러 본다.

| 도구 | 지금 상태 | 무엇을 보나 |
|---|---|---|
| **메뉴판 읽기** | 🟢 **된다** | 메뉴판 사진을 찍으면 글자를 읽어 준다. **안 되면 그건 새 결함이다 — 찍어서 보낸다** |
| **날씨** | 🟢 된다 | 부산 날씨가 나온다 |
| **환율** | 🔴 **고장. 이미 아는 것** | 문구만 본다 ↓ |
| **대중교통** | 🔴 고장. 이미 아는 것 | 문구만 본다 ↓ |
| **번역** | 🔴 고장. 이미 아는 것 | 문구만 본다 ↓ |
| **비서(챗봇)** | 🔴 고장. 이미 아는 것 | 문구만 본다 ↓ |

넷이 고장 난 이유는 하나다 — **서버에 업체 열쇠(API 키)가 안 꽂혀 있다.** `S15P21E201-1186`
으로 이미 추적 중이고, 사람이 열쇠를 받아 와야 풀린다. **그러니 「안 된다」는 티켓을 새로
만들지 않는다.**

대신 **문구 하나만 본다 (1200)**. 넷 중 아무거나 하나 눌러서 나오는 메시지를 찍는다.

| 🟢 정상 (오늘 고친 결과) | 🔴 옛 빌드 |
|---|---|
| 「**이 기능은 아직 준비 중이에요**」 — 「다시 시도」 단추가 **없다** | 「제공처가 잠시 응답하지 않아요 · **다시 시도**」 → **build 26 이 아니다.** 2장으로 돌아간다 |

### G. 소리가 나는가

홈 → 현장 도구 → **「장소별 한국어」** → 문장 하나를 눌러 재생.

**이건 화면으로 판정이 안 된다 — 귀로 듣는다.** 「소리 남 / 안 남」 한 줄만 적어 주면 된다.

### H. 지도가 실제로 그려지는가

**내 여행** 탭 → 여행 하나 → 지도.

**회색 네모만 있고 지도 그림이 안 그려지는 경우**가 있었다. 눈으로 보고 찍는다.

### I. 앱이 꺼지는가 (크래시)

시험 중에 **앱이 저절로 홈 화면으로 튕겨 나가면** 그게 크래시다. 몇 번, 어느 화면에서
났는지 적어 준다. 증거는 이렇게 남긴다.

> 아이폰 **설정 → 개인정보 보호 및 보안 → 분석 및 개선 → 분석 데이터** →
> 목록에서 **`GABOLLE`** 로 시작하는 항목(날짜가 오늘인 것)을 누른다 →
> 오른쪽 위 **공유** → 본인에게 보낸다

이 파일이 크래시의 진짜 원인을 담고 있다. 튕긴 적이 없으면 이 단계는 건너뛴다.

## 6. 결과를 노트북으로 옮겨서 보내는 법

아이폰 사진을 윈도우로 옮기는 길이 셋 있다. **아무거나 편한 것**을 쓴다.

| 방법 | 어떻게 |
|---|---|
| **카카오톡 「나에게 보내기」** (제일 쉽다) | 아이폰 카톡 → 나와의 채팅 → 사진 전부 보내기 → 노트북 카톡에서 내려받기 |
| **USB 케이블** | 아이폰을 노트북에 꽂고 **「이 컴퓨터를 신뢰」** → 파일 탐색기에 `Apple iPhone` 이 뜬다 → `Internal Storage\DCIM` 안에 사진이 있다 |
| **iCloud 웹** | 노트북 크롬에서 `icloud.com` → 사진 → 내려받기 |

### 보낼 것 — 이 두 가지면 충분하다

1. **스크린샷 전부** (폴더째 압축해서)
2. **아래 여섯 줄을 채운 메모**

```
빌드 번호:        1.0.0 (  )        ← TestFlight 에 보이던 괄호 안 숫자
사진 올리기:      됨 / 안 됨 (안 되면 뜬 문구 그대로)
로그인 뒤로가기:  로그인 화면 다시 뜸 / 안 뜸
소리:             남 / 안 남
지도:             그려짐 / 회색 네모
앱이 튕긴 횟수:   0 회 (튕겼으면 어느 화면인지)
```

> 🔴 **못 한 항목은 「확인 못 함」이라고 적는다.** 빈칸으로 두거나 「됨」으로 적으면
> 다음 사람이 확인된 줄 안다. 어제 자동화 보고서 하나가 「20/20 성공」이라고 적었는데
> 실제 기능 검증은 0% 였다 — **거짓 성공이 실패보다 나쁘다.**

| 초대 메일이 안 온다 | 스팸함을 본다. 그래도 없으면 **알려 준 애플 ID 철자**를 다시 확인한다 |
| TestFlight 에 GABOLLE 이 안 보인다 | 초대 수락이 안 된 것이다. 메일의 링크를 **아이폰에서** 다시 누른다 |
| 앱을 켰는데 **언어 선택이 안 나온다** | 이미 온보딩을 지난 상태다. **앱을 지우고 다시 깐다**(3장) |
| 「계속」이 회색이라 안 눌린다 | 나이 확인 화면이다. **체크박스를 먼저** 누른다 |
| 구글 로그인이 브라우저에서 안 돌아온다 | 화면 왼쪽 위 「가볼래로 돌아가기」를 누른다. 그래도 안 되면 그 화면을 찍어서 보낸다 |
| 사진 고르기에서 사진이 안 보인다 | 아이폰 설정 → 가볼래 → 사진 → **「모든 사진」** 으로 바꾼다 |
| **Xcode 를 깔라는 안내를 어디선가 봤다** | 그건 **맥북용 문서**(`docs/ios-automation/`)다. 윈도우에서는 해당 없다 — 0장 참고 |

## 8. 그래도 자동화를 꼭 해야 한다면 (셋 다 이번 스프린트에는 권하지 않는다)

| 길 | 필요한 것 | 왜 지금은 아닌가 |

## 9. 이 문서가 확인하지 못한 것

정직하게 적어 둔다. 다음 사람이 다시 재보지 않도록.

- **build 26 은 2026-09-18 10:2x 에 App Store Connect 로 올려 보낸 것까지 확인했다.**
  그 뒤 애플이 5~10분 처리해야 TestFlight 에 보이는데, **그 마지막 단계는 확인하지 못했다.**
  그러니 **2장의 번호 확인을 반드시 먼저 한다**
- **App Store Connect 의 테스터 초대 화면을 이 문서는 직접 띄워 보지 못했다.** 초대 절차
  (1-1)는 애플 문서 기준으로 적었다. 화면이 다르면 알려 주면 고친다
- **아이폰 실기기가 확보되었는지 모른다.** 없으면 이 문서 전체가 못 돌아간다 — 8장으로 간다
- 5장 C 의 장소 상세는 **어느 장소를 열든** 경사도·영업시간·사진 출처를 보는 목적에는
  지장이 없다. 다만 장소에 따라 경사도가 **아예 없을 수** 있다. 그럴 때는 「경사도 칸이
  없었다」고 적으면 된다 — 그건 결함이 아니다
