# 받은 zip 과 다른 것 두 가지

받은 파일: `회원가입 동의 화면.zip` (2026-09-23, 16개 파일 · 28MB). 나머지는 **받은 그대로**다.

| 파일 | 받은 것 | 여기 둔 것 | 왜 |
|---|---|---|---|
| `prototype/fonts/Pretendard-{Regular,Medium,Bold}.ttf` | 3개 · 8MB | **넣지 않음** | `frontend/assets/fonts/` 의 같은 이름 파일과 **바이트까지 같다** (sha256 대조). 같은 8MB 를 두 번 올리지 않는다 |
| `prototype/assets/busan-night.jpg` | 6192×4128 · 18MB · 카메라 EXIF | **2000×1333 · 약 240KB · EXIF 없음** | 앱에 들어간 `frontend/assets/home/busan-night.jpg` 와 같은 압축본이다. 원본은 저장소에 두기에 너무 크다 |

🔴 README 에는 사진 원본이 「약 2350×1570」이라고 적혀 있지만 **실제 받은 파일은 6192×4128** 이었다 (JPEG 머리에서 잼).

## 시안을 제 글꼴로 열려면

`prototype/fonts/` 폴더를 만들고 `frontend/assets/fonts/Pretendard-*.ttf` 셋을 복사한 뒤
`prototype/signup-consent.dc.html` 을 브라우저로 연다. 없으면 시스템 한글 글꼴로 대신 그려진다.
