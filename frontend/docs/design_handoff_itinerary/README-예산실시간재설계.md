# 인계 — 일정 화면 재설계 (예산 명세 · 출발/실시간 추적 · 순서 수정 · 이름 바꾸기)

대상: `app/trips/[id]/itinerary.tsx` · `src/plan/NowCard.tsx` · `src/components/TabBar.tsx` · `src/trip/TripNameSheet.tsx`
시안: `배포본 일정 (예산·실시간).dc.html` — 브라우저로 열면 동작(같은 폴더의 `support.js`·`assets/`). 스타일은 전부 인라인. 색은 `src/design/tokens.ts` 부산은행 톤 그대로.
백엔드가 아직 없는 값(예산 합계·GPS·대중교통 안내)은 **뼈대와 자리**만 잡는다 — 시안의 숫자는 예시.

## 1. 헤더 (스크린샷 01)
- 어두운 헤더 **제거** → 바탕 `canvas #F5F5F7`. 글자 `#191919`, 요약 `#6F6F6F`. 어두운 면은 「지금」 카드 하나만.
- 제목 옆 「이름 바꾸기」: 흰 알약 32px, `1px #EBEBEF`, `white-space:nowrap`.
- 요약 한 줄: `3일 · 12곳 · 도보 6.5km · 약 19.8만원` (당일치기면 `당일치기 · 5곳 …`).
- 헤더 아래 칩: **지도 보기 · 동행 초대 · 날씨** (「추천 다시 보기」 삭제, 「날씨·준비물」→「날씨」). 흰 배경 `1px #EBEBEF`, 반경 14, 44px, `nowrap; flex:none`.
- **일차 탭**: 세그먼트(`#E9E9EC`, 패딩 4, 반경 999) 안에서 **동백색(#D83A48) 알약이 좌우로 미끄러짐** — `left` 트랜지션 `.45s cubic-bezier(.22,1,.36,1)`, 글자 흰/`#444`. 데스크톱은 `max-width 560, margin auto`로 중앙. **하루짜리 여행이면 탭을 그리지 않고 공간도 접는다.**

## 2. 「지금」 카드 — NowCard (01·02)
- `#191919`, 반경 20, 패딩 16. 도착 순간만 `#2E9E5B`로 0.4s 전환.
- 상태별 문구
  - 대기: 「지금」 · 「다음은 해운대해수욕장」 · 「5곳 · 첫 정차 10:00」 · `▶ 출발`(동백)
  - 이동: 「지금 · 위치 추적 중」(빨간 점 맥박) · 「해운대해수욕장으로 이동 중」(조사 `koreanToward`) · 「버스 12분 · 도보 600m · 약 3분 남음 · 139m」 · 폰은 6px 진행 막대 · `⏸ 일정 중지` `건너뛰기`
  - 도착 순간: 카드 초록 · 「도착 · GPS 자동 기록」 · 「해운대해수욕장 도착!」
  - 머무는 중: 「지금 · 머무는 중」 · 「해운대해수욕장에 있어요」 · 「약 n분 더 머물러요 · 11:20 출발 → 동백섬 산책로」 · 버튼 `지금 출발`
  - 완료: 「오늘 일정을 다 돌았어요」
- **데스크톱은 진행 막대 대신 노선도를 카드 안에 넣는다**(RouteStrip을 본문에서 헤더 카드로 이동, 가운데 정렬). 노드 40px: `0` 출발지(흰 테두리) → 정차 1…n. 다녀옴 초록 ✓ · 현재 빨강 ● · 다음 흰 채움 · 이후 흰 테두리. 지나온 구간 선은 초록, 남은 구간 `rgba(255,255,255,.25)`.

## 3. 실시간 안내 카드 (02, 이동 중에만)
흰 카드, 반경 20. 위 168px 지도 자리(경로선 · 현재 위치 빨간 점 · 「GPS ±12m」 · 「10:00 도착 예정」). 아래 두 줄(48px): ① 다음 안내 「해운대해변로 따라 직진 / 200m 앞 … 좌회전 / … 도착 n m 앞」 + 「n m · 약 n분」 ② 대중교통 「1003번 버스 · ○○ 정류장 / 지하철 2호선」 + 「4분 후 도착 · 환승 없음」. 도보 구간이면 「도보 구간 · 대중교통 없음」. 머무는 중엔 ① 「이곳에서 약 n분 · 출발 시각」 ② 「다음 ○○ 시각」.
폰: NowCard 아래. 데스크톱: 오른쪽 360 기둥 맨 위.

## 4. 노선(정차 목록) (01·06)
- **0 · 출발지 노드**를 맨 위에(흰 바탕 `2px #191919` 테두리, 「출발 · 부산역 · 09:48」). 그 아래로 첫 구간(버스 12분 · 도보 600m) 선이 1번으로 이어진다.
- 세로선·구간선 `#DADCE2` 3px. 노드 32px(폰)/40px(데스크톱).
- 현재 정차 카드에만 붉은 링 `0 0 0 1.5px #D83A48`. 다녀온 정차 아래 「도착 10:00 · GPS 자동 기록」(초록), 건너뜀은 회색.

## 5. 순서 수정 (06)
- **폰**: 하단 탭바 가운데(원래 「여행 만들기」) 자리가 이 화면에서는 **「순서 수정」**(동백 원 + ≡). 누르면 탭바가 그 자리에서 검게(`#191919`) 바뀌며 탭 층은 아래로 24px 내려가며 사라지고 「≡ 손잡이를 끌어 순서를 바꿔요 · **수정 완료**(동백)」 층이 위에서 내려온다(`.45s cubic-bezier(.22,1,.36,1)`). 위에 따로 있던 「순서 수정」 버튼은 없앤다.
- **데스크톱**: 날짜 줄 오른쪽에 「순서 수정」 알약(흰, `1px #EBEBEF`) → 편집 중 「수정 완료」(동백 채움). 노선도는 편집 중 숨김.
- 편집 중: 노드가 ≡ 손잡이(`#2B2B2E`)로, 🔒 고정은 `#E9E9EC` + 잠금. 행을 끌어(drag) 순서 변경, 구간 표시는 숨김.

## 6. 이름 바꾸기 (05·07)
- **데스크톱**: 어둠막 `rgba(25,25,25,.45)` 위 480px 모달 — 「이름 바꾸기」 · 「비워 두고 저장하면 이름이 지워지고 카드에 날짜가 보여요.」 · 입력 · 「카드에 이렇게 / 미리보기」 · 취소 / 저장(비우면 「지우고 저장」).
- **폰**: 모달 대신 **탭바가 시트로 자란다** — 328×64 → 361×340, `.42s cubic-bezier(.34,1.3,.64,1)` (TabBar `expanded`). 내용은 모달과 같고 ✕로 닫는다.

## 7. 예산 명세 (01, 오른쪽 기둥 / 폰은 노선 아래)
「예산 대비」 카드: 총액 26px + 오른쪽 「예산 300,000원 / 예산에 맞아요 · 10.2만원 남음(초록)」, 넘으면 「예산을 n만원 넘어요(#B02A38)」 + 막대 빨강. 10px 막대(총액/예산) → 6px 분해 막대(식비 `#2B2B2E` · 카페 `#6F6F6F` · 입장·체험 `#A0A0A6` · 교통 추정 `#DADCE2`) → 항목 목록 → 일차별 막대. 각주 「교통은 구간 거리로 추정한 값이에요 · 입장료·식비는 장소 자료 기준」.

## 8. 하단 탭바 (실제 TabBar 그대로)
328×64, 반경 20, 그림자 `0 -2px 14px rgba(25,25,25,.10)`. 홈 · 피드 · **(이 화면) 순서 수정** · 내 여행(활성: 굵은 글자 + 아래 5px `#F25454` 점) · 마이페이지. 아이콘 20px, 라벨 12px `#8B8B8B`.
