# 인계 — 조건 설문(/plan) · 온보딩 취향(taste-profile) 재설계

디자인 도구에서 확정한 화면. `*.dc.html`을 브라우저로 열면 실제로 동작하는 시안(같은 폴더의 `support.js`·`assets/` 필요).
스타일 값은 전부 인라인이라 그대로 읽어 옮기면 된다. 색·간격은 `src/design/tokens.ts`의 부산은행 톤 그대로다.

## 1. /plan 조건 설문 — `배포본 조건 질문.dc.html` · `app/(plan)/questions.tsx`

### 문항 (10 → 7)
| # | key | 종류 | 비고 |
|---|-----|------|------|
| 1 | areas | 필수 | 여행 범위 |
| 2 | budget | 필수 | 총예산 — 소비 프로필 값으로 미리 채움 |
| 3 | move | 필수 | 하루 여행 시간 · 이동수단 |
| 4 | cats | 선택 | 여행 카테고리(최대 3) |
| 5 | pace | 선택 | 여행 기분 |
| 6 | aids | 선택 | 이동 보조 · 짐 |
| 7 | must | 선택 | 꼭 가고 싶은 장소 |

**삭제**: `moods`(좋아하는 분위기) · `scales`(로컬성·조용함·관광지) · `foods`(음식 취향).
로컬성·조용함·음식은 온보딩 취향이 `draft`로 이식되므로(PlanProvider prefill, 백엔드 변경 없음) 다시 묻지 않는다.
`planQuestions.ts`의 `PLAN_QUESTIONS`, `questions.tsx`의 `SCALES`·`body()`·`summaryOf()`·`effectOf()`에서 해당 분기 제거.

### 데스크톱 (wide ≥1024) — 스크린샷 01·03·05·07
`PlanContextColumn`(제목·설명·사진 카드·미니 카드 3개·기억된 취향 카드) **전부 제거**. 대신 왼쪽 280px 레일:
- 「이번 여행」 카드: 날짜 · 출발지/인원 · 우상단 「수정」(홈 시작 바로)
- **체크리스트**(7행, 각 44px): 원 24px — 현재 `#191919` 채움+번호, 답함 `#2E9E5B` ✓, 남음 흰 바탕 `1px #DADCE2` 회색 번호. 현재 행 배경 `#F0F0F3`, 반경 10.
  라벨 13px(현재 700 / 그 외 500 `#444`), 아래 12px `#6F6F6F` — 답한 값 요약 또는 「필수/선택」. 누르면 그 문항으로 이동(필수 미완 상태에선 뒤 문항 이동 불가).
- 레일은 `position: sticky; top: 24`.

오른쪽 760px: 눈썹(「필수 1 / 3」·「선택 1 / 4」) + 제목 → 4px 진행 막대(`#DADCE2` / 채움 `#2B2B2E`) → **질문 카드 하나** → 「이전 / 다음」.
답한 목록·「다음 질문」 목록·StepDots·상태 문구는 데스크톱에서 그리지 않는다(레일이 대신한다).
가운데 정렬: `justify-content:center; gap:32px; padding:24px 40px 64px`.

### 모바일 — 스크린샷 02·04·06·08
기존 구조 유지(위 줄: ‹ + 홈 칩 + 수정 → 눈썹/제목 + StepDots → 진행 막대 → 상태 문구 → ✓ 여행 날짜 행 + 답한 행 → 질문 카드 → 이전/다음 → 다음 질문).
- **기억된 취향 카드 없음**(폰·데스크톱 모두).
- **「지금 이대로 만들기」 갈림길 카드·버튼 제거**(`forkCard`·`buildNow`). 마지막 문항의 「이 조건으로 일정 만들기」만 남긴다.
- 질문 카드 `minHeight` 제거(`cardWide: 360`·`cardPhone: 300` 삭제), 폰 패딩 24 → 20. 예산처럼 짧은 문항이 빈 공간을 남기지 않게.

### 공통 값
- 질문 카드: 흰 배경, `1px #EBEBEF`, 반경 20, gap 16. 눈썹 13/700 `#6F6F6F` · 제목 18/700 · 힌트 15 `#6F6F6F`.
- 선택지 카드(OptionCard): min 72px, 반경 14, `1px #EBEBEF`, 선택 시 `#191919` 채움 + 흰 글자 / 부제 `#DADADF`. `flex: 1 1 150px`.
- 「이렇게 반영돼요」 띠: `#F0F0F3`, 반경 14, 8×12 패딩.
- 「이전」 알약(`1px #EBEBEF`, `flex:none; white-space:nowrap`), 「다음」 채움 `#D83A48` / 비활성 `#DADCE2`, 반경 14, 48px.

## 2. 온보딩 취향 — `배포본 온보딩 취향.dc.html` · `app/(onboarding)/taste-profile.tsx` — 스크린샷 09·10
- `tasteProfile.ts`의 `TASTE_QUESTIONS`에서 **`tourist` 문항 제거** → 4문항(locality · quiet · foods · slope). 제목 「여행 취향을 4개만 여쭤볼게요」.
- **건너뛰기 전면 제거**: 상단 「전체 건너뛰기」, 문항별 `skip`(잘 모르겠어요 / 지금은 안 고를게요) 모두 삭제. 답을 골라야만 다음으로. 「‹ 이전」만 유지.
- 안내 문구: 「…추천 순서가 달라져요. 마이페이지에서 언제든 바꿀 수 있어요.」(「건너뛰셔도 돼요」 삭제)
- 데스크톱 카드 푸터: 왼쪽 「‹ 이전」, 오른쪽 `n / 4` 회색 캡션(skip 링크 자리).
- 그 외(5점 척도 트랙 56px 원, 음식 칩 + 「선택 완료」, 경사 선택 카드)는 배포본 그대로.
