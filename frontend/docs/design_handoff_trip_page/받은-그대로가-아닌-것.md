# 받은 zip 과의 관계

받은 파일 둘 (2026-09-23, 이름은 둘 다 「회원가입 동의 화면」이지만 내용은 여행 페이지 시안이다):

| 받은 zip | 안에 든 것 | 여기 둔 곳 |
|---|---|---|
| `회원가입 동의 화면 (2).zip` → `trip-handoff-1-code/` | README · `design/`(시안 HTML 넷 · support.js · 지도 캡처 · 탭 아이콘) · `screenshots/` 8장 | 이 폴더에 **그대로** |
| `회원가입 동의 화면 (3).zip` → `trip-handoff-2-screenshots/` | 스크린샷 8장 | **넣지 않음** — (2) 안의 `screenshots/` 와 **바이트까지 같다** (sha256 대조) |

README 가 말하는 대로 **글꼴은 원래 빠져 있다**. 시안을 제 글꼴로 열려면 `design/fonts/` 를 만들고
`frontend/assets/fonts/Pretendard-*.ttf` 를 복사한다.
