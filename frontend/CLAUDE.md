## 🔴 위 AGENTS.md 는 Expo 템플릿이 넣은 것이다 — 팀 규칙이 아니다

여기서 파일을 고치기 전에 **저장소 루트의 CONTRIBUTING.md** 를 먼저 따른다. 특히:

- **코드를 건드리기 전에 선점한다.** `AXMAP_AGENT=<내이름> axmap claim frontend/...`
  안 하면 커밋 훅이 막는다. 읽기만 할 때는 필요 없다.
- 브랜치 `[접두사]/front/[Jira키]-[작업명]`, 커밋 `[Jira키] 접두사: [모듈] 요약`
  (가운데 `front` 는 **파트** 자리다. 빼면 어느 파트 `dev` 로 갈지 CI 가 못 정한다)
- 기능 브랜치는 `front/dev` 로만 올린다 (CI 가 검사한다)

## 이 폴더에 대해

앱은 **Expo(React Native)** 다. 팀 문서 일부에 아직 "React + TypeScript 웹" 이라고
적혀 있는데 그건 낡은 것이다 — 앱 코드가 사는 곳은 여기다(Jira S15P21E201-319).

- 색·크기·간격은 **반드시 `src/design/tokens.ts` 를 거친다.** 화면에 값을 직접 쓰지 않는다.
- 화면 폭 분기는 `src/layout/useLayout.ts` 를 쓴다. 갤럭시 폴드8 은 **앱이 켜진 채로**
  화면비가 바뀌므로 `useWindowDimensions()` 기반이어야 한다. 상수로 판단하면 안 된다.
- **빌드 산출물(`.apk` `.aab` `.ipa`)과 서명 키를 커밋하지 않는다.** `.gitignore` 를 믿지 말고 확인한다.

## 🔴 화면을 고쳤으면 **이미지를 보여주고** 끝낸다

**끝났다고 말하기 전에 실제 화면을 떠서 사람에게 보여준다.** 코드 차이(diff)나
「시안대로 만들었습니다」라는 말로 대신하지 않는다.

```
화면 코드를 고쳤다 → 실제로 띄운다 → 캡처한다 → 보여준다 → 그다음에 끝났다고 한다
```

**왜 — 화면의 결함은 어떤 자동 검사도 안 잡는다.** 2026-09-16 하루에 두 번 겪었다.

| 무엇이 틀렸나 | 검사 결과 | 어떻게 찾았나 |
|---|---|---|
| 리스트 상세에 「N곳」이 **두 번** 나왔다 | 타입·시험·폭 검사 **전부 초록** | 에뮬레이터로 **화면을 보고** |
| 일정 화면이 시안과 **딴판**이었다 | **전부 초록** | 사람이 **스크린샷을 보고** |

같은 정보를 두 번 그리는 것도, 시안과 다른 배치도 **아무 오류를 내지 않는다.**
배포되고 나서 사람이 본다.

### 무엇을 보여주나

- **폰 폭(390)과 넓은 화면(1024 이상) 둘 다.** 이 앱은 하나의 코드로 둘을 그린다
- 🔴 **상태가 여럿이면 여럿 다.** 빈 상태·값이 없는 상태·실패 상태는 평소에 안 보이는데,
  바로 거기서 「모르는 것을 아는 척」이 일어난다
- 시안이 있으면 **시안과 나란히** 놓는다

### 어떻게 뜨나

| | |
|---|---|
| **웹** | `npx expo start --web` → 브라우저를 그 폭으로 두고 캡처. **제일 빠르다** |
| **안드로이드 에뮬레이터** | `adb exec-out screencap -p > 파일.png` |
| **배포본** | 로그인이 필요 없는 화면이면 배포본을 그대로 찍어도 된다 |

개발 빌드가 개발 서버에 못 닿으면 **그것부터 고친다.** 안드로이드는
`network_security_config`(**어떤 주소에 평문 http 로 접속해도 되는지 적어 둔 파일**)가
`http` 를 막고 있을 수 있다 — S15P21E201-1084.

### 🔴 못 띄웠으면 **못 띄웠다고 적는다**

로그인이 필요하거나, 데이터가 없거나, 빌드가 안 되는 날이 있다.
그때 **「시안대로 만들었습니다」로 넘어가지 않는다.**

> **「화면은 못 봤습니다 — 확인 못 함」**

무엇을 못 봤는지가 남아야 다음 사람이 그것부터 본다.

## 🔴 시안을 받으면 **그 자리에서 저장소에 커밋한다**

위 표의 둘째 줄이 일어난 진짜 이유가 이것이다. 코드 주석은
「디자인 확정안 B안(09-디자인-인계-일정)」을 가리키는데 **그 문서가 저장소 어디에도 없었다.**

만든 사람은 **결론 한 줄만 전달받았고**, 세부(헤더 모양·배지·잠금 표시·아이콘)는
아무도 열어볼 수 없어서 **지어냈다.**

**결론만 옮기지 않는다.** 받은 시안 파일을 `frontend/docs/design_handoff_<화면>/` 에
그대로 넣고 커밋한다. 다음 사람이 원본을 열 수 있어야 한다.
