**Jira** `S15P21E201-705` · 라운드3 · **2026-09-07**

선등록(preregistration — *"판정용을 열기 전에 최종안·예상 성적·기준을 적어 두는 것"*)
은 열어 본 뒤에 말을 바꾸지 못하게 하려고 쓴다. 라운드2 의 `r2-preregistration.md`

열지 않았다.

| | 지표 | 넘어야 하는 선 |

**둘 다 넘어야 성공이다.** 🔴 결과를 보고 낮추지 않는다.

## 2. 무엇을 판정하나

## 3. 최종안 `m3`

로지스틱 회귀(여러 신호에 무게를 곱해 더한 뒤 0~1 확률로 눌러 담는 가장 단순한
지도학습 모델)를 **조정용 110곳만 보고** 맞췄다.

| | |
|---|---|
| 입력 칸 | **85개** — 수치 29 + 업종 소분류 원핫 40 + 구군 원핫 16 |
| 🔴 정답표에서 온 입력 | **없다.** 전부 상가정보 CSV · OSM · 해안선에서만 나온다 |
| 라운드2 대비 새 칸 | 🌊 **해안선까지 거리(log)** · 🌊 **바다 300m 안** — 2칸 |
| 규제 세기 λ | **0.001** — 조정용 안 5겹 교차검증으로 골랐다. 판정용 안 씀 |
| 정답 가중 | ×**30** (정답이 0.2% 뿐이라 그냥 두면 전부 "아니오" 라고 답한다) |
| 오답 표본 | 15,000곳 (순위에는 영향이 없다) |
| 🔴 **정답의 강도** | **출처 수** — 두 곳에 실렸으면 ×2, 셋이면 ×3. A(무게 없음)·B(출처 수)·C(출처 수 + 리본 2개면 +1) 셋을 교차검증으로 견주어 **B** 를 골랐다 |
| 🔴 미쉐린 가격대 | **안 썼다.** 가격대는 **비싼 정도**이지 맛의 등급이 아니다. 무게로 쓰면 비싼 집 쪽으로 모델을 민다 |
| 손잡이 쓸기 | `r3-07b-sweep.mjs` 로 칸 자르기 2가지 × 정답가중 3가지 × λ 3가지 = 18조합을 조정용 교차검증으로 재고 골랐다 |

**조정용 교차검증 성적: Recall@200 6.4% · 중앙 백분위 12.1%**
(조정용 전체 재적합 후 조정용에서: R@200 7.3% · 중앙 4.9% — 외운 값이라 부풀려져 있다)

## 4. 🔴 판정용을 열기 전 예상 — 이 줄을 나중에 고치지 않는다

| 항목 | 예상 | 왜 |
|---|---|---|
| **Recall@200** | **5 ~ 8%** (중심 6%) | 조정용 교차검증이 6.4% 였다. 판정용 47곳이면 한 곳이 **2.1%p** 씩 움직이니 3~4곳 맞히는 셈이다 |
| **중앙 백분위** | **8 ~ 18%** (중심 12%) | 교차검증 12.1% |
| **주 기준(≥20%) 통과** | 🔴 **못 넘을 것으로 예상한다** | |
| **부 기준(≤33%) 통과** | 🟢 넘을 것으로 예상한다 | |
| **최종 판정** | 🔴 **실패로 예상한다** | 예상하고도 그대로 연다. 예상이 맞는지도 기록이다 |
| 라운드2 최종안 `m1` 이식 | R@200 **1 ~ 4%** · 중앙 **15 ~ 25%** | 조정용에서 2.6% / 19.3% 였다 |
| 라운드2 손조합 `w18` 이식 | R@200 **0 ~ 3%** | 조정용에서 1.8% |

**왜 20% 를 못 넘을 것 같은가** — 지금 가진 신호는 전부 **동네 수준**이다
(업종·구군·밀집·바다까지의 거리). 같은 골목 같은 업종의 두 집 중 어느 쪽이 맛있는지를
가를 값이 우리 데이터에 **하나도 없다.** 상위 200위는 후보의 0.37% 라, 동네 수준
신호만으로는 그 좁은 칸에 정답을 몰아넣을 수 없다.

## 5. 판정용을 연 뒤에 **하지 않을 것**

- 모델을 고치지 않는다
- 기준을 낮추지 않는다
- 정답표를 다시 만들지 않는다
- 분할 씨앗을 바꾸지 않는다
- 고칠 것이 생기면 **문서에 적기만** 한다 (라운드2 11.3 과 같다)
